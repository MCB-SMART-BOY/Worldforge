# 11 · 操作工作流

> 写作、审校与维护任务的总入口。根 `AGENTS.md` 说明共享约束；本页负责把目标路由到具体流程，并闭合当前任务。
> 最后更新：2026-11-14

## 一、任务闭环

1. 明确用户目标、验收范围与当前文件状态；检查 Git 改动，保留不属于本任务的内容。
2. 查实时审校账本和正式索引，按需读取正文、章纲、canon、workspace 资料及必要的相邻上下文。
3. 按本页路由选择流程或技能；各 harness 按自身能力发现/调用技能，不能自动发现时直接读取对应 `SKILL.md`。
4. 完成修改后回读受影响内容，并按任务风险应用[质量门](03_质量门.md)；只更新确有变化的索引、canon 或实时记录。
5. 记录结果、证据、待核事项和续接点。目标尚未完成且仍可推进时继续处理；不得把未完成项写成已完成。
6. 提交由作者明确决定；未获要求时不创建提交。

## 二、按任务进入

- **写作或实质改写**：进入[章节流水线](01_流水线.md)。
- **审阅、设定核验、跨卷核验、人物/入口/实践单设计**：在[任务路由与资料索引](04_命令中心.md)选择专项技能。
- **项目资料、规则、技能或路径维护**：进入[运维手册](10_运维手册.md)。
- **更新实时进度**：按[状态机](02_状态机.md)维护 workspace 实时账本。

04 维护唯一的详细技能映射；各技能的输入、步骤和输出格式以对应 `SKILL.md` 为准。技能 ID 是稳定路由名称，不代表所有运行环境都提供同名命令；不能自动发现时，直接读取对应文件执行。

## 三、状态与事实来源

- 全项目正文审校进度、已完成范围、待决项和续接点：[`workspace/正文全卷审校进度.md`](../workspace/正文全卷审校进度.md)。历史报告与快照只说明其记录时点。
- 正文顺序和稿件类别：目标卷根目录的 `00_正文索引.md`（若存在）；否则结合正文、章纲和实时账本核对，不从文件名推断。
- 人物、章纲、研究与工作区导航：对应 `.agents/workspace/` 卷索引及资料；章纲和提案不自动证明事件已写入正文。
- 世界事实、系列锚点和术语：按主题查对应 `.agents/canon/` 文件；跨卷因果优先核对 canon26、当前正文及卷索引。

产出物状态定义见 [状态机](02_状态机.md)，检查标准统一见 [质量门](03_质量门.md)。本页负责任务入口和闭环，不另设一套章级检查清单；动态进度以实时账本为准。

## 四、恢复与交接

需要续接上次会话时，按 [会话协议](06_会话协议.md) 从实时账本恢复；需要并行拆分或跨代理交接时，按 [多代理协作与交接](12_多代理协作与交接.md) 先划定互不冲突的范围，再由主任务统一复核。
