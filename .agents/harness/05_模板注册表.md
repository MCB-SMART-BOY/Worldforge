# 05 · 模板注册表

> 集中登记当前可复用的模板定义。实例文件可能沿用旧结构；创建新材料前以正文索引、现行 canon 和对应技能复核适用性。

```

│   └── 按任务范围选取的人物卡参考结构
├── 章节模板 (Chapter)
│   ├── 章节设计蓝图模板
│   ├── 六拍骨架模板
│   └── 正文文件模板
├── 场景模板 (Scene)
│   └── 场景工艺模板
├── 卷级模板 (Volume)
│   ├── 卷索引模板
│   ├── 章纲 Section 文件模板
│   └── 正文设计目录模板
├── 教学模板 (Supplements)
│   ├── 章节实践单模板
│   ├── 卷级里程碑表模板
│   └── 术语工具最小索引模板
└── 入门模板 (Entry)
    ├── 世界入门模板
    ├── 卷入门模板
    ├── 第零章模板
    └── 阅读指南模板
```

## 三、模板依赖链

```
基础规则 / 相关卷设定 ──→ 章节与场景设计技能 ──→ 本章设计产物
人物谱系 / 主角模板 ────→ gen-character ────────→ 人物卡
学习目标 / 配套规则 ────→ gen-practice ─────────→ 实践单
工程术语表 ─────────────→ 写作、审校及教学材料
现行正文索引 / 实时账本 ─→ 章节范围、现状与映射核验
```

依赖应由任务决定，不存在一张能覆盖所有卷和所有模板的固定 canon 清单。`.agents/canon/23_四卷120章总蓝图.md` 是旧设计材料，不能作为现行章纲模板的数据源。

## 四、模板使用原则

1. **模板是参考，不是必填表**：模板提供可复用的结构，按具体章节、人物和读者任务选择字段
2. **只填适用项**：重要项不适用时说明原因；不为满足格式而捏造事实或内容。
3. **版本可追溯**：模板有实际版本号时记录版本；没有版本号时引用文件路径和修订日期，不虚构版本。
4. **模板演化**：调整模板定义时，核对现有实例和相关技能，说明迁移是否必要；不批量改写旧实例而丢失其来源。

## 五、创建新模板的流程

1. 确认现有模板确实不覆盖此需求
2. 确定新模板的分类（人物/章节/场景/卷级/教学/入门）
3. 确定新模板的适用范围和真正依赖的 canon、索引或技能（无需为形式强行引用 canon）
4. 创建模板定义（在对应的 skill 或 supplements 中）
5. 在此注册表中登记
6. 只有组件职责或相互关系发生变化时，才更新 `00_架构总图.md`
