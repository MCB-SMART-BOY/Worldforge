# 04 · 任务路由与资料索引

> 本页是专项技能与参考资料目录，不提供统一命令行或 slash command。任务闭环见[操作工作流](11_操作工作流.md)；新章写作流程见[章节流水线](01_流水线.md)。

## 专项技能

按任务选择技能；需要时可组合多个技能。技能步骤、输入和输出格式以各自的 `SKILL.md` 为准。当前 harness 不支持自动发现技能时，直接打开对应文件并按其中流程执行。

| 任务 | 技能 | 常见输入 | 交付物 |
|---|---|---|---|
| 审校单章因果、正典、动机、连续性或表达 | [`review-chapter`](../skills/review-chapter/SKILL.md) | 正文路径与审阅重点 | 有文本证据的审阅意见及修改建议 |
| 复核指定章节范围或整卷 | [`audit-volume`](../skills/audit-volume/SKILL.md) | 卷名、范围、审计目标 | 按范围组织的发现、证据、优先级与未决项 |
| 核对设定、工程事实或信息边界 | [`check-canon`](../skills/check-canon/SKILL.md) | 新增或修改的内容及相关来源 | 一致、冲突、假说、未知与不适用项 |
| 核对跨卷承接和本卷自足性 | [`check-cross-volume`](../skills/check-cross-volume/SKILL.md) | 目标章节、引用事件及相关卷材料 | 信息边界、证据状态和读者理解缺口 |
| 设计新章或重排章纲 | [`design-chapter`](../skills/design-chapter/SKILL.md) | 卷、章、叙事任务与工程主题 | 可供写作的章节设计 |
| 规划或重构场景 | [`craft-scene`](../skills/craft-scene/SKILL.md) | 场景目标、人物与前后情境 | 场景行动、信息揭示、选择和情感节拍 |
| 创建或补充人物资料 | [`gen-character`](../skills/gen-character/SKILL.md) | 人物职责、现有正文及设定 | 与任务范围相称的人物卡或补充材料 |
| 制作世界/卷入口或阅读指南 | [`gen-entry`](../skills/gen-entry/SKILL.md) | 目标读者、入口类型和现行索引 | 读者入口材料；正式正文另走章节流程 |
| 制作章节实践单 | [`gen-practice`](../skills/gen-practice/SKILL.md) | 已完成正文、学习目标与读者水平 | 与正文内容对应的实践单或反思题 |

## 不依赖专项技能的任务

| 任务 | 操作入口 | 需要核对的结果 |
|---|---|---|
| 写新章或实质改写 | [章节流水线](01_流水线.md) | 证据、章纲、正文、前后衔接与适用质量门 |
| 更新进度 | [操作工作流](11_操作工作流.md)与实时审校账本 | 状态定义见[状态机](02_状态机.md)；只记录已核实的范围、待决项和续接点 |
| 检查跨卷锚点或系列结构 | [集成验证](09_集成验证.md) | 当前正文、索引和锚点账本相互一致，未知仍标未知 |
| 新增或维护卷、技能、模板、共享规则及路径 | [运维手册](10_运维手册.md) | 修复实际受影响的索引和引用，明确历史材料效力 |
| 恢复未完成会话 | [会话协议](06_会话协议.md) | 从实时记录与当前文件确定续接点 |
| 并行分工或跨代理交接 | [多代理协作与交接](12_多代理协作与交接.md) | 范围互斥、证据可查、主审完成整合 |

## 资料定位

| 需要查找 | 资料位置 | 使用边界 |
|---|---|---|
| 正式阅读顺序和稿件类别 | 各卷根目录 `00_正文索引.md`（若存在） | 索引未覆盖时结合正文和实时账本核实，不从文件名推断 |
| 世界规则、人物谱系、术语和系列锚点 | [canon 索引](../canon/README.md) | 按主题读取；历史蓝图和人物解释不能替代正文证据 |
| 当前章纲、人物卡和研究资料 | `.agents/workspace/<卷>/` 下对应分区 | 工作材料不自动证明事件已写入正文 |
| 全项目审校状态和续接位置 | [实时审校账本](../workspace/正文全卷审校进度.md) | 历史报告只描述其记录时点 |
| 阅读指南、世界入门和练习 | [配套材料索引](../supplements/00_配套索引.md) | 不裁定正文顺序；模板存在不表示必须产出 |
| 架构、实施和审计档案 | [维护记录索引](../docs/README.md) | 有日期和范围，不替代现行规则或动态状态 |

第一阶段四卷的具体设定文件位于 `.agents/canon/09_驭器卷设定细化.md` 至 `12_明契卷设定细化.md`。其他卷按其现行索引、对应 canon 和实时账本定位；四卷旧蓝图只供追溯主题，不推定全系列章序或映射。

## 维护本页

新增或调整技能时，先修改对应技能文件，再更新上表。只有任务路由或资料职责变化时才修改本页；流程细节留在相应 workflow 文件，避免在目录中复制第二套步骤。链接与目录发生变化后，按[运维手册](10_运维手册.md)核对活动引用；归档文档中的旧路径保留时，应明确其历史性质。
