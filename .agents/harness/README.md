# Harness 手册索引

本目录提供 Codex、Omarchy OMP、DeepSeek Harness 可共用的流程说明，不是运行时插件。开始任务读[操作工作流](11_操作工作流.md)；理解资料职责与证据来源读[架构总图](00_架构总图.md)。

| 文件 | 用途 |
|---|---|
| [00 · 架构总图](00_架构总图.md) | 资料职责、证据来源与工作流关系 |
| [01 · 流水线](01_流水线.md) | 新章或实质改写的准备、设计、写作和审阅阶段 |
| [02 · 状态机](02_状态机.md) | 章纲、正文、人物卡和资料的状态定义 |
| [03 · 质量门](03_质量门.md) | 按任务和风险适用的复核标准 |
| [04 · 任务路由与资料索引](04_命令中心.md) | 专项技能、任务产出与参考资料的详细映射；不是命令行入口 |
| [05 · 模板注册表](05_模板注册表.md) | 可复用模板及其定义位置 |
| [06 · 会话协议](06_会话协议.md) | 从实时记录恢复未完成任务 |
| [07 · 历史进度面板归档](07_进度面板.md) | 指向维护档案中的旧快照；当前进度见[实时审校账本](../workspace/正文全卷审校进度.md) |
| [08 · 自动化](08_自动化.md) | 未部署的检查示例、依赖与 hook 边界 |
| [09 · 集成验证](09_集成验证.md) | 跨卷事件和系列锚点的验证参考 |
| [10 · 运维手册](10_运维手册.md) | 资料新增、规则变更、结构迁移与恢复 |
| [11 · 操作工作流](11_操作工作流.md) | 总任务闭环与常用任务入口 |
| [12 · 多代理协作与交接](12_多代理协作与交接.md) | 并行分工、统一验收和跨会话交接 |

按任务选择专项方法和资料时查[任务路由与资料索引](04_命令中心.md)。技能发现和调用方式由运行环境决定；共享手册只约定稳定的技能 ID 与文件路径。当前状态以实时审校账本为准，历史快照不代表现状。
