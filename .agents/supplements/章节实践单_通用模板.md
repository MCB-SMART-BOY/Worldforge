# 章节实践单 · 通用模板

> 用于任意卷的教学练习草稿。使用前核对卷内索引、章纲与正文，并按 canon 中现行的术语标注规则执行；模板问题不应被当成正文事实。

## 第[章号]章 · [标题]

### 使用范围与来源

- 所属卷：
- 旧稿编号（如适用）：
- 现行目标章/范围：
- 映射依据与核验日期：
- 正文核验范围：未核 / 已核（索引、章纲、正文）：
- 案例性质：正文事实 / 教学虚构 / 历史草稿 / 待核假说

> 若属历史稿或虚构案例，需说明哪些细节不可回写为正典；练习者的现实项目结果也不属于小说设定。

### 二、四蚀判断

本章结算了哪一种四蚀？如何判断？

- [ ] 失式（结构崩塌）
- [ ] 乱流（运行时失控）
- [ ] 背契（承诺被打破）
- [ ] 断史（信息被切断）

**判断依据**：[从正文中引用具体的场景或对白]

### 三、三问自检

1. 🩻 本章在结算哪一种四蚀？
2. 😣 代价落在谁身上？
3. 🛤️ 后来者是否比之前更有路可走？

### 五、叙事练习

选择一个场景，用"如果X不存在/如果X不同"的假设重述。例如：
- 如果观测面板不存在,凌晨的故障排查会变成什么样？
- 如果桥谱系没有建立,那条最老的wrapper会在什么时候被谁发现？

### 七、实践任务

1. 对照术语 canon 核查本章需要说明的中文工程术语及英文原名
2. 用一句"前提声明"格式总结本章的核心工程判断
3. 如果本章有一个角色做了"当时对但后来可能不够"的决定——它是谁？什么决定？在什么前提下成立？
