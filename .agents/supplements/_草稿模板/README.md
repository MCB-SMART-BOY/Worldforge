# 历史实践单草稿与样本

> 本目录保留早期实践单草稿。目录名和文件名里的章号来自旧设计，不表示目标正文尚未写；文件也不因正文已存在而自动成为现行配套。使用前对照正式正文索引（若不完整，则再对照工作区章纲和正文）、实时账本与 canon 核实映射。

## 格式说明

这些样本曾采用五段结构：

1. **工程概念清单** — 术语和必要的解释。
2. **四蚀判断** — 相关问题及正文证据。
3. **三问自检** — 🩻 蚀、😣 代价、🛤️ 后来者的路。
4. **叙事练习** — 从工程视角重述场景。
5. **跨卷追踪** — 核对跨卷引用和信息边界。

该结构是旧样本的组织方式，不要求新实践单机械复制。

## 使用方式

这些草稿不应仅因“目标章节已完成”就移动或升级。先逐条核验映射、故事映照和教学任务，再标记为已审、改写后采用或继续留作历史样本；同步更新对应卷的配套索引。未证事实只能作为待核假说或明确标注的虚构练习情境。
