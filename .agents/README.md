# Agent 资料与工作流

根目录的 [`README.md`](../README.md) 是读者和项目总览入口；根 [`AGENTS.md`](../AGENTS.md) 是各 harness 共用的约束与任务路由。本目录只管理 agent 使用的详细资料。内容按需读取，不要求每次会话加载全部文件。

## 资料地图

| 目录 | 保存什么 | 效力与使用方式 |
|---|---|---|
| [`canon/`](canon/README.md) | 世界事实、系列结构、术语及写作规则 | 写作和审校的设定依据；具体事实仍须与正文证据核对 |
| [`harness/`](harness/README.md) | 工作流、状态、质量门、会话恢复、多代理协作和维护指南 | 定义任务如何组织和验收，不取代专项技能或正典 |
| [`skills/`](skills/) | 单项审阅、设计和生成方法；每项位于 `<skill-id>/SKILL.md` | 按任务选择。共享文件使用通用步骤和相对路径；发现与调用方式由当前 harness 决定 |
| [`workspace/`](workspace/00_工作区说明.md) | 人物、章纲、研究、正文设计、审校记录和实时账本 | 提供项目证据与当前工作上下文；章纲不等于已发生的正文事实 |
| [`supplements/`](supplements/00_配套索引.md) | 世界入门、阅读指南、实践单和教学配套 | 面向读者或练习者的材料，不裁定正文顺序 |
| [`docs/`](docs/README.md) | 架构与工作流的规格、计划、审计和覆盖记录 | 项目维护档案；审计有范围和日期，不自动成为正典或实时状态 |
| [`legacy/`](legacy/README.md) | 迁移前的 Claude 专属文件和旧架构说明 | 只读历史档案，不是任何活动 harness 的指令 |

正文和卷内稿件位于仓库根目录的卷文件夹；读者入口与卷目概览见根 `README.md`。本页只负责 agent 资料导航。正文顺序和稿件类别以目标卷的 `00_正文索引.md`（若有）为准；索引覆盖不全时结合正文与实时账本核实。

## 执行入口

1. 先读根 `AGENTS.md`，确认共享规则、证据优先级与当前状态来源。
2. 从 [`harness/11_操作工作流.md`](harness/11_操作工作流.md) 进入任务；需要恢复上次会话时再读 [`harness/06_会话协议.md`](harness/06_会话协议.md)。
3. 依任务范围读取卷索引、相关正文、canon 和 workspace 材料；按需使用对应 `.agents/skills/<skill-id>/SKILL.md`。
4. 修改后按 [`harness/03_质量门.md`](harness/03_质量门.md) 复核适用项，回读受影响内容，并更新确有变化的索引或实时账本。

Codex、Omarchy OMP 和 DeepSeek Harness 共用规则、设定、流程和技能正文；启动、技能发现与多代理接口由各运行环境适配。九项技能的代码围栏均为模板或示例，没有可提取的可执行脚本；自动化示例集中在 [`harness/08_自动化.md`](harness/08_自动化.md)，尚未部署。只有机械步骤稳定、跨卷可用且调用入口与维护责任明确时，才新增共享工具。

## 维护边界

- 新增、迁移或重命名资料时，修复相关索引和链接，并注明其效力；旧资料只作追溯，不复制为当前规则。
