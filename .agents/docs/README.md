# 项目维护记录

本目录保存项目结构与工作流的设计、实施记录和审计证据。这里的内容有日期和范围，适合追溯当时的判断；不替代现行项目规则、故事正典、正文索引或动态审校状态。

## 资料导航

| 路径 | 内容 | 使用边界 |
|---|---|---|
| [`superpowers/specs/`](superpowers/specs/) | 结构与工作流设计稿 | 已实施设计留作决策依据；现行规则以根 `AGENTS.md` 和 `.agents/` 活动指引为准 |
| [`superpowers/plans/`](superpowers/plans/) | 对应实施步骤与完成记录 | 已完成计划是历史执行记录；未完成项须先核对当前工作区再续做 |
| [`audits/`](audits/) | canon、harness、skills、supplements、workspace 与正文审读报告及覆盖清单 | 报告和覆盖表记录各自审计时点与范围；不替代当前正文索引、canon 或实时审校账本 |
