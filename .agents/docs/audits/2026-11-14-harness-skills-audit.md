## P0：术语规则与 canon15 / canon24 冲突

canon15 第 70–76 行、canon24 第 7、15、900–902 行明确要求：中文工程术语在**每章首次引入**时标注英文原名；连续语境明确复指可省略；换章、语义歧义或可能混淆时重新标注；已有 English 列不重复标注。英文术语直接出现时不另注，文学别称和隐喻不强制标原名。

多份活动规则却写成“每次出现都标注”，会让作者与 agent 按技能执行时违反现行 canon：

- `.agents/harness/03_质量门.md:131`：W17 要求“每个中文…术语每次出现时注了英文原名”。
- `.agents/skills/check-canon/SKILL.md:56–62`：标题和首项均要求每次出现；同一段又正确允许英文词与文学别称不标，内部标准不一致。
- `.agents/skills/design-chapter/SKILL.md:59,214`：正文要求每次标注，Gotcha 再强调一次。
- `.agents/skills/craft-scene/SKILL.md:114`、`.agents/skills/review-chapter/SKILL.md:95`：重复出现同一“每次出现”要求。
- `.agents/harness/08_自动化.md:37–65,172–215`：术语示例以整章“至少有一次带括号”为通过，且脚本不会判断首次引入、语境复指或跨章重引；它只能作粗糙候选提示，不能执行成质量门。

建议将所有活动文案统一为 canon15/24 的首次引入与必要重标规则；08 中两个检测样例应明确为非裁决性候选提示，避免“至少出现一次”漏报后续新义项，或对可省略复指误报。
