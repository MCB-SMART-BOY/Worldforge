本审计逐篇阅读全文，覆盖 `.agents/supplements/` 下 **113 份 Markdown 文件**，没有抽样。对照根 `AGENTS.md`、`check-canon`、`gen-entry`、`gen-practice` 技能，以及四卷正文索引（明契卷根索引仅列Ch01–30，存在明显缺项）、各卷章纲旧→新映射、`.agents/workspace/正文全卷审校进度.md` 和 `.agents/canon/26_全系列叙事架构与锚点账本.md`。此处“可信”评价的是文件能否作为**当前事实来源/读者指引**，不等于评价其文字或练习设计好坏。未逐段核对每份旧情节与120章正文，明确将其结论记作“待正文回读”，不会把主题相似当成正史映射证据。

## 总结裁定

- 现行可直接作为入口的主要是根级总索引、通用模板与部分工程概念速查；读者入门文、卷级里程碑和章节实践单混有旧章规划、现行目标与未经回核的场景，当前不能整体当作正典或正式阅读地图。
- 01–03卷的十五章材料均为旧结构来源。各卷章纲已有明确旧→新主题映射；练习单里的故事情节是否迁移/保留仍要对照正式正文，特别是同主题拆章与桥/值守状态变更。
- 明契卷旧30章配套也不是现行120章顺序。另有更上游的索引缺口：根目录 `04_明契卷/00_正文索引.md` 只列序章及Ch01–30；章纲索引声明120章、物理目录有134个编号章节稿，审校账本计135篇含序章。故明契正文入口索引本身不完整，当前映射只能查工作区章纲旧→新表并逐章核正文。章纲明确映射到新章位（例如旧Ch13→正式Ch32，旧Ch15→正式Ch41，旧Ch29→正式Ch101，旧Ch30→正式Ch111）。现存30份练习的文件号不能用作正式章号。
- 多份配套材料把教学建议写成无例外的工程判据（固定限时、固定数额、必删桥、普遍三层规则等），或将戏剧中的人物结论推广为真实团队规范。应改成“本练习示例/可调整判据”，保留适用前提、风险、失败条件。
- 草稿模板目录和分卷索引之间存在现实文件漏列；“未写”状态表与已有正式正文冲突，必须先修状态/映射再供调用。

## 需要优先修复的跨文件问题

1. **明契卷正文索引缺项。** 根目录索引只列至Ch30，与章纲索引120章、物理稿件数量和审校账本不一致。应补全Ch31–120及正式附篇/来源稿边界；完成前，明契实践单目标章引用须由章纲索引和正文双重核验。
2. **旧章号显式映射。** 每份来源练习头部应同时写“旧稿主题编号”和“正式目标章（若章纲明确）”，并说明所据索引版本；涉及一对多映射的练习必须拆分目标，不能让同一份实践单假定一章承载全部旧场景。
3. **配套索引完整性。** 化形、简阵卷目录当前漏列实际存在的旧Ch11–15实践单；草稿 README 的状态列表也需逐项核准。
4. **情节证据边界。** 教学案例中的姓名、具体事故次数、日期、代码路径、人物动机应注明“正式正文事实 / 旧稿设想 / 练习虚构情境 / 未证假说”。任何相似旧记录不得被解释为共同作者、信念或机制，遵循 canon26 的 A2–A4 未证规则。
5. **将通则降为示例。** 对“所有新模块必须满足X”“只有三层规则”“必须删至少一桥”等建议注明项目条件、可逆步骤、回滚/审批边界。练习若涉及删除或生产操作，要优先给模拟/副本路径。
6. **入口与范围。** 《阅读指南_全系列》目前主体为第一阶段四卷；应改标题/范围或真正补齐八卷，同时将章节粒度、正式顺序和状态统一链接到根 README 与卷内索引。
7. **教学反照剧情的创作机会（供主审决定，不在本次写入正文）：**
   - 为跨卷练习设计一张“证据卡”：练习只给本卷角色/读者当时可见的日志、文档缺口和代价，空白处写“本材料不能证明什么”。后卷以新证据重读同一字段，形成回响，但避免要求读者预知后卷。
   - 让练习产物成为轻量伏笔载体，例如被忽略的“最后核验人/适用环境/未知调用方”字段，在早期仅表现为正常表单空栏；后续因一场事故揭示它保护了什么。回收时补出可见证据，不靠神秘句子泄谜。
   - 建立“同一工程对象、不同责任视角”的递进练习：早期读者画出对象关系，中期必须为未经证实的边标状态，后期继承者决定是否保留/退场。每份练习可独立完成，并在末尾放“前一卷留给我的一条待验证线索”，使练习记录同时映照角色选择，而非复述正文情节。
   - 所有虚构案例数据与小说正史明确分层：读者真实项目结果不回写世界观；小说内练习样本使用统一标签，未来在正文中回收时由实际章节提供佐证。
