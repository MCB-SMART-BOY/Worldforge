# 明契卷 · 第43章 · 顾迁衡的桥

顾迁衡从化形卷和简阵卷而来，是渡桥人，负责记录兼容桥从建立、延期到退场的生命周期；他不替各世界决定内部架构。青炉的旧构建脚本仍被少数调用方使用，他翻开桥账。

"第一座桥——旧构建脚本到青炉 build 模块。桥名：build-shim。预计退场：六个月。退场条件：旧构建脚本全部迁移到青炉。六个月后——我会来检查——退场日期到了——桥拆了没有。如果还没拆——我会标注退场延期、理由、新日期。桥的退场不是自动的——是需要人推动的。"

这不是完美的接口，而是一段有明确范围的兼容层：让旧脚本在迁移期间仍能调用青炉的新 build 模块。桥账还要写明负责人、依赖方、验收条件和复查日期；到期只会触发复查，不会自动拆除。迁移完成并验证调用方切换后，桥才进入退场归档。

沈见微看着那一栏"六个月后复查"，问："若到时还有人没迁完呢？"

"就记下谁还在用、卡在哪里，再定新的日期。"顾迁衡合上桥账，"我管的是这段通道从建立到退场的过程，不替他们决定何时改内部架构。"

桥不是一个人的债务。依赖者要迁移，维护者要验收，渡桥人则得在期限到了以后回来问一句：这座桥还能不能拆？
