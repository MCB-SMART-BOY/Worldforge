# 明契卷 · 第71章 · 器成可试

北岭二号守门房的偏灯下，段迟舟照着新补的帮助纸，把 `qinglu doctor` 连跑了三遍。

第一遍，他用常走的新样本。石镜给出结论，连“旧桥已被围起”都写得明白。第二遍，他换上那块错版夜发后留下的老窗样本。结果仍然稳，可他盯着屏幕看了很久，还是说不准：这次真是青炉拦住了病，还是哪位老手早先在这台机器里留下了手工补丁。

第三遍，他合上帮助纸，只按记忆往下走。行至一半，果然又卡住了。

天快亮时，他把三次结果抄在一张短纸上，末尾只写了一句：“若没有你们在场，我怎么判断这次更稳，不是北院自己说自己稳？”

第二天，程知序把这张纸压在一叠使用回报最上头。她没问哪里坏了，只把四张纸摊开：“我不要你们拍胸口说看过。我要不认识你们的人，也能自己看出这次有没有把老病带回来。”

韩砺年在门边沉默片刻，取出一叠旧事故纸。纸上有的只剩半句话——“回滚后旧别名夜里又活”；有的写着“清缓存后不复现，换机再来”；还有几张只提醒“这里千万别改”。那些不是答案，是被人记住、却没被后来者接住的疼。

沈见微没有先让季循改代码。他把纸按病因摊开，让每张旧纸都回答一个问题：若这件事再次发生，什么证据能先一步亮红？

第一组先钉住回滚。旧别名一旦退场，回滚之后也不能悄悄回到主入口。季循写下固定样本，第一次运行时，问心台亮起一道短促的红光：旧输入仍会漏进来。没人需要再凭记忆证明它危险。

第二组把 `doctor`、旧桥和帮助说明接在一起。同一份历史工件若被送进旧桥，屏幕必须同时说清“由旧桥处理”，不能一边走桥，一边让使用者以为走的是核心路径。程知序读完用例，指着预期输出说：“你们内部知道它绕了路，不等于门外的人看得出来。”

第三组由顾迁衡来写。他把桥的前提、异常状态码和失败名称一项项钉住：输入不满足稳定缓冲前提，桥就拒绝进入；旧库返回异常，青炉就报 `LegacyBridgeFailed`，不能把失败装成核心成功。顾迁衡看着那条用例，沉默了一息。渡桥人的经验第一次不再只住在他心里。

最后一组，程知序把维护者的说明纸推开，只留下一个真实样例。“让第一次收窗的人从入口走到结果。要是中间哪一步非得问你们，演练就不算走通。”她照着 `README`、`--help` 和样例走了一遍，把卡住的地方逐一记下。测试不是替文档作证；它让这条使用路径能被重复走出来。

入夜后，四组问心条才一盏盏亮起。旧别名回滚会拦住旧病；入口说明与实际路径不再各说各话；旧桥异常能被叫出名字；北岭收窗人也能从入口走到可解释的结果。

灯稳下来时，韩砺年把剩下的旧事故纸放到长案上。“以前我觉得记住就算守住了。”他说，“现在看，不够。真能接火的，不是我记得，是我不在的时候，这些东西还拦得住人。”

段迟舟收起帮助纸，仍没完全放心。他问：“换一台机器呢？还有哪些前提没试？”

沈见微看向那一排绿灯。它们证明了眼前这些承诺；灯外的路，还没有名字。
