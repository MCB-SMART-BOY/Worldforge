# 明契卷 · 第66章 · 越过边界

依赖更新说明只有两行：新版本改用共享静态缓冲区，解析函数不再保证可重入。

季循把更新前后的实现对照起来。旧版本每次调用各自处理输入；新版本为了减少分配，把中间结果写进同一块静态内存。青炉的安全封装仍允许两个报表线程同时调用。双项样本里，两次调用拿到同一地址，输出出现交叠。

“不是版本号自己把它变危险了。”闻衡看过变更说明后说，“是我们依赖的行为前提变了。”

他们先停用并行路径，在隔离环境复走确认。随后沈见微把锁移到 FFI 调用与复制结果的完整区间，确保任何调用者都不能绕过这层封装。锁外只返回自有的 Rust 缓冲区。并行样本再次通过；评审记录同时注明，这个方案依赖所有访问都经由同一封装。

沈见微划掉旧论证里“可重入”三个字，保留旧版证据，又添上新版本的前提和检查日期。unsafe 并没有忽然变成禁区；过期的是他们曾经相信的那条边界。
