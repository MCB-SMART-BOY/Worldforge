# 万构界设定文件集导览
## 总览与使用说明

本目录收录基础设定、卷级方案、写作约束、历史蓝图与跨卷证据。各文件效力不同，编号不代表正典等级、正文顺序或故事年代；文件分组与完整导航见 [canon README](README.md)。本页只说明如何选择设定材料，不重复列出目录树或项目工作流。

---

## 一、按任务查阅

| 任务 | 首选资料 | 使用边界 |
|---|---|---|
| 理解世界基础规则与对象层级 | `01–05` | 历史记载、解释和假说按各文件标注区分 |
| 查人物谱系及第一阶段卷设定 | `06`、`08–12`、`17` | 卷级设计须与现行正文索引和正文核对 |
| 设计新设定、写作约束或卷名 | `15–16` | 新设定按 `15` 的证据和因果要求处理；工作流见 `.agents/harness/` |
| 核对语言特质与工程术语 | `18`、`24` | 工程事实不以文学类比替代 |
| 核对跨卷事件和系列锚点 | `22`、`26` 及相关正文 | `22` 仅记录第一阶段共享事件；因果与来源仍须看正文证据 |
| 查历史蓝图或未来提案 | `14`、`19`、`23`、`25` | 只作设计参考，不推定现行卷序、章序或已发生事件 |

不必从头通读 canon。先按问题选择文件；遇到正文顺序、稿件类别或当前进度问题，转查目标卷正文索引和[实时审校账本](../workspace/正文全卷审校进度.md)。各卷具体写作约束见[设定扩展与写作铁律](15_设定扩展与写作铁律.md)，本页不另设一套重复规则。

本目录以第一阶段四主卷设定最完整；后续卷资料覆盖度不一，规划材料不等于已定稿或正式立项。读者入口和配套练习见 `.agents/supplements/`，人物、章纲、研究及工作状态见 `.agents/workspace/`。
