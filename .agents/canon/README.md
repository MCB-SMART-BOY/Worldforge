# Canon 导航

本目录保存《万构界》的基础世界设定、卷级设计、术语、写作规则和系列叙事账本。编号用于组织文件，不代表正典等级、正文阅读顺序或情节发生顺序。本目录不维护动态审校状态；请查 `.agents/workspace/正文全卷审校进度.md`。

## 按用途查找

| 范围 | 内容 | 使用边界 |
|---|---|---|
| `00–07` | 总览、四相、对象层级、道统、显世史、共构规则、人物谱系与术语关系 | 基础规则和历史材料的效力需逐文件查看；尤其把史料、解释和假说分开 |
| `08–12` | 第一阶段四卷总览及驭器、化形、简阵、明契卷设定 | 卷级设计须与现行索引和已写正文核对；不自行决定正文映射 |
| `13–18` | 路线记录、早期章纲、写作规则、命名、人物模板和语言主题 | 路线/蓝图/角色命运可能是历史方案；只有明确写明的规则作为现行约束 |
| `19–22` | 教学系列方案、学习目标、配套说明、第一阶段共享事件设计 | 设计参考不是完成状态或已发生事件的证据 |
| `23_四卷120章总蓝图.md` | 第一阶段旧120章蓝图 | 历史设计材料；不能推断现行卷序、章号或正文状态 |
| `23_基座谱系与七基座.md`、`25_第二阶段五卷蓝图.md` | 扩展世界设定与第二阶段提案 | 方案材料；未来卷数、技术映射和事件因果未确认前不得写成既定正典 |
| `24_世界术语-现实工程对照表.md` | 工程术语及中英文对照 | 按 `15` 的正文标注规则使用，避免以机械重复括注损害可读性 |
| `26_全系列叙事架构与锚点账本.md` | 跨卷锚点的证据、解释边界和待决假设 | 当前系列因果审查的关键来源；仍须对照正文和索引，不把提案段落当事实 |

## 使用原则

1. 先按任务读对应文件，不必从头通读整套 canon。
2. 正文顺序与稿件分类以各卷根目录的 `00_正文索引.md` 为准；若索引缺项或与正文冲突，保留差异并标“待核”。
3. 基础法则查 `01–05`，卷级故事查对应卷资料，系列事件查 `26` 及正文证据，工程术语查 `24`，表达约束查 `15`。
4. 蓝图中的旧卷段名和旧章号不是现行编号。任何映射须由对应卷索引、章纲和正文确认。
5. 相似措辞、时间对齐或主题回声不等于共同来源。未证假设必须同时说明证据、替代解释和允许采取的行动。
