# check-canon — 世界观一致性校验

校验新增设定/章节/人物是否破坏已有世界观骨架。
**同时检验两个维度：世界内一致性 + 读者可及性。设定再精妙，如果新读者在第一页就被术语淹没，设定也是失败的。**

## 参数

`content` — 待校验内容（粘贴或文件路径）
`content_type` — `setting` | `chapter` | `character` | `event`

## 校验前：锁定当前语境

通用证据规则、当前状态来源和任务闭环见[操作工作流](../../harness/11_操作工作流.md)。本技能另需核对：

1. 对具体卷章，定位现行卷索引、相关章纲和最新正文；新增设定则查 canon 中相邻概念与规则。
2. 涉及全系列时间线、伏笔或跨卷事件时，以 canon26、现行索引和正文为主；canon22 只供核对第一阶段历史共享事件。
3. canon23 等旧蓝图仅供主题追溯，不决定当前卷序、章序或编号映射。
4. 索引、正文、实时账本或 canon 相互矛盾时，记录各自证据并标“待决”；未确认的映射和设定不作为后续内容的既定事实。

## 校验清单

### 一、检查顶层法则是否扩张

- [ ] 内容是否试图增加新的顶层法则，或改变式/流/契/史的定义？
- 只有触及顶层法则时，才检查它与现有四相的边界并说明新增理由；普通的新术语、物件、制度或角色观点不必强行归入某一相。
- 若作者尚未决定新概念属于世界事实、人物假说还是修辞表达，先标“待决”，不要仅凭无法分类就否定创意。

### 二、必要时定位世界观概念

若内容引入了会影响世界因果或设定关系的新概念，可用以下问题澄清位置；列表是诊断工具，不要求每个专名或叙事细节全部填满：
- [ ] 它归哪一相（式/流/契/史）？
- [ ] 它作用于哪一层级（念/约/图/文/骨/器/阵/门/史）？
- [ ] 它与哪个核心机构相关？
- [ ] 它与旧概念的父子/并列关系是否清晰？

若暂时答不上，记录未知项及其对当前场景的影响；只有因此造成设定冲突或因果不可理解时，才建议重设计。

### 三、检查会影响因果的规则边界

- [ ] 若该概念承担工程规则或推动情节因果，正文是否交代其适用范围、失效方式或可观察后果？
- 不承担规则因果的象征、人物信念或场景意象，不必附加故障模式。
- 四蚀可作为分类视角；除非正文已确立，不把每次失败自动归因于某种世界机制。

### 铁律四：世界观词汇不替换现实术语

扫描内容中是否出现：
- [ ] 用了世界术语替代 Cargo/crate/trait/Result/CI/tracing/service 等现实工程词？
- [ ] 用了世界术语替代 Git/branch/release/deploy/runbook 等操作词？
- [ ] 用了世界术语替代 ownership/borrowing/concurrency/FFI 等概念词？

→ 世界术语只能解释这些词在文明中的位置，不能替换它们本身。

### 铁律四之补充：中文专有名词准确标注英文原名

- [ ] 中文工程术语首次引入时是否标注准确英文原名？连续语境中明确复指可省略；跨章重引、语义变化或可能混淆时重新标注。
- [ ] 格式是否正确？（如"所有权（ownership）"、"健康检查（health check）"）
- [ ] 参考文件 `.agents/canon/24_世界术语-现实工程对照表.md` 中的术语是否被覆盖？
- [ ] 已直接在正文中使用英文原词者（如 `Cargo.toml`、`trait`、`goroutine`）是否不再另注？（正确）
- [ ] 文学别称/诗性隐喻（如"未定之海""债影"）是否自然融入叙事而不强制注原名？（正确）

### 文学表达与工程映射（按理解需要）

- [ ] 如果读者需要理解某个世界观表达的工程含义，文本是否在合适位置给出足够语境？
- 术语映射表供作者保持内部一致；不要求正文逐个标注意象的工程原型。

### 铁律五：工程冲突优先

- [ ] 核心冲突是否来自工程现实（边界失控/依赖失衡/承诺失信/历史断裂/运行失象/债务沉积）？
- [ ] 是否避免了纯粹玄幻对抗？
- 若冲突本质是玄幻 → 重新设计冲突来源

### 铁律六：读者认知负荷检查

- [ ] 新世界观术语是否影响读者定位？数量仅作负荷提示，不设统一配额。
- [ ] 新术语是否在读者需要理解其作用前得到够用语境？不要求固定字数。
- [ ] 陌生术语是否集中到妨碍读者理解场景行动、后果或人物选择？结合本章功能判断，不按连续段落或术语数自动判错。
- [ ] 新读者能否在适当位置辨认场景、视角和当前问题？按文本媒介和章节功能判断，不设固定字数。
- [ ] 是否有连续定义削弱场景推进？结合语境判断，不按句数机械裁定。

### 铁律七：与现有设定的冲突检查

扫描内容是否与以下文件发生实质冲突：
1. `.agents/canon/01_万构界总纲与四相法则.md` — 四相四蚀定义
2. `.agents/canon/02_对象层级_机构_域与宿域.md` — 层级链和机构
3. `.agents/canon/03_诸道总纲_道统名录.md` — 道统体系
4. `.agents/canon/04_诸道显世史与历史地图.md` — 历史顺序
5. `.agents/canon/05_共构机制_工程映射_冲突规则.md` — 冲突规则
6. 卷级设定：先读[四大主卷设定总览](../../canon/08_四大主卷设定总览.md)；第一阶段四主卷的细化文件为[驭器](../../canon/09_驭器卷设定细化.md)、[化形](../../canon/10_化形卷设定细化.md)、[简阵](../../canon/11_简阵卷设定细化.md)、[明契](../../canon/12_明契卷设定细化.md)。其他卷须查对应现行卷设定与索引。

## 事实来源与冲突处理

不同资料负责不同事实，不用一条总排序覆盖所有冲突：

1. **当前章序、事件是否已写、人物当前状态**：以现行卷内索引与实际正文交叉核对；审校进度以实时账本为准。三者不一致时记录差异并标“待决”，不擅自重编号或改写事件。
2. **基础世界规则**：以[万构界总纲与四相法则](../../canon/01_万构界总纲与四相法则.md)、[对象层级与机构](../../canon/02_对象层级_机构_域与宿域.md)、[道统名录](../../canon/03_诸道总纲_道统名录.md)、[显世史](../../canon/04_诸道显世史与历史地图.md)、[共构机制与冲突规则](../../canon/05_共构机制_工程映射_冲突规则.md)为依据，并查相关卷设定。
3. **全系列时间线与跨卷因果**：以[全系列叙事架构与锚点账本](../../canon/26_全系列叙事架构与锚点账本.md)和适用的共享事件资料核对；如其与正文、索引不一致，保留冲突证据并标“待决”。
4. **写作约束与术语**：写作规则见[设定扩展与写作铁律](../../canon/15_设定扩展与写作铁律.md)，工程术语见[世界术语-现实工程对照表](../../canon/24_世界术语-现实工程对照表.md)。它们分别裁定表达规范和术语口径，不替代事实证据。
5. **旧设计材料**：[四卷120章总蓝图](../../canon/23_四卷120章总蓝图.md)、[明契卷早期章级蓝图](../../canon/14_明契卷十卷三十章蓝图.md)及其他旧蓝图只作历史/主题参考，不覆盖现行索引、全系列账本或正文，也不用于推定未映射章号。

## 输出

状态使用“符合 / 有问题 / 待核 / 不适用”等结论，并给出证据；模板项不适用或缺少来源时不得强行判定。

```

| 检查项 | 判定 | 说明 |
|------|------|------|
| 是否改变顶层法则/四相定义 | 符合/有问题/待核/不适用 | 仅在触及顶层法则时填写 |
```

## Gotchas

- **设定完美主义**：为世界观的一致性而牺牲故事的可读性。设定是骨架，不是牢笼。如果一段设定验证完美但读者读起来像说明书，设定仍然需要改写。
- **术语滚雪球**：一个概念的解释需要引用另一个概念，那个概念又需要引用第三个……解药：不是每个世界概念都需要在首次出场时被"完全解释"。够用即可。
