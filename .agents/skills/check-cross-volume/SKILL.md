# check-cross-volume — 跨卷引用检查

检查跨卷引用是否遵守四条铁律，确保每卷可独立阅读。
**同时检查：跨卷引用的入门友好度——一个从别卷进入的读者，会不会在本卷的第一章被"你必须知道"的潜台词劝退。**

## 参数

- `source_volume` — 发起引用的卷
- `target_content` — 被引用的内容（人物/事件/概念/机构）
- `context` — 引用所在的章节和上下文

## 检查前：核对两卷当前状态

通用证据规则、当前状态来源和任务闭环见[操作工作流](../../harness/11_操作工作流.md)。本技能另需核对：

1. 分别定位来源卷和目标卷的现行索引及相关正文，确认事件在两卷中的当前呈现。
2. 用 canon26、相关正文和实时账本核对全系列因果、锚点及待决事项；canon22 只作第一阶段历史共享事件参考。
3. canon23 等旧蓝图不决定当前章序、事件映射或卷间先后。映射未获索引、正文和账本确认时标“待核”，不得以同号章节认定同一事件。

## 四项检查原则

### 一、互文不应成为本卷理解前提

- [ ] 如果读者没读过被引用的卷，本章的核心情节是否仍然成立？
- [ ] 被引用的内容是否是"加分项"而非"必要条件"？
- 若引用是理解核心情节的必要条件 → 在当前卷内补足信息，或调整为不影响理解的可选引用

### 二、共享事件按本卷视角重新呈现

- [ ] 共享事件是否从本卷主角的视角重新呈现？
- [ ] 是否突出了本卷特有的病理视角（而非简单复述原卷内容）？
- [ ] 代价归属是否与本卷的人物和项目绑定？
- 若只是复述 → 重写，确保本卷有自己的视角和代价

### 三、跨卷概念在本卷内给出够用语境

- [ ] 这个跨卷概念是否在本卷首次出现时做了够用解释？
- [ ] 若以中文引入工程术语，是否按 canon15/24 在目标章节首次引入时标英文原名；明确复指可省略，歧义或跨章重引时再标？
- [ ] 解释是否足够让未读别卷的读者理解该概念在本卷中的作用？
- [ ] 解释是否自然嵌入剧情（而非生硬插入一段说明文）？
- 若解释不足 → 补充嵌入式的概念说明

### 四、卷尾接口保留邀请感

- [ ] 卷尾是否出现了"你必须先读某卷才能理解"的表述？
- [ ] 卷尾接口的语气是"邀请"还是"门槛"？
- [ ] 是否用以下措辞暗示读者必须先读别卷？单独出现不构成问题，应结合上下文判断依赖关系。
  - "详见X卷"
  - "如前卷所述"
  - "请先阅读X卷"
  - "在X卷中已经解释过"
- 若措辞设置了阅读门槛 → 补足本卷理解所需信息，或改成不影响本卷理解的可选延伸

## 入门可及性检查

跨卷引用可能增加读者的前置信息负担；按实际引用和章节功能检查：

- [ ] **首章洁净度**：本卷第 1 章中有没有引用其他卷的角色/事件/概念？如果有，数量几何？是否在出场同时给出了足够让新读者不困惑的解释？
- [ ] **跨卷人物首次亮相**：本卷引用的跨卷人物首次出场时，是否像一个"新角色"一样被建立（有独立的出场场景、独立的动机展示），而非像一个"你该知道他是谁"的旧识？
- [ ] **跨卷机构提及**：如果本卷提到了其他卷的机构/项目（青炉/玄枢/息壤/驿河），第一次提及时是否用一句话说清了它和本卷的关系？
- [ ] **情感前置条件**：是否假设读者已经有了对某个人物/事件的"情感预设"？（如"读者应该已经在前卷中关心这个人了"）→ 危险。必须在当前卷内重新建立情感连接。
- [ ] **术语陡增**：跨卷概念叠加是否妨碍读者理解场景？数量只作提示，结合解释、语境和章节功能判断。

## 跨卷人物检查

若引用/出场了跨卷人物，按当前卷索引、正文和全系列锚点账本确认身份与关联；本 skill 不维护封闭人物名单：

- [ ] 人物首次在本卷出场时是否给出了独立的角色建立（不依赖别卷的人物卡）？
- [ ] 人物在本卷中是否展现了新侧面（而非简单复用原卷形象）？
- [ ] 人物在本卷中的行动是否有本卷特有的工程理由？
- [ ] 一个从未读过别卷的读者，是否能在这个人物的首次出场中明白：他是谁、他为什么在这里、他想要什么？

## 跨卷机构/概念检查

若引用了跨卷机构（如青炉、玄枢、息壤、驿河，以及系列中其他已确认的机构）或跨卷概念：

- [ ] 首次提及时是否做了简短但足够的背景介绍？
- [ ] 是否说明了该机构/概念与本卷项目的具体关系？
- [ ] 介绍方式是否适合本场景；若旁白更清楚且不打断叙事，不必强制改成场景展示。

## 共享事件检查

优先对照 `.agents/canon/26_全系列叙事架构与锚点账本.md`、当前卷索引和相关正文。只有涉及第一阶段四主卷的历史共享事件设计时，才把 `.agents/canon/22_第一阶段四卷共享事件表.md` 作为参考；它不是全系列许可清单：

- [ ] 若涉及第一阶段历史事件，当前叙述是否与可核对材料相符？
- [ ] 当前卷是否给出理解本卷情节所需的信息和代价？
- [ ] 是否发现与相关正文、索引或全系列锚点的冲突？如有，记录证据并标待核。

## 输出

按证据填写结论；未发生或无法核实的项目标“待核/不适用”，不要求每个栏目都作通过/失败判定。

```

| 重述带本卷病理 | ✅/❌ | ... |

### 入门可及性
- 首章跨卷引用数：[按需记录；数量只作定位线索，不设门槛]

- 情感前置条件依赖：✅/⚠️/❌
```

## Gotchas

- **跨卷自豪感**：作者因为精心设计了跨卷人物网，所以想让每个读者都"get 到"——在每一卷都塞满对其他卷的引用。但新读者可能把它读成门槛。克制；入口早段尤其应先建立本卷场景与冲突，具体位置按卷内节奏判断。
- **"你该认识他"病**：跨卷人物出场时，作者下意识省略了建立过程——因为你（作者）已经认识他了。解法：每次跨卷人物出场，假装这是你第一次写他。
