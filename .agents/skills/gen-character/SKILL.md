# gen-character — 人物卡生成

按《万构界》人物卡模板生成或补全一张人物卡。
主要人物通常需要明确其工程位置和冲突潜能；配角或局部补卡可只补本次任务所需信息，不为填模板虚构动机。

## 参数

- `volume` — 所属卷；按项目根目录的现行卷目录和对应索引填写，不限于第一阶段四主卷
- `role`（可选）— 角色原型；可参考下方示例或按当前卷和任务补充，不限于表中类型
- `name` — 暂名
- `context`（可选）— 该人物在卷中的位置和已有出场

## 创建前：核对现行卷内事实

通用证据规则、当前状态来源和任务闭环见[操作工作流](../../harness/11_操作工作流.md)。本技能另需核对：

1. 查所属卷的现行索引、相关章纲和最新正文，确认人物既有出场、关系与当前剧情位置。
2. 涉及全系列关系或伏笔时参照 canon26、实时账本及相关正文；canon23 等旧蓝图只供主题追溯。
3. 正文、索引和账本未确认的人物经历或跨卷关系标为“待核”，不从旧蓝图补写成既定事实。

## 核心原则：人物推动选择与关系

一个好人物满足三个条件：
1. **有想要的东西**（欲望）—— 推动行动
2. **有看不到的东西**（盲点）—— 制造错误
3. **有不肯放的东西**（执念）—— 阻碍成长

当欲望、盲点和执念彼此牵制时，人物容易产生内在张力；角色之间的冲突也可来自不同目标、责任或信息边界。这是可用的设计入口，不要求每个角色都同时具备三者或制造冲突。未知内容标记为待核，不补造事实。

## 人物卡参考结构（按人物重要性与任务范围取用）

以下栏目为参考，按本次任务取用；人物尚未确定的经历、关系或动机标“未知/待核”，不得为填卡补造。

### 一、基础信息
- 姓名
- 所属道统
- 所在宿域
- 当前职责
- 所属器/门

### 二、叙事信息
- 角色原型：[如有助于本次设计，从角色原型列表选用]
- 首次出场状态：[有正文时引用具体场景；尚未出场时标计划/待核]
- 与主角表层关系：[师徒/同事/对手/陌路/旧识...]
- 与主角深层冲突：[他们真正在争什么 —— 不是"意见不同"，而是"各自的核心信念无法共存"]

### 三、病理信息（按角色与任务适用性取用）
- 最敏感的文明病灶：[黑箱化/继承失能/断桥潮/门规失效/...]
- 最擅长对抗哪种四蚀（适用时）：[失式/乱流/背契/断史] + 为什么
- 最容易制造哪种四蚀（适用时）：[失式/乱流/背契/断史] + 为什么
- 是否意识到这一点：[是/否/意识到一半] + 说明

### 四、道心信息
- 真正信奉的构世回答：[一句核心信念]
- 最看重什么：[可用关键词或短句概括]
- 最轻视什么：[可用关键词或短句概括；未知时留空/待核]
- 对其他道的最大偏见：[具体对哪一道，偏什么]

### 五、弧线信息
- 初始能力：[会什么]
- 初始盲点：[看不到什么]
- 最大诱惑：[什么会让他偏离自己的道]
- 最大代价：[他可能失去什么]
- 关键转折：[什么事件会改变他的轨迹]
- 与后来者的关系/责任变化（如已写或本次设计需要）：[正文证据、提案或待核；不预设结局]

### 六、语言气质信息
- 说话节奏：[短快/沉缓/绕/直/...]
- 喜欢用什么比喻：[火候/接缝/断口/桥/阵/...]
- 习惯先谈什么：[边界/速度/可行性/代价/...]
- 最常说的一类话：[一句话例句]
- **与谁说话时语气会变**：[什么关系，怎么变 —— 这是揭示隐藏情感的入口]

### 七、关系钩子（按重要关系选用）

| 对象 | 关系性质 | 表层关系 | 可能的张力/互助 | 一句话 |
|------|---------|---------|---------|--------|
| 主角 | ... | ... | 目标、责任或信息边界如何相遇？ | ... |
| 镜像者 | ... | ... | ... | ... |
| 守门者 | ... | ... | ... | ... |
| 继承者 | ... | ... | ... | ... |
| （其他相关角色）| ... | ... | ... | ... |

### 八、卷内作用（适用于重要角色）

记录人物在当前故事中的作用；按人物和任务选择需要填写的方面，不要求每个角色制造困境：
1. [推进剧情的事件]
2. [可能带来的选择、阻力或帮助；尚未确定时标待核]
3. [揭示主题或代价的瞬间]

### 九、一句话收束

**[名字]最难的一课，不是[表面困难]，而是[深层命题]。**

## 输出与写入边界

按人物重要性和任务范围交付完整人物卡或局部补充。对已写事实、设计提案、角色假说和未知信息分别标明证据状态；不适用的栏目可省略，不为填表补造动机或结局。写入角色卡前先查对应卷的现行卷索引并沿用已有目录与命名；没有已确认位置时先提供内容，不另建平行人物库。

## 人物冲突潜力评估（按人物重要性选用）

设计主要角色时可检查：

- **内在冲突**：这个人最想做的事，和他最擅长的事，是否矛盾？（矛盾 = 有戏）
- **人际冲突**：这个人和主角的核心信念在哪一点上不可调和？（不可调和 = 有戏）
- **环境冲突**：这个人的做事方式，和本卷的工程文化，在哪一点上互相排斥？
- **时间冲突**：这个人过去最自豪的成就，是否正在成为他现在最大的包袱？

无法回答的内容先标为未知或待核；是否需要深化取决于人物在本次故事中的作用，不为凑足冲突而虚构动机。

## 角色原型说明

| 原型示例 | 核心功能 | 可能的张力来源 | 第一阶段常见卷（非全集） |
|------|---------|------------|--------|
| 主角（起炉者/接火者/试法者/守阵者） | 面对本卷核心文明命题的人 | 想立新约但旧约的代价是谁来付 | 全部 |
| 镜像者 | 与主角走不同路线但面对同一问题 | 同病不同药——谁的解法代价更小？ | 明契/驭器/化形 |
| 守门者 | 现有秩序的守护者，疲惫但不可缺 | 守护的东西正在腐烂——继续守还是放手？ | 明契/驭器/化形 |
| 审契者 | 校验边界、承诺与规则的人 | 指出所有人的错，但自己也不全对 | 明契/化形 |
| 继承者 | 下一代接火人 | 要接过的东西和要扔掉的东西分不清 | 全部 |
| 同门者 | 邻道的同行者 | 不同的工具文化在同一问题上的碰撞 | 明契/化形 |
| 使用者 | 承受工程决策后果的日常用户 | 不是决策者，却付最大的代价 | 明契/化形 |
| 渡桥人 | 负责迁移、兼容层和弃用路径 | 桥是临时的，但拆桥的日期永远在推迟 | 明契/化形 |
| 诱惑者 | 短期绩效压力代表 | "先这样，回头再整理"——他说得没错，但他说的"回头"永远不会来 | 明契/化形 |
| 失传者 | 已退场但遗留仍在影响当下 | 人不在了，但留下的决策还在咬人 | 明契/化形 |
| 观象者 | 建立可见性体系的人 | 看见一切，但看见不等于能修 | 驭器/简阵 |

## 不同卷的人物偏好

> 以下四卷人物偏好是第一阶段设计材料，不代表全系列卷序或章数。为既有角色补写时，以现行卷索引、正文和全系列账本核实其经历及出场位置；旧蓝图仅作主题参考。

### 驭器卷（C++·玄枢）
- 人物在"古与旧、重与秘"的张力中行动
- 冲突常表现为：古器威能 vs 继承失能，宗匠知识 vs 公共文档，工具链蛮荒 vs 制度建立
- 关键词：敬畏、解释权、接火、考古层
- 典型内部冲突：**"我花了十五年才学会的东西，怎么可能一纸文档就传下去"**
- 独有人物原型：观象者（建立观测体系的人）、失传者（永久缺席的传奇宗匠）

### 化形卷（Python·息壤）
- 人物在"快与乱、试法与沼泽"的张力中行动
- 冲突常表现为：个人效率 vs 团队债务，快乐 vs 复现，动态自由 vs 类型约束
- 关键词：速度、遗迹、分层、包管理
- 典型内部冲突：**"上次这么做省了一天，这次这么做省了一周——我为什么要改"**

### 简阵卷（Go·驿河）
- 人物在"扩域与可知、个人与制度"的张力中行动
- 冲突常表现为：快速接入 vs 共同理解，英雄值班 vs 制度保障，简洁 vs 隐藏复杂度
- 关键词：可知、平台、共同维护、简洁哲学
- 典型内部冲突：**"凌晨两点总是我接的——是我放不下，还是制度让我放不下"**

### 明契卷（Rust·青炉）
- 人物在"边界与承诺"的张力中行动
- 冲突常表现为：写清 vs 口传，立约 vs 灵活，显式 vs 隐式，工具完备 vs "然后呢？"
- 关键词：边界、责任、可解释、工具完备与判断余地
- 典型内部冲突：**"我知道应该写清楚，但写清楚意味着承认我之前的模糊是错的"**

## 跨卷人物规则

若该人物可能跨卷出场：
1. 在目标卷首次出场时，给出理解本场所需的角色信息（不假设读者已读别卷）
2. 在不同卷中可以暴露不同侧面，但核心信念不能自相矛盾
3. 跨卷出场时，必须在本卷有独立的动机（不只是"从别卷走过来"）
4. 全系列关系与事件优先查 `.agents/canon/26_全系列叙事架构与锚点账本.md`、现行卷索引和正文；canon22 仅作第一阶段历史共享事件参考，不是全系列人物关系网或许可清单。

## Gotchas（常见人物设计错误）

- **工程功能化**：人物变成了某个工程概念的"讲解员"——他存在的唯一理由是在第X章向主角解释Y概念。解药：给这个人物一个和教学任务无关的执念。
- **成长缺少依据**：若人物经历了重要转变，检查转变是否有选择、代价或新责任支撑；不要求每条弧线都以痛苦、失去或关系破裂表现。
- **全员理性**：所有人物都用分析性语言说话，没人真正愤怒、恐惧、或羞耻。情感不只是"情绪渲染"，它是角色判断力的组成部分——恐惧让人短视，羞耻让人隐藏，愤怒让人鲁莽。
