# 驭器卷 · 第83章 · template · howto · reference

钟守玄的 runbook 写到第七页——内容在增长——但——结构——是平的。

诊断步骤——旁边——是——历史典故。历史典故——旁边——是——配置说明。配置说明——下面——是——一条——三十年前——崔工——留下的——"等新版本出来就删"——的注释——被钟守玄——顺手——写在——诊断步骤——的——空白处——作为——背景。背景——旁边——是——一条——"此步骤——需要——同时——看——三个——指标"——然后——是一长段——关于——硬盘——型号——的——回忆——那个硬盘——在——十年前——已经——被替换了。

所有的东西——都在——一个人——的——脑子里——按——大脑——自己的——关联——方式——组织——是——按——时间——按——联系——按——情感——按——"那次断火——我想起来了——那个硬盘——噪音——不对——先听——再——敲——命令——"——的——那种——组织——在——脑子里——是对的——因为——大脑——可以——在——关联——之间——跳跃——不需要——结构——但——落在纸上——对于——一个新来的人——是——迷宫。

"内容——是对的。"陆踏痕指着第七页。"但是——如果我是新人——第一天——拿到这个——我会——不知道该——先看——哪里。——每一段——都是——重要的——但——不同——的——阶段——需要——不同的——东西。——第一天——需要——'这是什么——怎么——开始'——不是——'十二年前——北岭——有一个——硬盘——坏了——我们——发现——是——因为——wrapper——的——浮点数——被截断了——然后——当时——没有——观测——所以——追了——三天——在凌晨。——从那以后——我每次——听到——散热塔——转速——变化——就——去——看——这个——指标。'——这段话——是——宝藏——但不应该——放在——新人——第一页——的——诊断步骤——里——应该——放在——'为什么——这样——设计'——的——深度层——让——已经——入门——的人——在——需要——理解——深层——逻辑——的时候——去——读。"

"需要——分层。——后来者——不是——一上来——就能——消化——三十年的——经验。——他们需要——先——走——然后——跑——然后——在——跑累的时候——停下来——读——为什么——这条路——是这样——修的。——分层——不是——把——内容——砍掉——是——让——不同的人——在不同的阶段——能找到——适合自己的——入口。"

· · ·

纪承钧拿出一张新纸，画了四个横着的格子，又在纸边补了一行：“模板是可复用的空表，不是一类读者指南。”

第一格——"入门教程——从一个可完成的小任务带新人走一遍。先让他知道系统是什么、第一步怎么做，以及在哪里求助。不是浓缩全部规则，而是让第一次值夜的人在一条安全路径上完成操作。遇到具体维护任务，再转去 how-to。"

第二格——"how-to——完成一件具体工作：怎么追一条迹，怎么跑一次 `perf`，怎么设置告警。每篇都要说明前提、步骤、验证结果和不适用的情况；如果步骤不适用，告诉读者去哪里找替代方案。"

第三格——"reference——可查的事实：命令参数、配置项、接口字段、错误码和支持范围。读者遇到具体字段时可以直接查，不必从头读故事。"

第四格——"解释文档——回答为什么这样设计：事故背景、约束、取舍和历史条件。比如十二年前硬盘故障的故事，应放在这里；它帮助读者理解规则，但不代替reference里的参数定义，也不该挡在新人第一步前面。"

四种内容不是必须排成先后等级。读者按眼前的问题进入：第一次学习看教程，要完成任务看how-to，要查具体事实看reference，要理解设计缘由看解释。模板可以为其中任何一种提供可复用结构，但不能替代内容分类。

"好的结构让后来者按自己的问题进入，不必一口气吞下所有东西。钟师的脑子曾是唯一的索引；现在，读者可以直接去找操作步骤、定义或缘由。经验没有被删，只是从入口处让开，等读者需要时再出现。"

· · ·

傍晚。钟守玄看着陆踏痕重排的七页runbook。内容没有删，只是分进四种用途：先学会一项任务，再按需查步骤、定义或缘由。顺序不再跟着他的记忆走，而是跟着读者的问题走。

"我以前按自己的记忆写，现在按后来者眼前的问题排。第一眼若先撞上十二年前的硬盘故事，他不知道那和此刻要做的事有什么关系，也就不会往下读。故事没有变轻，只是放到了读者能用上的位置。"

"这不是内容变正确了，是它更容易被正确地找到。结构决定读者从哪里进入，也决定他会不会继续读。我花了三十几年才想到后来者的第一眼；你重排这些页不是否定我，是把我想留下的东西放到了他们够得着的地方。"

守门者 runbook 仍在补充。钥匙从一页长到七页，内容没有变多，入口却更清楚了：读者可以从教程开始，转向操作、查阅或解释；找不到答案时，文档也会告诉他该问谁。
