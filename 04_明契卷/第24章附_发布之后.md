# 明契卷 · 第24章附 · 发布之后，crate之外的承诺

青炉的第一个命令器包发布到公共注册表那天，沈见微在发布说明的最后加了一段话——不是技术更新，是给所有从公共注册表安装青炉的人。这个包只提供二进制入口，不开放 `qinglu-core` 作为库依赖：

"通过 `cargo install` 从源码构建青炉，需要当前稳定版 Rust 工具链；更早工具链不在本次支持范围内。若使用我们提供的预编译二进制，则无需安装 Rust 工具链。此即发布前提声明。不是免责——是告诉你：在什么条件下，我刚才写的那一堆'它能做什么'是真的。"

闻衡审核这段话时，把“语言演进会暂停承诺”的句子划掉，改成：“若未来的 Rust 工具链不再满足本包的构建前提，青炉将通过新版本更新支持范围，并在变更日志中说明影响；既有版本的承诺不会因此自动失效。”
