# 明契卷 · 第67章 · 法宝传世

第一次 crate 发布——`qinglu-core` v0.1.0 到 crates.io。不是正式版本——是预览。但即使是 0.1，也需要 changelog。

"Changelog 不是记录'我做了什么'——是记录'使用者需要知道什么'。新增了什么功能，修复了什么 bug，哪些 API 变了（即使只是不兼容的调整），哪些已经被标记为弃用。不是给你自己的备忘录——是给使用者的信号。他们在凌晨打开 changelog 想知道——'我的代码还能跑吗，需要迁移吗。'"

Rust 的 `cargo doc` 会把源码里的文档注释渲染成 API 文档，但注释本身仍要有人维护。架构决策、迁移指南、弃用声明——这些也不会由机器替你补齐。Version 号的每一段都有语义承诺——MAJOR 表示不兼容变更，MINOR 表示兼容的新功能，PATCH 表示兼容的修复。不是标签——是消息。
