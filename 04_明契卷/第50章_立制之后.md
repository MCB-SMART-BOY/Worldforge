# 明契卷 · 第50章 · 立制之后

Trait把类型能力写成承诺，顾迁衡把第一座桥的退场日期记进桥账，闻衡也开始逐项审查对外接口。门规初稿贴上记录板：对外发布的公共 API 变更要经过审契。

但沈见微看着门规的第一行——心里知道制度立起来了，但制度本身会不会成为新的黑箱？

"闻衡的尺是好的——但如果闻衡不在，谁来执尺？门规是好的——但如果门规被当成不可更改，它就成了新的不可理解的旧脚本。制度也需要自省，也要承认规则可能不完整。立制不是终点；前提变了，后来者就该回来重看。"

闻衡在门规第一行加了一句话——这是审契者对自己的审查。"此门规由闻衡与青炉同门起草——基于截至目前的事故与评审教训，仍可能不完整。每次版本修订须留下提出者、理由和生效范围；条件变化时重新评估。"

门规立起后，沈见微把草案交给众人评阅。第一轮review里，苏野平在“谁来维护这些规则”旁画了一个问号；没有共同修订记录，再周全的制度也可能只留在一个人的脑中。
