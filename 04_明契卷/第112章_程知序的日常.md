# 明契卷 · 第112章 · 程知序的日常

程知序的日常——上午打开青炉，跑了一遍测试，全绿。升级了一个 crate 版本，changelog 里列出的 breaking change 都带了迁移指南。这次没有意外。她在季循的 PR 下面加了确认——不是报 bug，而是确认这次升级没有断裂。

从卷一到现在——从凌晨翻源码找权限问题、到 changelog 没写 breaking change 导致编译失败——青炉的变更正在变得更可预期。不是系统完美了——是断裂的方式从不可见变成了可追查。对于已知的破坏性变更，会附声明、迁移指南、弃用窗口期和回滚路径；没能预先发现的部分，也有 issue 和事故记录可循。"不是不会炸——是炸之前尽量把变化告诉你，炸之后告诉你去哪查，炸完把这次的断裂补进前提声明。"

日常不是无聊——日常是制度最崇高的证明。以前的不正常变成了现在的正常。不是某一天的奇迹——是每一天的安静。
