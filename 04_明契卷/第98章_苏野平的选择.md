# 明契卷 · 第98章 · 苏野平的选择

苏野平在青炉的 workspace 里留下了他最后的脚本——不再是三百行无文档的临时工具，而是一个带前提声明和退场期限的 Python 桥接模块。它只为仍在使用的旧 Python 依赖扫描已知安全漏洞，不判断一般兼容性。"这是临时的——登记日起六个月内退场；如果青炉 CI 提前接入等效的漏洞扫描步骤，就提前拆桥。我仍然用 Python——因为我跑得快。但我现在搭桥的时候——在桥账上写清用途、边界和到期时间——让后来的渡桥人知道该来找谁。"

他不放弃快。快是他的道。但在"先跑通"的同时，他给脚本加了一行标注——这个模块在什么前提下成立、什么时候到期、谁在维护。快不必反慢——只需在速度快的同时让后来者跟得上速度的方向。化形之道的快没有被他丢弃——他把声明写在了脚本旁边。
