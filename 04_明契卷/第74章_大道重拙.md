# 明契卷 · 第74章 · 大道重拙

苏野平写了一周 Rust 之后说了一句话。"你们的语言——太重了。每改一行——要改十个地方——类型、trait bound、生命周期——我写 Python 的时候——改了就跑——跑不了再改——三分钟。在 Rust——三十分钟——还在编译。"

"编译时间长——但 Rust 编译器能在编译期指出一部分类型和内存安全问题。Python 三分钟'改了就跑'——但你在凌晨追的那个 bug 是因为传了 None 给一个标注不完整的函数——那个 bug 排查花了三个时辰。三分钟和三十分钟——不止是时间的差异——是时间在不同阶段的分配。Python 的时间可能花在前面的编写和后面的排查，Rust 会把更多时间花在前面的类型检查和编译；运行时行为仍然要靠测试、观测和排查。"

"重——不一定是拙。拙——是编译器的钳制似乎让你慢下来，但它在每次编译中替后来者检查一部分约束。你写的 trait bound 是给调用者看的——它告诉他这个函数要求什么能力。你写的生命周期是给维护者看的——它告诉他这个引用关系必须满足什么条件。你的重——是后来者的轻。后来者少一类需要靠猜或靠运行时才发现的问题——但边界之外的行为仍要由人验证。"
