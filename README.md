# 万构界 / Worldforge

《万构界》是一部以工程文明为底层的中文长篇系列，借编程语言与工程制度讲述复杂性、时间、协作、债务与传承，并追问：后来者能否沿着前人留下的路继续走。

这里的“道”对应编程语言，“器”对应软件与工程系统。结构、运行、契约与历史共同支撑世界秩序；当它们失守，技术事故就会成为人物必须承担的现实代价。

## 阅读入口

- **第一次进入**：先读[00 入界卷](00_入界卷/00_正文索引.md)，再从[驭器卷第一章《重器不眠》](01_驭器卷/第01章_重器不眠.md)进入正篇。00 卷按读者理解路径编排，不是古代前传或统一时间线。
- **快速查世界设定**：读[《万构界是什么》](.agents/supplements/世界入门_万构界是什么.md)。
- **查看阅读建议**：读[《第一阶段四主卷阅读指南》](.agents/supplements/阅读指南_全系列.md)。它是第一阶段的建议，不代表全系列只有四卷。
- **进入某一卷**：先看该卷的 `00_正文索引.md`（若有）。索引缺项或映射未明时，结合正文、工作区资料和实时审校账本核对，不凭文件名推断正式章序。

00 入界卷是非编年的读者序卷，不计入八卷正篇，也不构成世界内的年代事件。下表展示系列构成；各卷阅读顺序以本卷正文索引为准。

## 故事的方向

工程问题先落到具体的人与选择上，再由后果显出它的意义。人物的成长不是获得更大的力量，而是接过更多责任；留下的记录也不是永恒正确的地图，而是后来者可以检验、修订并继续前行的路标。

**前提可能不成立，但方向仍值得交给后来者。**
