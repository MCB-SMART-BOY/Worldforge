# 万构界 / Worldforge

一个在写的小说系列。关于编程语言、工程文明、和"后来者还有没有路可走"。

---

## 先读这个（30秒入境）

这个世界不是由魔法驱动的。是由**工程文明**驱动的。

这里的"道"不是修仙门派，是编程语言。这里的"器"不是法宝，是软件项目。这里的人用 Rust 写契约、用 C++ 守古核、用 Python 点火试法、用 Go 管服务阵。

这个世界有四条最基本的法则——**式、流、契、史**。每条法则崩了，会长成一种病——**失式、乱流、背契、断史**。故事里所有的大事故，追到底都是这四种病在发作。

这里最大的反派不是魔王。是一句话：**"先这样，回头再整理。"**

这里最高的成就不是战力突破。是：**后来者不用你在场，也能沿着路走下去。**

好了。现在你可以进正文了。

---

## 这是什么

一句话：**把 Rust / C++ / Python / Go 写成四卷奇幻小说。**

但不是"教程换皮"。每个世界有自己的道、自己的病理、自己的人物。读者跟着剧情走，自然会撞上所有权、FFI 边界、依赖地狱、on-call 翻车——只不过它们在这里叫别的东西。

四卷的顺序是：

1. **明契卷**（Rust）—— 从一场发版事故开始，学怎么写清楚边界和承诺
2. **驭器卷**（C++）—— 一座跑了十几年的古器核心，和它不敢退休的守门人
3. **化形卷**（Python）—— "我这边能跑"的快乐，和它留下的脚本沼泽
4. **简阵卷**（Go）—— 五十一个服务，二十三个人，凌晨两点传讯牌谁来接

合起来是：**见病 → 追根 → 反照 → 结账**。

## 不只是小说

除了正文，还有两套东西：

- **设定总集**（`设定总集/`）—— 世界观、四相法则、基座谱系、人物原型。写给自己看的，用来确保不会写到后面忘了前面。
- **卷外配套**（`卷外配套/`）—— 每章的实践单、里程碑表、术语索引。如果你真用这本书学编程的话。

但这两个文件夹都不是必读。只想看故事——只看 `主卷/` 就行。

## 如果你也想写

每写一章我都会问自己三件事：

1. 这章在结算哪一种四蚀（失式/乱流/背契/断史）？
2. 代价落在谁身上了？
3. 后来者有没有比之前更有路可走？

三条里答不上至少两条——这一章大概率还没接上这个世界的核。
