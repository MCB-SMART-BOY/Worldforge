# 万构界 / Worldforge

> 一个在写的小说系列。关于编程语言、工程文明、和"后来者还有没有路可走"。

---

## 👁️ 先读这个（30秒）

> **这个世界不是由魔法驱动的。是由工程文明驱动的。**

- "道"不是修仙门派 → 是**编程语言**
- "器"不是法宝 → 是**软件项目**
- 这里的人用 **Rust** 写契约、用 **C++** 守古核、用 **Python** 点火试法、用 **Go** 管服务阵

这个世界有四条法则——**式 · 流 · 契 · 史**。每条崩了，长成一种病——**失式 · 乱流 · 背契 · 断史**。

> 🦠 故事里所有的大事故，追到底都是这四种病在发作。

> 👹 最大的反派不是魔王。是一句话：**"先这样，回头再整理。"**

> 🏆 最高的成就不是战力突破。是：**后来者不用你在场，也能沿着路走下去。**

好了。现在你可以进正文了。

---

## 📚 这是什么

**把 Rust / C++ / Python / Go 写成四卷奇幻小说。**

不是"教程换皮"。每个世界有自己的道、自己的病理、自己的人物。读者跟着剧情走，自然会撞上所有权、FFI 边界、依赖地狱、on-call 翻车——只不过它们在这里叫别的东西。

| # | 卷 | 语言 | 一句话 |
|---|---|---|---|
| 1 | **明契卷** | Rust | 从一场发版事故开始，学怎么写清楚边界和承诺 |
| 2 | **驭器卷** | C++ | 一座跑了十几年的古器核心，和它不敢退休的守门人 |
| 3 | **化形卷** | Python | "我这边能跑"的快乐，和它留下的脚本沼泽 |
| 4 | **简阵卷** | Go | 五十一个服务，二十三个人，凌晨两点传讯牌谁来接 |

> 四卷合起来：**见病 → 追根 → 反照 → 结账**

## ✍️ 写给自己看的三条

每写一章都问：

1. 🩻 这章在结算哪一种**四蚀**？
2. 😣 代价落在**谁**身上了？
3. 🛤️ 后来者有没有比之前**更有路可走**？

> 三条里答不上至少两条——这一章大概率还没接上这个世界的核。
