# 万构界 / Worldforge

一个在写的小说系列。关于编程语言、工程文明、和"后来者还有没有路可走"。

---

## 这是什么

一句话：**把 Rust / C++ / Python / Go 写成四卷奇幻小说。**

但不是"教程换皮"。每个世界有自己的道、自己的病理、自己的人物。读者跟着剧情走，自然会撞上所有权、FFI 边界、依赖地狱、on-call 翻车——只不过它们在这里叫别的东西。

四卷的顺序是：

1. **明契卷**（Rust）—— 从一场发版事故开始，学怎么写清楚边界和承诺
2. **驭器卷**（C++）—— 一座跑了十几年的古器核心，和它不敢退休的守门人
3. **化形卷**（Python）—— "我这边能跑"的快乐，和它留下的脚本沼泽
4. **简阵卷**（Go）—— 五十一个服务，二十三个人，凌晨两点传讯牌谁来接

合起来是：**见病 → 追根 → 反照 → 结账**。

## 这个世界的核心

万构界不是"魔法系统"驱动的世界。它是**工程文明**驱动的。

一切判断落在四个东西上：

- **式**（结构）—— 骨架还在不在
- **流**（运行）—— 资源还在不在该在的地方
- **契**（承诺）—— 说好的事还算不算
- **史**（继承）—— 后来的人还能不能看懂

这四个东西崩了，分别长成四种病：

失式、乱流、背契、断史。

合起来就是这个世界里最危险的一句话：**"先这样，回头再整理。"**

所以这书里的成长不是战力升级。是从"我能修"到"别人也能修"，从"我记住了"到"我写下来了"，从"反正我在"到"我不在也行"。

## 如果你也想写

每写一章我都会问自己三件事：

1. 这章在结算哪一种四蚀（失式/乱流/背契/断史）？
2. 代价落在谁身上了？
3. 后来者有没有比之前更有路可走？

三条里答不上至少两条——这一章大概率还没接上这个世界的核。
