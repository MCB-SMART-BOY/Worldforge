## 👁️ 先读这个（30秒）

> **这个世界不是由魔法驱动的。是由工程文明驱动的。**

- "道"不是修仙门派 → 是**编程语言**
- "器"不是法宝 → 是**软件项目**
- 这里的人用 **C++** 守古核、用 **Python** 点火试法、用 **Go** 管服务阵、用 **Rust** 写契约

这个世界有四条法则——**式（structure）· 流（runtime）· 契（contract）· 史（history）**。每条崩了，长成一种病——**失式 · 乱流 · 背契 · 断史**。

> 🦠 故事里所有的大事故，追到底都是这四种病在发作。

> 👹 最大的反派不是魔王。是一句话：**"先这样，回头再整理。"**

> 🏆 最高的成就不是战力突破。是：**后来者不用你在场，也能沿着路走下去。**

## 🛠️ 项目结构

- `正文/` — 唯一的读者面。480章，四卷×120章
- `.claude/` — 内部工具。设定(canon)、教学(supplements)、工作区(workspace)、技能(skills)、工程流(harness)
- `CLAUDE.md` — 完整的写作铁律、世界观规则、当前状态

## 📋 写作规则

1. 先工程，后修辞
2. 一切设定都要可失守
3. 成长写成责任升级，不是战力升级
4. 中文工程术语每次出现必须注英文原名（如"所有权（ownership）"）

完整规则见 `CLAUDE.md` 和 `.claude/canon/15_设定扩展与写作铁律.md`。
