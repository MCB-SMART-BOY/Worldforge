# 化形卷 · 第69章 · 火种之后

林过川遗迹的第一轮清理告一段落。

十二个火种迁入了固核层——有了文档、测试、MRC，每个模块的`__init__.py`里有林过川的名字。废土归档了——两千多个文件在`xirang-archive/`里，每份旁边标注了为什么不能迁。骨殖留在原处——标注了"待判断"，等待后来的考古者。

"火种之后——不是遗迹消失了。是遗迹被分类了。有用的被抬上来——林过川的信号码解析、数据清洗、日报表生成。没用的被归档作为参考——依赖已关闭的API的管道、格式已过期的报表脚本。不确定的留给后来者——标注了'待判断'，标注了为什么不知道。林过川的沉默不再是一面墙。它被翻译成了一堆文件。每个文件都说：这是林过川做的东西。它的价值在这里。它的局限在这里。它的前提在这里。后来的考古者——你们不需要重新挖。我们挖过了。我们把坑标出来了。"

清理遗迹只是漫长重建的一部分。三层息壤的边界需要守界者，入世层的 API 契约需要验证，桥的治理也要制度化。接下来，他们还得把分层、固核和慢火一项项落到日常运行里。

林过川的笔记留在了公共记录板上，与驭器卷钟守玄的"前提可能不成立"、旧石镜中三代遗迹的记录并排。周栖野没有把它们写成同一种信仰，只在林过川笔记旁回应："我知道你为什么选择留白。理解你的动机，不等于原谅这份空白让后来者承担的负担。前提声明给后来者入口，同时不替他们判断。我会接住火种，也会把入口补上。"
