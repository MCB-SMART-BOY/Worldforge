# 化形卷 · 第68章 · 空白不是偷懒

林过川的笔记公开之后，周栖野把它和其他几样东西并排放在公共记录板上。

左边——旧石镜里三段代码遗迹的记录。shell脚本留下了“处理未安装 pip 的情形”这一 TODO；林过川的 README 记下工具依赖的 Python 版本在下一代息壤不兼容；C 工具的注释则说它依赖的内部 API 已废弃，关键函数无法完成。三份材料写下的停步原因不同。周栖野把其中相似的记录缺口概括成“后来者应该自己判断”；这句话是他的归纳，不是三位作者共同留下的原文。

中间——林过川的笔记。"我宁愿留下空白。让他们自己走进来。"

右边——从驭器卷传回来的抄片：`INHERITANCE COVENANT — PENDING RATIFICATION`。另一份材料记录了钟守玄的十六条私有维护命令：其中四条能找到已有说明，另外十二条的来源和条件仍有空白。他曾说："我怕写下来成为真理。"

不同世界、不同语言、不同时代。周栖野把这些材料并排比较，看到它们都留下了需要后来者判断的空缺；但现有记录不足以证明它们出于同一种信仰或同一种恐惧。

周栖野把林过川笔记中这类选择称为守缺者信仰（`deliberate-non-documentation`）。笔记写出了林过川的理由：他担心整理好的答案会限制后来者。旧石镜与驭器卷残码的动机则尚未得到同样的证实，不能仅凭相似的空缺归为一类。就林过川这份笔记而言，留白有善意的一面——不替后来者决定答案；它也有盲区——后来者可能没有同等的时间和能力来补入口。

但代价落在谁身上？季晚禾的三个时辰，白又新的两天，纪承钧在玄枢花的整卷考古。这些记录显示，补入口的成本落在一线操作者身上；至于每位留下空白的人是否预见或接受了这种代价，现有材料没有交代。

周栖野在记录板上写下自己的结论："把入口和答案混为一谈，会让后来者连从哪里开始都不知道。林过川这份笔记让我看到这一点；钟守玄和旧石镜材料是否也出于同样选择，仍待核实。给入口是告诉后来者从哪里开始，不替他们走到终点。入口不是枷锁——是路标，写着'这里开始'。"
