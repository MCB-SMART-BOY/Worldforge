# 简阵卷 · 第69章 · 温故来 512MB

傅远洲沿着此前查到的记录，追到了温故来的名字。三年前，驿河只有十一个服务；服务接入模板v1里的默认内存值是512MB，维护者一栏写着温故来。

配置文件只留了数字。部署记录能确认它在当时投入使用，服务也一直按这个值运行；可傅远洲在配置、版本记录和接入文档里都没找到选择依据。现有材料只够确认温故来维护过这份模板，不能证明是他选定了512MB；当时有多少服务，也不足以解释这个数字为何适用，更不能据此断定他没留下过说明。

这个名字傅远洲见过。在驭器卷的旧石录边缘和息壤的林过川 README 里，都有温故来的痕迹；两处记录的来历、年代，以及它们与修补者的关系，仍待核实。它们让这条线索通向另外两道，却不能替他证明师承。至于驿河的512MB，背后的判断也还没有找到。

“如果我现在说它当年一定合理，只是后来服务变多了——那还是猜。”傅远洲把“已确认”与“待查”分开写：已确认，温故来维护模板，默认值为512MB，驿河当时有十一个服务；待查，选择这个数字的计算依据，以及那份依据是否保存在旧配置之外。

他没有把维护者写成设值者，也没有把“未找到”写成“从未留下”。他请人继续翻旧版部署手册和归档纸页，先找依据，再判断三年间的环境变化怎样改变了这个数字的意义。

在默认值审计规则里，傅远洲先加上一条：“新设默认值必须附带环境前提和选择依据，供后来者复核。”这条规则来自眼前的记录缺口，不是对温故来当年做法的结论。
