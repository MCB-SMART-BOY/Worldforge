# 化形卷 · 第05章 · 脚本林

白又新写下那句"零个可以不经考古直接复用"之后的第二天，叶藏拙把周栖野带到了试法场最角落的架子后面。

那里有一台旧石镜。不是共享目录里那些每天被人点亮又熄灭的机器——这台已经很久没有人碰过了。试法场这个角落很偏，架子的阴影压下来，灰尘的气味是干的，像旧纸和金属混在一起慢慢烧。镜面上积了一层薄灰，电源线被一堆旧文档压在下面。叶藏拙蹲下去把线拉出来时，文档堆上滑下来几页纸——是打印出来的试验纸输出，日期是四年前。纸已经泛黄，边角卷起，但上面的数字还清清楚楚。季度结算。北岭设备集群。收入趋势。这些现在周栖野每天在跑的题目——四年前就有人在跑了。同一个人。同一台机器。

周栖野蹲下去捡那些纸。大部分是打印输出——数字列对齐，行号规整，机器吐出来的东西千篇一律。但有一张不一样。不是打印的。是手写的。笔迹工整，一笔一画都很慢，不像写代码注释时那种潦草——像是一个人在坐下来、放慢速度之后才写的：

> final_v3的依赖版本已锁定。下次更新前请先跑 full test。——林过川

纸的边角也泛黄了，折痕很深，像是被压在什么东西下面很久。上面有日期。日期是他离开前不久。

周栖野盯着那行字。他听过林过川这个名字——不多。息壤最早期的推动者之一，极聪明，极快。四年前离开了，没有人确切知道为什么。在传说里，林过川是一个狂野的点火者——写代码像放火，点完就跑，从来不回头。但这张备忘不是。这张备忘是一个很认真的人写的。一个会在写完代码之后写备忘的人。一个在意依赖版本、在意 full test、在意后来的人会不会跑不通的人。

在这张备忘之前，林过川对周栖野来说只是一个名字和一个传说。现在——第一次——他觉得那个人是真实的。

叶藏拙用袖子抹掉镜面上的灰，按下电源。石镜嗡嗡地响了一阵，亮了。镜面上跳出的不是文件列表，是一整片密密麻麻的文件名，从屏幕顶端一直铺到底端，有些名字长得要翻页才能看完。

"这是林过川留下的。"叶藏拙说。

周栖野没有接话。他手里还攥着那张手写备忘。叶藏拙说的事他听过一些——有人说是累走的，有人说是被别的宿域挖走了。也有人说他只是某一天再也没有来——那天早上共享目录里还多了三个新脚本，标着"final_v2_updated"，修改时间是凌晨两点。之后再也没有新的修改时间。

"看这个。"叶藏拙指着屏幕。

`final_v2_really_final_use_this_one.ipynb`

旁边：`final_v2_really_final_use_this_one_FIXED.ipynb`。再旁边：`final_v3_merged.py`。再旁边：`do_not_delete_working_version.py`。再往下翻：`copy_of_final_v3.py`、`backup_20200115`、`old_version_keep_just_in_case`、`temp_test_delete_later`——那个 `delete_later` 的修改日期是三年前。

"他每次改一版，就复制一份，加一个后缀。"叶藏拙的声音不高，像是在描述一种慢性病。"从来没有删过旧版本。因为这些旧版本里可能藏着某次改动的上下文。也可能只是因为——删文件比复制文件更需要勇气。删错了，整个流程就断了。不删，至少还能跑。至少在自己手里能跑。"

周栖野盯着那片文件名，后背一点点发凉。

然后他看到了那个文件名。

在 `final_v2_really_final_use_this_one.ipynb` 旁边——`new_version_test.py`。

他的手指在石镜边缘上倏地收紧。不是后背发凉那种冷。是手指先于大脑认出了什么东西。`new_version_test.py`——和他在共享目录里上周刚存的某个文件命名一模一样。一个字都不差。

不是他学了林过川。是这种命名方式——不是从一个人传给另一个人的。是环境造成的。当你跑得太快、来不及命名、每次改版都复制一份旧文件——你自然就会这样命名。环境不变，一百个人会写出一百个 `final_v2_really_final`。他和林过川从来没有见过面。但他们在同一片土壤里长出了同一种命名病。

他在共享目录里看到过一模一样的命名模式。他自己的。唐野渡的。`final_v2`、`really_final`、`use_this_one`、`dont_delete`、`new_version`、`new_new_version`。他以为这只是个人习惯——随手命名，懒得整理，反正自己知道哪个是哪个。但叶藏拙给他看的不是个人习惯。是谱系（`lineage`）。是一种会传染的命名病。你跑得快，所以你没时间删。你跑得快，所以你没时间整理。你跑得快，所以每一个版本都留在这里——像地质层一样叠压在一起，等着后来的人来考古。一层一层往下挖，挖到最底——是第一个版本的 `final.py`。它上面的注释还写着："初版，基本功能完成，后续优化待定。"待定了四年。

失式。四蚀在化形侧最典型的形态：边界模糊，结构崩塌，原型沼泽由此而生。不是因为写得不好。是因为写得太快。快到结构还来不及成型就被下一个需求淹没了。快到清理的速度永远追不上生产的速度。快到"回头再整理"变成了一句永远兑现不了的承诺——然后人走了。承诺还留在共享目录里。和那些 `delete_later` 的文件一起。

"他离开之后，"叶藏拙往下翻了一页，"这些文件全部留在这里。没有人知道哪个版本是最终版本。没有人知道哪些还在被外部调用方使用。没有人敢删任何一个。因为删错了——可能整个季度结算流程就断了。可能北岭设备集群的实时监控停了。可能收入趋势分析里有个数字突然消失了而没有人知道为什么。"

"四年了。"

"四年了。"

周栖野在那片文件名的底部看到了一个文件。名字只有三个字母：`README.md`。他打开它。里面只有一段话。字迹不像平时写代码的注释那么潦草——像是专门坐下来、放慢了速度写的。像是他知道自己快要走了。像是在和看不见的后来者说话。

"这些脚本大部分还能跑。但我不确定它们依赖的环境还在不在。不确定外部数据源的格式有没有变。不确定后来的人能不能复现。不确定你用的基座和我用的是不是同一片。我走之前来不及整理。如果有人看到这段话——对不起。"

周栖野看着那行"对不起"。三个字。他想起了驭器卷里卫千枢的那句"后来的人，对不起"。不同的道。不同的器。同一句话。同一种被速度和孤身承担耗尽之后留下的空白。不是不想整理。是没有时间。不是没有时间——是永远有更紧急的事排在"整理"前面。整理不会让面板变绿。整理不会让传讯牌停下来。整理不会让谢催成少拍一张需求单在桌上。然后有一天，人走了。紧急的事也跟着人一起走了——因为那些紧急的事只有那个人能处理。留下来的只有那些从来没有被整理过的文件，和一个写了"对不起"的 README。

周栖野没有站起来。没有立刻说"我要清共享目录"。

他就那么蹲在那台旧石镜前面。很久。叶藏拙站在他身后，没有说话，没有催他。旧石镜的嗡嗡声填满了整个角落——那种低沉、持续的电流声，像是一台机器在替一个已经不在这里的人呼吸。

然后周栖野做了一件事。

他把那份 README 抄了两份。第一份——折好，对折再对折，放进自己石镜后面的夹层里。那个夹层里本来就有几张纸——都是他从来没有给别人看过的东西。有些是他刚来时写废的草稿，有些是他不确定对不对的想法，有些是他怕被人笑所以没拿出来的东西。现在，第一张真正重要的纸放了进去。只有三个字："对不起"。

他后来会在第十一章把林过川叛变的传讯记录也放进去。但现在——这个夹层的第一张纸是一个素未谋面的人写下的三个字。

第二份——他攥在手里，站起来。

"他没有恶意。"叶藏拙说，"他只是——"

"没有时间。"周栖野替他说完了。

"对。但你准备怎么不变成下一个他？"

周栖野没有立刻回答。他蹲在那台旧石镜前，翻着林过川留下的文件名。`final_v2_really_final`。`FIXED`。`do_not_delete`。`temp_delete_later`——三年了，还没删。他在每一个文件名里看到了自己的影子。不是将来的影子。是现在的。是他上周刚存的那几个文件。是他昨天刚加了一个 `new_` 前缀的脚本。是他说"回头再整理"时对自己撒的谎。他在心里默默数了一下自己共享目录里有多少个文件名里带"final"——至少十几个。一个都没有真正 final。

"我要把共享目录清一遍。"他站起来。"不是全删。是给每一个文件标清楚——哪个是当前版本，哪个是旧版本，哪个已经不再被任何人使用。像顾迁舟的桥账一样。每一条路都有搭桥日期和退场日期。每一个文件都有创建日期和废弃日期。"

"你知道那要花多长时间？"

"不知道。"

"你知道这期间外面还会来新的需求单？谢催成今天早上已经拍了三张在长案上。北岭那边又在催。"

"知道。"

叶藏拙看着他。那种看不是质疑——是确认。确认他不是在说大话。确认他不会在第三张需求单拍下来的时候把清理工作推到"回头"。

"清理的过程中你可能会发现——有些东西只有林过川知道怎么改。有些依赖只有林过川知道为什么要那么引。有些文件名只有林过川自己能区分。有些基座差异只有林过川自己在脑子里处理过，从来没有写成文档。"

"那我就写'待问'。"周栖野说。他想起了驭器卷里钟守玄写的"待补"。想起了简阵卷里乔落在手册上写的"此处原因待追溯"。不知道不是罪。假装知道才是。沉默不是中立。沉默是留给后来者的迷宫。

他把林过川的 README 抄的第二份带回试法场，贴在公共记录板的最上面。旁边加了一行自己的字：

"此人是息壤最早的点火者之一。他在四年前写下了和我们今天一模一样的文件名——final_v2、really_final、dont_delete。他不是懒惰。他是被永远做不完的紧急需求和永远没时间的整理工作一起吞掉了。后来者以此为鉴。"

然后在最下面加了一行——字很小，但每一笔都很用力：

> "我不会变成下一个林过川。不是因为我比他强。是因为他留了 README。我看到了。"
