# 《万构界·化形卷》第十四章：慢一步，活得更久

三层息壤正式运转之后的第二周，一次新的紧急需求来袭。北岭设备集群的数据管道出现了一处格式变更，和第一章的情况几乎一模一样。谢催成把需求单拍在桌上时，所有人都看着周栖野。

"这次你怎么做？"

三个时辰的窗口。和第一章一样。新格式，旧流程，中间需要一个翻译层。第一章里周栖野的做法是直接写脚本、跑通、丢进共享目录——从头到尾半个时辰。这次他做了一件所有人都不适应的事：他先在实验田里开了一张新的试验纸，把格式变更的特征、影响范围和临时映射方案全写在了上面。然后他把季晚禾叫来。

"你先看看这张纸能不能看懂。如果看不懂，告诉我哪里需要补。"

季晚禾花了半个时辰看完了。她指了三处需要补充的地方。周栖野一一补上。然后他让白又新在干净环境里跑了一次——不是在他的机器上，是在一台新清空的石镜上，基座配置故意设置成和季晚禾一样的稳流派。

跑通了。

"现在迁进稳定骨。"他把试验纸上的映射逻辑改写成稳定骨的模块格式，加了完整文档，标注了基座兼容性——已验证稳流派和前沿派，承契派待季晚禾下周在企业仓库里验证——然后从 xirang-gate 上开了一个新入口。整个过程花了将近三个时辰。是第一章那次耗时的六倍。

谢催成急得在门口来回走。"三个时辰。上次你只用了半个时辰。"

"上次半个时辰跑通的东西，后来被九个流程引用。其中三个因为环境漂移在两个月后失效。一个因为依赖冲突输出了错误结果。季晚禾用它做了一次错误的管理层汇报——因为她的基座和我不一样，而她不知道。"周栖野把稳定骨里的新模块最后检查了一遍，"这次三个时辰。但这次的东西——两年后还有人能用。不需要我在场。不需要传讯牌。不需要猜。也不需要和我在同一片大地上。"

谢催成不说话了。他看着石镜上那个新模块的入口——干净，文档齐全，输入输出标注清晰，基座声明写了三行。和共享目录里那些只有文件名和一堆便利贴的旧脚本相比，它像一座有门牌号、有地图、有紧急出口——还标注了"本建筑在哪些地基上已验证可以站立"——的屋子。

---

同一天，唐野渡和叶藏拙之间发生了一件事。

唐野渡在实验田里试了一个新想法——用外部 API 实时拉取北岭集群的调用状态，和息壤内部的延迟数据做交叉分析。这个想法如果做成，会比之前所有的诊断图都更快、更直观。他在试验纸上只花了不到一个时辰就拉出了一个能跑的版本。然后他拿着这张试验纸去找叶藏拙。

"帮我看看——如果我想把这个迁进稳定骨，还缺什么？"

叶藏拙看着那张试验纸。上面引了三个外部 API，其中一个来自通界宿域，两个来自简阵宿域。数据源的有效期没有标注。API 的返回格式没有任何文档。更关键的是——这三个 API 背后的服务，可能运行在完全不同的基座上。通界的 API 在永序之台上。简阵的两个服务一个在稳流派上，一个在承契派上。唐野渡的试验纸在前沿派上跑通了——但在其他任何基座上都没有被验证过。

"它缺的东西比能跑的东西多。"叶藏拙说，"缺的不是代码。是基座。你拉通的这三个 API——它们在哪些基座上提供服务？它们的基座差异会不会影响返回格式？如果永序之台上的那个 API 下个月升级了系统版本，你的脚本还能不能认得它的返回格式？"

唐野渡沉默了。他以前从来没有想过这些问题。化形之道教会了他"先让形出来"。但没有教会他"形出来之后，它在哪些大地上能站住"。

"所以我现在需要做什么？"

"第一件事。标注每一个外部 API 的基座。不是'大概在哪个基座上'——是具体的基座流派和版本。第二件事。给每个 API 的返回格式写文档——不是'大概长这样'，是完整的字段列表，包括基座差异可能导致的字段差异。第三件事——"

叶藏拙停了停。

"第三件事。在不同的基座上分别验证。不是只在前沿派上。在季晚禾的稳流派上。在白又新的承契派上。如果有可能——在永序之台上也试试。你不试，后来者就会替你试。他们试的时候会发现跑不通。然后他们会在传讯牌上找你。然后你会发现你已经不在了。"

唐野渡把这些一条一条记下来。然后他在试验纸的最上面写了一行字：本试验纸为实验田产物。目标迁入稳定骨。当前状态——待完成跨基座验证。预计完成日期——两周后。他在日期旁边签了自己的名字。

不是"到时候再改"。是一个具体日期。和一份跨基座的验证清单。

---

傍晚，周栖野和唐野渡站在试法场的窗边。外面天已经暗了。石镜的光映在两人脸上。

"三个月前，"唐野渡说，"我以为化形之道就是快。你也是。我们都在比谁更快——谁先跑通，谁先出图，谁先让别人看见形。"

"现在呢？"

"现在我觉得——化形之道真正的考验不是快。是快完之后，愿不愿意慢下来。慢下来写文档。慢下来标注基座。慢下来告诉后来者——你站的是哪片大地，这片大地有什么前提，如果不匹配该怎么办。"

"慢一步，活得更久。"

"对。"唐野渡看着窗外，"快能救一场火。慢能让火种不被下一场火烧掉。"
