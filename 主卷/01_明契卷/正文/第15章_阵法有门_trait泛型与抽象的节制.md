# 明契卷 · 第十五章 · 阵法有门，trait、泛型与抽象的节制

第十四章刚把总工地立起来，北院小室里的气氛难得松快了半日。

可这种松快，往往最容易把人往另一种坑里送。

· · ·

午后，季循和苏野平守着长案左侧那面石镜，越看越兴奋。

他们不是在修小毛病（bug）。

他们是在看见青炉已经分出 `qinglu-cli`、`qinglu-config`、`qinglu-core` 三块骨以后，忍不住生出一种很诱人的念头：

既然以后还会有新的查病骨、新的试跑骨、甚至新的接窗骨，那不如现在就先立一扇大总门。

凡是以后要进青炉做事的，都从这扇门里过。

苏野平把纸一铺，先写下一句解释：

先把“谁能做哪些事”写成一份共同遵守的行为约定（trait）

又写第二句：

先留一个能换不同对象的位置，让同一套骨架去接不同东西（泛型）

季循盯着这两句，越看越觉得顺。

前几章他们一直在拆。

拆入口，拆配置，拆核心，拆总工地。

可拆到今天，若不再往上收一层，看上去好像就永远只是“三块骨并排摆着”。

他低声说：

“若现在先立一个总约，以后不管查病、试跑、解释、接窗，甚至更后头要外接的小骨（插件），只要照这个约来接，不就整齐了？”

苏野平眼睛一亮。

“对。先做一个大 trait，把能做的几件事都写进去。以后谁要接进来，只要把这张纸填满。”

他说着，已经在石镜上飞快写出一版漂亮得几乎让人舍不得驳的草案：

```rust
trait QingluAction {
    fn check(&self, input: &WindowInput) -> Diagnosis;
    fn explain(&self, diag: &Diagnosis) -> String;
    fn dry_run(&self, input: &WindowInput) -> Preview;
    fn apply(&self, input: &WindowInput) -> ApplyResult;
}
```

季循看着这一版，心口都微微发热。

因为它太像答案了。

一张纸，四件事。

查病、解释、试跑、落动作，全在里面。

连以后怎么接新骨、怎么写新入口，仿佛都一下子有了总门。

他甚至已经顺着往下想到了第二步。

若再做一层泛型（generic），也就是给同一种骨架先留一个可替换的位置，那将来不同的窗口单、不同的输出样式，也都能顺着同一套写法走。

他说：

“是不是还能把执行那层也收掉？像这样，谁守这份约，就都能往同一个跑法里送。”

```rust
fn run_action<A: QingluAction>(action: A, input: &WindowInput) { ... }
```

苏野平听得直点头。

“这才像阵法。以后长什么新骨，都先入这扇门。”

门边的韩砺年本来还在翻旧窗名录，听到这里，手却慢慢停了。

他没先反驳，只是抬头看了那张“大总门”的草案很久。

程知序也走了过来。

她先没看懂那些字，只听懂了一件事。

“也就是说，你们打算让以后所有骨头，都得会这四样？”

“差不多。”苏野平说，“这样最整齐。”

“可有的骨，本来就不会落动作。”程知序说。

“不会就先留空。”苏野平答得很快，“或者写个暂时不做的占位，后面再补。”

这句一出口，闻衡立刻抬起头。

“先留空？”她问。

屋里一下静了半拍。

因为这四个字，正是北院所有旧病最熟的气味之一。

闻衡走到石镜前，没先碰那段草案，而是另外摊开一张纸。

她在纸上只写三行：

有的骨，只负责看病。

有的骨，只负责把病说清。

有的骨，才真正负责落动作。

· · ·

然后她转头看向季循。

“这三种事，真是同一种事吗？”

季循先想说“都是青炉在做的事”。

可话到了嘴边，又停住了。

因为他忽然想起第八章。

那时他们刚学会把“有结果”“有失守”“直接炸开”分开。

如今若为了看上去整齐，反而把“看病”“说病”“治病”一口气糊成同一类，那不就是刚分开的东西，又往回缠了？

闻衡没有等他答，继续往下逼：

“若一条规则根本不会自动落动作，你却让它也填 `apply`。那它最后会写什么？”

苏野平皱眉。

“先写个空的。”

“也就是纸上说它会，真到用时其实不会。”闻衡说。

这一下，连程知序的脸色都沉了。

因为她最怕的，就是这种“看起来什么都有，真问起来全是空位”的假完整。

她说得很直：

“我宁可青炉老实告诉我，这条骨只会查、只会解释，不会替我动手。也不想看到它纸上写着会做，最后却只是给我一个空壳。”

韩砺年终于把旧窗名录合上，低声接了一句：

“旧桥当年就爱这样。十样东西先全挂上，真问到第七样、第八样，就说以后补。补到最后，写在纸上的比真能做的多一倍。”

这话像一盆凉水，把季循胸口那股“越整齐越好”的热意压下去一半。

可另一半还在。

因为那张大总门，确实漂亮。

漂亮到你一眼看去，会以为自己已经替未来十步都铺好了路。

沈见微直到这时才从案尾走过来。

他没先说“这不行”，反而先把那张草案完整看了一遍。

看完以后，他问季循：

“你觉得它最诱人的地方是什么？”

季循沉默片刻，还是照实说了。

“它像一次把未来都收住了。”他说，“现在先把总门立好，后面每长一块骨，好像都知道该怎么接。”

沈见微点头。

“这感觉是真的。”他说，“而且不是错觉。trait 确实就是拿来写行为约定的，泛型也确实就是拿来让同一套骨架能接不同对象的。”

他顿了顿，语气却立刻沉下来。

“可前提是，你先看清，这些对象到底是不是真的在做同一件事。”

他说完，拿过笔，在那张大 trait 草案旁边又写了一句更白的话：

不是长得都像门，就该共用同一把锁

闻衡立刻接上。

“查病骨和落动作骨，看上去都在处理窗口单，可责任根本不是一回事。”

“解释骨和试跑骨，看上去都在对人说话，可它们承诺的东西也不是一回事。”程知序说。

“若现在图省事，把四件事硬塞成一种，后面谁想补一块只会查病的骨，就得先假装自己也会修。”韩砺年说。

这几句一层层压下来，季循终于完全看见那张大总门最危险的地方了。

它不是不能写。

它是写得太早了。

现在的青炉，还没有长到“所有骨头都天然共享同一份职责”的地步。

若此刻先立一个覆盖一切的大 trait，不过是把今天还没分清的责任，提前钉死成一张以后更难拆的硬纸。

苏野平还是不甘心。

“可要是不先收总门，后面不是会越长越散？”

沈见微摇头。

“抽象（abstraction）不是越早越高明。抽象是等你反复看见同一种责任，已经稳到不会轻易改口，才把它收成共门。”

他说着，把那张大草案上四个方法一一划开。

没有把纸扔掉。

而是拆成三张更小的纸。

第一张写：

只负责看病的约（trait）

```rust
trait Diagnose {
    fn diagnose(&self, input: &WindowInput) -> Diagnosis;
}
```

第二张写：

只负责把结果说明白的约（trait）

```rust
trait Explain {
    fn explain(&self, diag: &Diagnosis) -> String;
}
```

第三张写：

只有真能落动作的骨，才去守“落动作”的约（trait）

```rust
trait ApplyFix {
    fn apply(&self, input: &WindowInput) -> ApplyResult;
}
```

季循盯着这三张小纸，心里先是失落，随后却慢慢稳下来。

它们没有刚才那张大总门那么漂亮。

甚至看上去有点笨。

可它们没有撒谎。

会查病的，就只承认自己会查病。

会解释的，就只承认自己会解释。

只有真能动手改的，才承认自己会落动作。

程知序看着那三张纸，明显松了口气。

“这才像青炉。”她说，“能做什么，就只说什么。”

苏野平还盯着那句泛型不放。

“那泛型还能不能用？”

“能。”沈见微说，“但也只在你已经确定‘这一段骨架真的完全一样，只是换了接进来的人或东西’时用。”

他又写了一小段更收敛的草案：

```rust
fn run_diagnose<D: Diagnose>(rule: D, input: &WindowInput) -> Diagnosis {
    rule.diagnose(input)
}
```

然后他在旁边补了一句解释：

同一套跑法不变，只换进来的人不同，这才是泛型该发力的地方

“这里为什么能用？”他问季循。

季循这次没有迟疑太久。

“因为这段跑法真的只有一件事。”他说，“不管接进来的是哪条查病骨，它都只是接一份窗口单，吐一份诊断。骨架没变，只是守这份约的人变了。”

“对。”沈见微说。

“可若你把解释、试跑、落动作全塞进去，表面上像统一了，实际上一半骨头根本不是照同一种骨架在跑。”

闻衡把那张被拆掉的大草案折起来，压进一旁空匣里。

“这张纸别烧。”她说，“留着。”

“为什么？”苏野平问。

“因为它不是错纸。”闻衡说，“它只是来得太早。以后若青炉真长到那一步，再回来看看，它也许会变成另一种更成熟的约。可不是今天。”

这句一出，连苏野平都沉默了。

因为这不是单纯的否。

这是更难的判断：

不是漂亮结构没价值。

而是你得先分清，它是此刻该立的骨，还是此刻最容易让人自我陶醉的幻影。

屋里安静了一阵。

最后，还是季循自己把那三张小 trait 纸往总工地图旁边重新排好。

他排得很慢。

像是在亲手承认一件不太甘心、却越来越清楚的事实。

技术上最诱人的那一版，不一定是此刻最对的一版。

第十五章临收尾时，沈见微在文契第十层补下一句短得不能再短的话：

> 优雅要服从可继承

季循看着那句话，忽然觉得它不只是写给 trait，也不只是写给泛型。

它更像是在写青炉这一整路新火。

不是所有看上去更高、更整齐、更像总答案的东西，都该立刻拿来盖在众人头上。

> 有些抽象，若来得太早，就不是桥。
>
它只是把今天还没长稳的骨，提前封进一层明天更难拆开的壳里。
