# 明契卷 · 第05章 · 一纸丹方，Cargo.toml 里的工程世界

东廊的风还没散尽，北院那间小室里的灯已经换过一轮。

季循原以为，第四章做到这里，接下来总该真正去写青炉的本事了。

可沈见微并没有先让他碰那些新立起来的命文。

他只是把石镜轻轻一转，让镜面停在青炉目录里那张最短的纸上。

`Cargo.toml`

苏野平看了一眼，先笑了。

"就这？"

镜面上的纸干净得过分。

除了 `package` 几行，只剩一片还没落字的空白。没有复杂结构，没有一串串看着就像能立刻救火的旧补丁，也没有贺时进最想看到的那些"先都接上"的应急口子。

"对，就这。"沈见微说。

季循盯着那张纸，有点没回过神。

昨日断史库里那些旧东西，哪一件不比眼前这张纸更像"真有用的东西"。可偏偏从昨夜到现在，闻衡、程知序、沈见微三个人都像在盯一份不能随便下笔的重契。

闻衡把新的记录纸展开，先写下一句：

给项目看的总说明，也是给后来者看的总说明（`Cargo.toml`）

季循低声念了一遍，忽然明白过来。

"这不只是配置。"

"当然不只是。"闻衡说，"配置若只是给眼前这台机子看，它写在哪张纸上都行。可一旦写进 `Cargo.toml`，它就成了青炉自己公开承认的事。"

程知序站在镜边，抬手点了点那张空纸。

"我现在最在意的，反而不是它能不能立刻替我多做一件事。"她说，"我是想看看，这次别人能不能从这一张纸里先看懂青炉要做什么，不做什么。"

贺时进从外头进来得很急，像是刚从别处窗口里被叫过来。

他看见镜面上的 `Cargo.toml`，眉头先皱了一下。

"你们不会真要为这几行东西坐一整晚吧？"

苏野平接话接得飞快。

"他们会。"

韩砺年没笑。他站得离镜面更近一些，像是想看清这张纸到底凭什么让一群人这么上心。

"写吧。"他说，"我也想知道，北院这回准备先把哪几句真话写进去。"

· · ·

沈见微没有立刻落字。

他把镜面往前推了一寸，让所有人都能看清第一段：

```toml
[package]
name = "qinglu"
version = "0.1.0"
edition = "2024"
```

贺时进先开了口。

"`name` 先不说，`version` 为什么是 `0.1.0`？"

"因为它现在就是 `0.1.0`。"沈见微说。

"可窗口不会喜欢这个数。"贺时进盯着那行版本号，"你拿去给外面看，别人第一眼就会觉得这东西还没站稳。"

"它本来就还没站稳。"闻衡说。

贺时进看了她一眼，火气压得并不好。

"可你也不能上来就把心虚写在脸上。"

程知序终于笑了一下，那笑不算客气。

"我宁可它把心虚写在脸上，也不想它把嘴硬写进纸里。"

屋里静了片刻。

因为这话太像卷首那夜的余震。

太多东西就是这样坏掉的: 明明只站住了半步，却先把自己写成能扛十步。

沈见微把手按在那行 `version` 上，声音很平。

"版本号（`version`）不是拿来壮胆的。它是告诉别人，你现在到底把东西做到哪一步了。"

季循抬头问：

"所以 `0.1.0` 的意思，就是它刚起步？"

"对。"沈见微说，"还很小，还只够承诺最少的几件事。写 `1.0.0` 很容易，可一旦写了，别人就有理由按那个分量来要求你。"

闻衡把这句补进记录纸：

版本号（`version`）不是装样子，是公开说明自己做到哪一步

贺时进冷笑了一声。

"行。你们诚实。可窗口出事的时候，别人不会因为你诚实就少催你。"

"别人催，是别人的事。"闻衡说，"我们不能因为怕被催，就先把还没有的东西写成已经有了。"

韩砺年这一次站在了闻衡这边。

"这句我认。"他说，"写大了，后头总得有人拿命补。"

苏野平靠在窗边，轻轻晃着那页早被放下的旧兼容壳标签，像是笑，也像是叹。

"版本写小，你们舒服。可别忘了，别人看一眼就会顺手给自己找旧法。"

"那就只能让青炉做得更真。"程知序说，"不是把版本写大。"

· · ·

争过 `version`，沈见微才把手指移到第一行。

"再看 `name`。"

季循念出那行字：

`name = "qinglu"`

这一次，他比昨天懂得快得多。

"包名（`name`）就是它在项目里的正式名字。"

"也是别人以后在命令、依赖、目录里真正会遇见的名字。"沈见微说，"青炉可以是它的门内名，可写进项目里，就得是一个能稳稳落地、能反复被别人叫到的名字。"

苏野平瞥了一眼。

"倒还算朴素。"

"朴素没坏处。"程知序说，"至少不像在提前吹自己是什么救世大器。"

闻衡没有插话，只在纸上补了第三句：

包名（`name`）不是雅号，是别人真正要反复叫到的正式名字

接着，沈见微点了点最后一行：

`edition = "2024"`

这回轮到季循先问：

"这个又是什么？"

"写法约定用的是哪一代规则（`edition`）。"沈见微说，"不是说你今年才准写，而是说这个项目默认按哪一套 Rust 的写法和习惯来。"

季循愣了愣。

"就像同样一群人修桥，也得先说好按哪一代桥律、哪一套尺法来修？"

"差不多。"沈见微点头，"你不先写明，后来接手的人就会一边照旧习写，一边照新习改。到头来，东西也许还能跑，规矩却已经散了。"

韩砺年听到这里，忽然低低说了一句：

"这像门规。"

"本来就是门规的一部分。"闻衡说。

她落下第四句：

写法约定（`edition`）不是装饰，是先说清大家按哪套规矩一起写

到这里，镜面上还只有三行真正落定的字。

可季循已经感觉到，这张纸的重量并不比昨日那套工具轻。

昨日是在回答"怎么把空机子拉起来"。

今日是在回答"拉起来之后，这东西准备怎样对别人说话"。

· · ·

沈见微没有停，继续往下拉。

镜面露出下一段空白标题：

`[dependencies]`

季循对这个名字有点陌生。

沈见微看出他的神色，先解释了：

"借别人已经写好的东西来帮自己做事，叫依赖（`dependencies`）。它们不是白来的。你一旦写进来，就等于承认青炉要靠它们一起站着。"

程知序接得很快。

"也就是说，写一个依赖，不只是省点力。也是在告诉别人: 青炉有一部分能力，是借了别人的。"

"对。"闻衡说，"所以每一个依赖都该能回答三个问题。为什么非借不可，借来做什么，若它变了或坏了，谁负责跟着改。"

苏野平终于来了精神。

"那不是正好？"他说，"先把该借的都借上。命令行要解析吧，配置要读吧，说明要补吧，旧窗口要接吧。你们现在越写得全，外面越早能用。"

贺时进立刻点头。

"至少得先把旧窗口那边要的兼容口放进去。哪怕先挂着，也比没有强。"

沈见微没有顺着他们走，只问了一句：

"你们说的'先挂着'，是准备让谁来负责？"

贺时进顿了一下。

苏野平笑意淡了点。

"先挂着的意思，就是先别把门关死。"

"那也得知道门后面是什么。"闻衡说。

她把记录纸翻到下一行，像在替所有争执先定边。

依赖（`dependencies`）不是捡现成便宜，是把别人的一部分也写进自己的责任里

沈见微看着那片空白的 `[dependencies]`，竟没有立刻落一行字。

季循忍不住问：

"先空着？"

"对。"沈见微说。

"可不是要做项目吗？"

"要做。"沈见微说，"但不是今天靠多借几样东西，先把自己写得很像个大器。"

程知序听到这里，轻轻出了口气。

她最怕的恰恰是这一点。

好不容易把卷首那夜那种"说明看着什么都有，真出事全靠熟手补"的病撕开一点，结果青炉一立，又迫不及待开始往自己身上挂一串谁也说不清的借力。

"空着也好。"她说，"至少人人看一眼就知道，它现在还没借谁来撑场面。"

贺时进显然不满意。

"你们这叫起炉，还是叫摆样子？"

"叫先不撒谎。"闻衡说。

· · ·

这句话刚落，苏野平已经把另一张纸拍到了镜边。

那张纸上写着几行他刚加出来的东西：

```toml
[features]
default = []
legacy-window = []
fast-rescue = []
```

季循看不懂，目光先落在了 `legacy-window` 和 `fast-rescue` 这两个名字上。

"这是……"

"可选功能开关（`features`）。"沈见微说。

他这句解释刚落，苏野平已经把纸往前推了一点。

"说白了，就是先把以后可能会用到的口子写在这里。默认不开，不代表以后不能开。你们不是最爱讲边界吗？这也是一种边界。先把名字立住，后面真要接旧窗口、真要留快救火口，也不至于重改骨架。"

贺时进立刻接上：

"而且这两个开关真有用。一个能先替旧窗口留位置，一个能在急事上给我们一口快气。你们现在不做，至少也该先写进来。"

镜面前安静了很久。

因为这提议太诱人了。

它不像卷首那夜那样粗糙地让人去走暗门。

它看起来很体面。

写进 `features`，默认又不开，似乎已经算是很克制。

连季循都在那一瞬觉得，这样是不是并不过分。

可闻衡先开了口。

"不行。"

"为什么？"贺时进压着声音，"都写了 `default = []`，又不是现在就让你们必须接。"

"因为你一旦把名字写进去，别人就会以为这件事已经是青炉承认过的能力边界。"闻衡说，"哪怕它今天不开，明日别人也会拿着这张纸来问: 你既然早就写过，为什么还不给？"

程知序盯着那两个名字，看得比谁都冷静。

"而且这两个名字本身就会骗人。"她说，"`legacy-window` 听起来像你们已经知道怎么把旧窗口稳稳接进来。`fast-rescue` 听起来像青炉已经打算负责一类急救场景。可我们现在明明都没做到。"

韩砺年站在一旁，神色复杂得很。

因为他知道，这两个口子在现实里都真有价值。

旧窗口那边不能说断就断。

真到了大火压脸的时候，多一口快气，有时就是能不能先把人拖出线外的区别。

可他同样知道，北院最擅长的，就是把"以后再补"先写成"已经有了个口子"。

这时，沈见微终于伸手，把那两行慢慢划掉。

只留下：

```toml
[features]
default = []
```

苏野平盯着那道划痕，半晌才问：

"你真不要？"

"现在不要。"沈见微说。

"你知道这会挡掉多少现实上的方便。"

"知道。"

"也会挡掉后面好几扇窗口。"

"知道。"

苏野平沉默了一瞬，像是忽然有点恼，又有点无奈。

"你这不是在造器。你是在逼大家先忍着。"

"对。"沈见微说，"青炉第一轮就是要逼大家先忍住那种'名字先写上，东西以后再补'的冲动。"

季循看着镜面上那一片被重新压回空白的地方，忽然明白了这章真正难的地方不在 `Cargo.toml` 的写法。

而在于这张纸会逼人承认:

有些东西不是不能想。

是不能现在就写成自己已经准备负责。

闻衡把最后一句写完：

功能开关（`features`）不是许愿单，是你准备公开负责的可选能力

· · ·

到这里，镜面上的 `Cargo.toml` 已经变得极瘦。

它甚至瘦得有点刺眼。

可程知序看着那份瘦纸，反而第一次真正放松下来。

因为她终于能从头看到尾，而且看完之后，没有哪一行在偷偷骗她。

沈见微把最终留下的内容重新誊了一遍：

```toml
[package]
name = "qinglu"
version = "0.1.0"
edition = "2024"

[dependencies]

[features]
default = []
```

贺时进看完，脸色仍旧不好。

"就这点东西，你们也敢拿去叫项目总说明？"

"敢。"程知序说，"因为它至少把现在有的和现在没有的，都说清了。"

"可它没法帮我过下一个窗口。"

"那是下一章该回答的事。"沈见微说，"不是这一张纸该先替未来撒的谎。"

韩砺年看着镜面，忽然问季循：

"你现在若把这张纸带走，明日换一台机子、换一个像你一样刚进门的人，他能看懂什么？"

季循看着那几行字，想了很久，才慢慢答：

"他会知道青炉叫什么，知道它现在只到 `0.1.0`，知道它按哪一代 Rust 的规矩写，知道它眼下还没借别人的东西来撑场面，也知道它没有偷偷答应额外的口子。"

"还行。"韩砺年低声说。

这句夸得不高，却比空洞的好听话更像真话。

闻衡把整张记录纸收起，只留下最上面一句没有折进去：

> `Cargo.toml` 不是配置杂项，是项目第一次公开说自己准备成为什么。

苏野平看着那句，最后还是笑了。

"行吧。至少这回我骂你们，也知道该骂哪一行。"

贺时进没有笑。

他盯着那片空着的 `[dependencies]` 和被划掉的两个 `features` 名字，半晌才把那口气慢慢压下去。

"我先记着。"他说，"等外头真催起来，你们别拿今日这几句漂亮话躲。"

"今日这几句不是漂亮话。"程知序说，"是欠账单。"

沈见微把镜面轻轻合上，没有再争。

他知道，贺时进说的也不假。

拒绝这两个名字，不会让现实窗口自己消失。

可若今天不拒，青炉从出生那一刻起，就会学会把未来该偿的债，先写成已经备好的药。

灯火在薄石镜上轻轻一晃，照得那张短得近乎寒酸的 `Cargo.toml` 像一张刚起笔的丹方。

> 丹方小得很。可每一味都是真药。而不是看起来什么都能治，实则只会把病继续往后拖的漂亮空方。
