# 明契卷 · 第08章 · 辨药识毒，Option、Result 与错误的正名

北院的天亮得很慢。

雨过以后，空里带着一点潮冷，连薄石镜的边沿都像比平时更凉。

第七章刚把青炉的函数和模块拆出个样子，程知序就把卷首事故附近那批最让人头疼的旧样本又抱了过来。

她把其中两份压到最上面。

"别先庆功。"她说，"你们现在只是让我知道该去哪一间屋里找事。可一旦真出错，青炉究竟会怎么说，还没试过。"

沈见微点了点头。

"就从最接近卷首那夜的样本开始。"

季循看向第一份样本。

那是从旧窗口路径里拆出来的一份旧说明。它有发版对象，有基本版本号，有外侧要看的名字，可最关键的回滚说明却空了一半。另一份则更隐蔽，看着大体齐全，只少了一行给人看的附加标题。

苏野平抱着手臂站在窗边。

"这两份放以前都照样能往外过。"

程知序冷冷看了他一眼。

"所以以前才会出事。"

· · ·

她坐到石镜前，按着青炉新立起来的 `check` 入口，把第一份样本送了进去。

镜面上的字一开始还很稳。

读说明。

建临时目录。

检查字段。

可走到一半，石镜忽然猛地一颤，接着整面亮光像被谁从中间砸断了一截。

最后只剩下一行生硬得刺眼的字：

`thread 'main' panicked at ...`

屋里所有人都静了一瞬。

这不是看起来成功。

可也绝不算看懂了失败。

程知序盯着那行字，脸色一点点沉下去。

"这和以前有什么本质区别？"

没人立刻接。

因为她问得太准。

旧法是把错误吞掉，装作没事。

眼前这一版则是直接当场炸停。

都没把真正的问题说给使用者听。

· · ·

闻衡最先走到镜前，抄下那行 `panicked`，压在长案中间。

"这不是把错误说清了。"她说，"这只是把程序自己的狼狈摔给外面看。"

季循盯着那行字，隐约知道它不对，却还没全懂不对在哪。

"可它至少停下来了。"

"停下来不等于说清。"闻衡说，"使用者现在知道它死了，却还是不知道是缺了什么、错在何处、能不能补、该不该重来。"

沈见微已经把那段出问题的命文调了出来。

问题出在一行极短的旧写法上：

```rust
let rollback_plan = manifest.rollback_plan.unwrap();
```

季循下意识念出最后那个词。

"`unwrap`……"

沈见微没有先讲它的名字，只先讲它干了什么。

"这行的意思很简单。它在赌这里一定有东西。若真有，就直接拿出来。若没有，程序就当场炸停。"

闻衡接得很快。

"这就是错的边界。"

· · ·

她把一张白纸推到季循手边，先写下第一句：

可能有，也可能没有的一格，叫 `Option`

又写下第二句：

要么成功，要么带着原因失败的结果，叫 `Result`

最后才补上第三句：

程序自己已经断了筋、没法体面收场时的当场炸停，叫 `panic`

季循盯着这三句，像突然看见一锅之前一直混在一起的药，终于被分成了三格。

"也就是说，少了附加标题，和少了回滚说明，不该按同一种死法来处理。"

"对。"沈见微说。

他把第二份样本也摊开来，指给众人看。

"这一份缺的是附加标题。它会难看，会少信息，但不至于让整个检查失去意义。它更像'可能有，也可能没有'。"

再指回第一份。

"这一份缺的是回滚说明。青炉若还假装它能过，那就是在替明日再开一次卷首那夜的门。这种情况就不该继续假装成功。"

程知序盯着那两份样本，慢慢点了头。

"所以前者该是 `Option`。"

"后者该是 `Result`。"闻衡说。

"那 `panic` 呢？"季循问。

韩砺年这时忽然开了口。

"`panic` 该留给真正不该发生的断筋。"

他声音不高，却很稳。

"比如你们自己写坏了，明明说好这一步绝不该空，结果到了这里还空；或者内里的状态已经乱到根本没法往下收。这才是程序自己的失守。不是使用者少填了一行字，就该让整面镜子当场砸给人看。"

· · ·

苏野平看着那三句解释纸，仍旧有点不服。

"你们这样分，字会越来越多。以前一行过去的事，现在得写几层意思。"

程知序却第一次没有顺着他的急。

"字多不是坏事。坏的是以前我每回碰到这种情况，都得自己猜系统到底在发哪门子脾气。"

她把那句 `thread 'main' panicked` 抄片往苏野平那边推了推。

"你看这句。它倒是短。可它除了告诉我'青炉炸了'，还告诉了我什么？"

苏野平没立刻答。

因为这句确实什么都没告诉。

沈见微把刚才那段命文重新写了一次。

这次没有 `unwrap`，只留下极简单的分岔：

```rust
let title = manifest.note_title;

let rollback_plan = match manifest.rollback_plan {
    Some(path) => path,
    None => return Err(CheckError::MissingRollbackPlan),
};
```

季循看着那两段差别，第一次觉得 `Option` 和 `Result` 不再只是两个生词。

前一行是:

有就拿来用，没有也不必立刻翻桌。

后一行是:

这里若没有，就不能装作这件事还成立。

闻衡把第四句补到纸上：

可缺可不缺的，留在 `Option`

缺了就不能继续负责的，写成 `Result`

然后她才抬头。

"真正的问题不是程序会不会失败。是失败时，它有没有把名字说出来。"

"名字？"季循重复了一遍。

· · ·

沈见微把另一张小纸翻过来，上面已经写了几行新的错误名：

```rust
enum CheckError {
    MissingRollbackPlan,
    InvalidManifest,
    MissingTarget,
}
```

"这就叫具名错误。"他说，"不是一句模糊的'出错了'，而是把这次到底失守在什么地方，先写成人和程序都能认的名字。"

程知序盯着 `MissingRollbackPlan` 那一行，忽然出了一口很长的气。

"这才像我能拿去跟外面说的话。"

"怎么说？"季循问。

"我可以直接告诉他们: 不是青炉发疯，也不是今晚运气差。是这份说明缺了回滚说明，所以检查不放行。"程知序看着那几个名字，一字一顿，"这叫得出病名。"

闻衡点头。

> "对。错误不是坏运气。错误是被说清的失守。"

苏野平仍旧皱着眉。

"可真到窗口压脸的时候，谁有空看你们这串名字？"

"恰恰是那时候更要看。"韩砺年说。

他把第一份样本重新推回镜前。

"因为最急的时候，人最没空猜。"

这句说完，连苏野平都没再顶。

· · ·

沈见微把新命文压进镜里，示意程知序再跑一次。

这一次，镜面的光没有再突然炸断。

它仍旧一路往下走，只是在走到缺失那一行时，稳稳停住，吐出一段比刚才长得多、也明白得多的字：

`error: 缺少回滚说明（MissingRollbackPlan）`

`check 已中止；请补齐后重试`

屋里静了两息。

程知序盯着那几行字，像是第一次真正看见一个系统在自己面前"讲人话"。

她没有立刻说好，也没有立刻说轻松。

她只是把第二份样本也送了进去。

这一回，青炉没有停。

镜面先吐出一行浅色提醒：

`warning: 缺少附加标题；将按无标题继续`

然后继续往下，把整个检查跑完了。

季循一下就看懂了。

"这就是 `Option`。"

"对。"沈见微说，"它没有装作那一格一定在，也没有因为那一格不在，就把整件事一把掀翻。"

闻衡把最后一句解释补齐：

`panic` 只留给程序自己的断筋，不拿来吓使用者

· · ·

到这一步，长案上的几张纸已经层层叠起。

有资源边界。

有函数和模块。

现在又多了错误的边界。

可屋里没有人觉得这些东西只是越写越繁。

至少程知序不这么觉得。

她低头看着那两次完全不同的结果，眼里第一次没有那种长期和旧系统周旋后留下来的疲惫猜测。

"以前每回出错，我都得先猜它到底是在说'真的不能过'，还是在闹脾气，还是其实已经坏了一半却还装作能走。"她声音很轻，却很实，"现在我终于不用猜系统的脾气了。"

苏野平靠在窗边，沉默了好一阵，才慢慢开口：

"这确实更啰嗦。"

没人接。

他抬起眼，看着那句 `MissingRollbackPlan`，又把后半句补完：

"可也确实更像是在说事。"

这已经很接近让步了。

韩砺年没看他，只把那张写着 `panic` 的解释纸抽出来，单独放到最上面。

> "这个得记牢。北院以前最坏的一种病，就是把本来该说清的失守，装成一种谁也说不明白的暴死。"

季循盯着那张纸，终于把这章最重的一句话压进了自己心里。

原来错误并不是天上掉下来的一团黑气。

它也不是谁今晚手气差。

它是某一层责任没有被完成，某一格该有的东西没有被放进来，某一道承诺到了这里就确实没立住。

而青炉要做的，不是替这件事遮脸。

是先把病名叫出来。

窗外的天色这时终于透出一点更清的白。

雨后残留在檐角的水珠一滴滴落下，正好敲在石阶边缘。

季循望着镜里那句清清楚楚的 `MissingRollbackPlan`，忽然觉得第七章那几间被拆开的"屋子"，到了这一刻才真正住进了灯火。

因为青炉第一次不只是能做事了。

它还能在失手时，告诉别人自己到底失手在什么地方。
