# 明契卷 · 第十七章 · 千里传书，远端仓库与协作秩序

第十六章把青炉的石录立起来以后，北院小室里终于有了“今天改了什么，明天还能回头查”的底气。

可这底气只安稳了两日。

第三日清晨，程知序抱着一摞从外头收回来的问单进门，脸色比平时更沉。

她没先坐下，直接把那摞纸往长案中央一放。

“再这么下去，我就要变成青炉的人肉门房了。”

苏野平本来还在看前一夜的石录，听到这句，先笑了一声。

“你不是一直就在当门房？”

“以前是替北院收窗。”程知序说，“现在是替青炉收问题、传说明、搬改动、再把回话送出去。外头每来一个新问题，都要先绕我一次，再绕你们一次，最后再从我手里绕回去。”

她说着，把最上面三张纸摊开。

第一张，是东侧守门房送来的。

问的是一类旧窗输入，在 `dry-run` 时能看见解释，却找不到完整复现步骤。

第二张，是南廊收窗人抄来的。

问的是某条旧别名规则，究竟从哪一版开始算正式承认。

第三张最短，却也最刺：

“若我只是想提一个问题，不认识你们北院的人，是不是连门都找不到？”

屋里一时安静下来。

因为这张纸直接把第十七章最重的一刀捅了出来。

青炉如今已经有本地石录，有总工地，有公共说明。

可它的入口，仍旧太近。

近到只要离北院远一点，问题就还是只能靠人传人、纸递纸、熟人找熟人。

季循看着那第三张纸，胸口微微一紧。

他忽然意识到，第十六章立起来的，还只是“北院里的人能沿着历史往回查”。

可若想让更远处的人也能问、也能看、也能参与，光在这间小室里把石录写好，还远远不够。

· · ·

贺时进先把最现实的话说了出来。

“那就让外头把纸和改动直接传过来。谁有问题，先把抄片寄到你这；谁改好了，直接把补丁包发来。北院这边看一眼，能用就并进去。”

这话听上去极省事。

程知序却立刻摇了头。

“那只是把传话的人从我一个，变成你们几个轮着当。”

她把三张纸一张张点过去。

“问题还是没有公共入口。改动还是没有公共入口。最后外头的人照样不知道，自己问的那件事到底有没有人接、接到哪一步、是谁在回。”

闻衡这时从案尾走过来，先把程知序那句“公共入口”写在了纸上。

然后她落下第一句解释：

放在远处、让多人都能看到同一份项目与历史的公共仓库，叫远端仓库（remote repository）

季循盯着“远处”二字，下意识问：

“也就是说，不再只是北院这台石镜里有青炉？”

“对。”闻衡说，“本地石录解决的是‘这里有没有史’。远端仓库解决的是‘别处的人能不能看见同一份史’。”

沈见微没有多说，直接把石镜翻到新的空面，写下第一串命令：

```bash
git remote add origin git@qinglu-archive:construct/qinglu.git
git push -u origin main
```

他在旁边补了一句人话：

先给青炉在远处立一座大家都能对上的公共库，再把本地主线推过去

贺时进盯着那两行字，皱了皱眉。

“听上去还是像把东西再多存一份。”

“不是。”闻衡说，“多存一份只是副本。远端仓库是让众人以后讨论、追问、送改动，都先对着同一个地方来。”

她顿了顿，又补了第二句解释：

把本地已经写清的历史送到远端去，叫推送（push）

季循看着那句“同一个地方”，心里忽然明白了为什么第十七章不能只停在本地石录。

若没有远端仓库，北院还是唯一能看见全貌的地方。

石录再清楚，也仍旧只是一间屋里的清楚。

沈见微把主线推上远端以后，石镜另一面很快浮起一份新的总页。

青炉的名字。

公开的 `README`。

最近几笔提交。

上一章刚打上的那枚稳定标签。

还有最要紧的一栏：

还没有人写字的问题区。

程知序看着那片空白，低声问：

“以后外头的问题，就写在这里？”

闻衡点头，写下第三句解释：

把一个问题公开写成能追踪、能补充、能被后来者翻到的问题单，叫 issue（issue）

她又在旁边补了更白的一句：

问题单不是喊一声“这里有事”，而是把现象、影响、复现办法、期待结果写清

这话一落，程知序几乎立刻就把手里第一张问单抽了出来。

“那我先写一张。”

她坐到石镜前，没有再像从前那样只在边角抄一行“外头反映这个不好用”。

她写的是：

标题：`dry-run 缺少完整复现步骤，窗口收单人无法独立重现`

正文下面，又按闻衡刚才那句话，一条条列开：

现象是什么。

是谁遇见的。

哪类旧窗会撞上。

现在卡在哪。

希望青炉最后能给出怎样的说明。

季循站在她身后，看得有点发怔。

因为程知序这一步，已经不再只是“把使用者的抱怨带过来”。

她是在反过来塑青炉的秩序。

不是替谁传话。

而是把外头那团原本只会散在口舌里的不满，压成一张共同体能看、能跟、能接的问题单。

issue 写完以后，贺时进还是忍不住追了一句：

“问题公开了，改动呢？外头真有人顺着这张单改完了，难道还让他把整份目录重新寄来？”

“这就是下一扇门。”沈见微说。

他在石镜上开出一条新分支，把这次要补的 `dry-run` 说明拆到单独一线，然后写下第四句解释：

把你在自己分支上改好的东西，公开提成一张“想并回主线”的请求，叫拉取请求（pull request，PR）

他又补了一句更白的话：

PR 不是把代码扔过来，而是把“我改了什么、为什么改、想并进哪一条主线”一起摆到台面上

苏野平挑了下眉。

“说到底，不还是请求你们北院点头？”

“不是请求北院。”闻衡说，“是请求主线。”

这句话一出来，连季循都愣了一下。

因为他马上就懂了这句话真正要改的是什么。

以前谁想动青炉，先要认识北院的人。

谁想解释自己为什么这么改，也往往只能对某个具体的人解释。

可若有了 PR，这份解释第一次不再只说给沈见微、韩砺年或程知序某一个人听。

它是先对着公共主线说的。

谁都能看。

谁都能沿着这张单追问。

谁都能知道，这笔改动现在卡在什么地方。

贺时进还是不耐。

“可现实窗口不等人。照你们这套，今天能补的东西，明天还卡在门口写纸。”

这正是第十七章最现实的压力。

快一点，直接把改动塞进来，眼前最省事。

可若每一笔改动都只走熟人快路，那所谓远端协作，不过是把“当面递纸”换成了“隔空递纸”。

闻衡没有和他硬顶，只把石镜转向程知序刚刚写好的那张 issue。

“你看这张单。”她说，“以前它会怎样？”

贺时进没答。

因为所有人都知道答案。

以前多半是程知序先来口头说一遍。

若季循在，就季循记。

若季循不在，就先压着。

中间还可能再丢一层、漏一层、少一层。

等改完以后，外头的人甚至未必知道自己当初提的那件事，究竟有没有被完整理解。

“现在至少它先在主线上留下了。”闻衡说，“哪怕今日来不及改，后来的人也能顺着找到它。若有人想接这张单，就沿着这张单开分支、提 PR。整条线都在外头看得见。”

这句话把贺时进顶得沉默了几息。

因为他也看得出，这种慢，不是纯拖。

这是把原先只存在于熟人之间的暗流，第一次翻成了人人看得见的明渠。

沈见微这时看向季循。

“你来提第一张 PR。”

季循心里一紧。

“我？”

“对。”沈见微说，“不是让你独自证明自己写得多好。是让你学会把一笔改动整理成别人不见你也能读下去的样子。”

这正是章纲里早就压着的那一关。

季循前面几章已经会拆骨、会分层、会留史。

可到了第十七章，他第一次要面对另一种更难的要求：

把自己脑子里那条“我知道我改了什么”的直线，翻成别人能顺着看懂的公共链。

他先把 `dry-run` 缺失复现步骤的改动单独摘出来。

没有混进别的修补。

又把第十六章刚学会的提交方式重新用了一遍，只留下和这件事真有关的两笔提交。

第一笔，补说明入口。

第二笔，补现实复现链示例。

做完以后，他才把那条分支推上远端：

```bash
git push -u origin issue-12-dry-run-explain
```

沈见微在旁边补了一句：

不是所有改动都往主线上直接压，先把它放到远端自己的分支上，让别人能看、能问、能接

然后，季循把第一张 PR 正式开了出来。

标题没有故作高深。

就写：

`补 dry-run 复现说明，并把窗口收单示例接入 explain`

下面照着第十六章的习惯，把缘由、改动范围、影响处、一眼能看的验证办法，一条条列开。

程知序站在旁边，忽然轻声说：

“这回就算你不在，我也知道该先看哪里了。”

季循听见这句，心里那点绷着的弦，反而更紧了一下。

因为他第一次真切地感觉到，PR 的难处不是写代码。

而是你得放弃“反正我到时候当面再解释”的侥幸。

你得先把解释权从自己嘴里拿出来，摆到那张公共纸上。

临近傍晚时，远端仓库上终于不再只有一条孤零零的主线。

有公开的问题单。

有对着问题单开的分支。

有一张等人来看的 PR。

更远一点的收窗人，也终于不必再靠程知序一人代问，才能摸到青炉这扇门。

就在众人以为这一章快要收住时，石镜远端页最底下，忽然又亮起一行新字。

不是北院里任何一个人的名字。

而是外头某位他们并不熟悉、却在卷首事故里已经被程知序点过一次名字的守门匠：

北岭二号守门房，段迟舟。

他顺着那张 issue 留下了一句补充：

“北岭二号守门机同样能复现，附复现场景如下。”

后面跟着一整段清楚到近乎工整的复现链。

季循盯着那行字，半晌没有出声。

因为他忽然意识到，第十七章真正打开的，已经不只是一个远端仓库。

它第一次让青炉面对了门外之问。

不是“有人隔着很远向北院求一声情”。

而是“有人沿着公开入口，把自己的问题和经验，正大光明地放进了共同体的光里”。

沈见微看着那条新补充，没有立刻回话，只在文契第十二层落下一句短短的话：

> 主线若只认熟人，就还不算公共之门

石镜微亮，远端页仍开着。

而青炉第一次不再只是一间屋子里的火。

它开始沿着远处的共库，把问题、改动与解释，一点点送到更远的人手里去。
