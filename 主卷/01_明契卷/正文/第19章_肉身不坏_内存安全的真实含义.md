# 《万构界·明契卷》第十九章：肉身不坏，内存安全的真实含义

第十八章刚把青炉的门规立住，外头的问单就立刻比从前更重了一层。

这一次，不再只是“这句说明够不够直”“这张问题单该不该补示例”。

而是几处外侧守门房都先后追来同一个要求：

青炉得尽快补出更重的全身查病入口（`doctor`）。

也就是一次把构件清单、临时目录、历史缓存都翻一遍的深查模式。

程知序把三处守门房送来的新单摆上长案时，连贺时进都少见地没先催。

因为这回确实不是小修小补能顶过去的事。

有些旧窗，平时 `check` 还能勉强看出七八分。

一旦真要追“为什么同样的窗这次过了、下次又歪”“为什么旧别名在某些地方还会悄悄被接进去”，就非得把那一轮里经过的临时目录、缓存残影、构件清单一起掀开看不可。

苏野平先把旧日最快的法子摆了出来。

“这事若老老实实一份份抄，慢得要死。”他说，“还不如沿用旧世界的共享暂存池。临时目录扫出来的东西先别散，历史缓存也别一轮轮重新抄，大家都挂在同一片暂存里，`doctor` 进来就直接拿。”

他说着，在石镜上写下了一版看起来很顺手的草案。

构件清单借来看。

临时目录扫出来的条目借来用。

历史缓存也只借一个视图。

最后等整轮 `doctor` 跑完，再一起清。

季循盯着那版草案，第一眼竟也觉得顺。

因为它太像第六章以前他们最熟的那种快路了。

不多抄，不多搬，不多占地方。

谁要查，就先进来借着看一眼。

可韩砺年站在门边，看见“最后再一起清”六个字时，脸色却一点点沉了下去。

贺时进先看出来了。

“你又想起什么旧事了？”

韩砺年沉默片刻，才低声说：

“梁故川还在的时候，旧工具链出过一次最难讲清的怪错。不是一上来就炸，也不是人人看一眼就知道哪坏了。它最可怕的地方是，同一版东西，有时这样跑，有时那样跑。”

屋里一下静了。

因为“同版异行为”这几个字，对北院的人来说，几乎就是卷首那夜最深的旧伤。

韩砺年把那段旧事慢慢讲了出来。

当时有一条旧钩子，要先扫一遍临时目录里的条目，再对着历史缓存核一遍旧别名。

可那一轮里，清理动作先走了一步。

临时目录被收走了，挂着那批条目的临时记录也跟着离了场。

偏偏另一条钩子还以为那批东西活着，继续顺着旧位置去读。

有时它会直接报错。

有时却不会。

因为那块位置已经被下一轮别的东西占去了，它读到的不是“空”，而是“错的活物”。

程知序听到这里，背后都微微发凉。

“所以它不是立刻炸开。”

“对。”韩砺年说，“最恶心就恶心在这里。你以为它还在读上一轮那批条目，其实它早就摸到别的东西身上去了。”

闻衡在白纸上落下第一句解释：

器里真正装着这些数据的内里地方，叫内存（memory）

然后补上第二句：

已经离场的东西，你却还继续去碰，这类病里最典型的一种，叫释放后继续使用（`use-after-free`）

她顿了顿，才又写下第三句：

一份东西从生出来，到该被收走，中间允许谁碰、碰到几时，这整段时间边界，叫生命周期（`lifetime`）

季循盯着“生命周期”四个字，心里忽然一紧。

第六章讲所有权时，他们已经把“谁拿着、谁负责、谁收尾”说清了一半。

可到第十九章，他才第一次真正看见另一半。

不是只问“它归谁”。

还得问“它能活到什么时候”。

若连这件事都说不清，那你今天借来看的一眼，明天就可能变成摸到一具早该离场的旧壳。

苏野平仍旧不甘心。

“可现在我们是在 Rust 里写青炉，又不是在旧工具链里乱抓旧地址。哪有那么邪乎？”

“那你试。”沈见微说。

他没有跟苏野平空争，只把石镜转向季循。

“按你们方才那版快路，先把 `doctor` 最小骨架搭出来。”

季循坐下以后，先真的照着苏野平的思路写了下去。

他想做的是一份轻巧的 `DoctorInput`。

不自己持有东西。

只借用这轮 `doctor` 里本来就会扫出来的那些数据。

石镜上很快浮起一小段草案：

```rust
struct DoctorInput<'a> {
    manifest: &'a Manifest,
    temp_entries: &'a [TempEntry],
    cache_view: &'a [CacheRecord],
}
```

他又顺着往下写，想把这份输入一路传给后面的深查动作。

起初看着一切都很自然。

可等他真把临时目录里扫出来的条目装进去，石镜立刻冷冷吐出一行拦字：

`borrowed value does not live long enough`

季循盯着那行字，眉头一下拧紧了。

苏野平立刻凑近。

“什么意思？”

沈见微没有先答。

闻衡先把那句翻成人话：

你想借来的这份东西，活不到你后面还想继续用它的时候

季循没有服气，换了个写法又试。

把临时目录本身留得更久一些。

把缓存视图也一起挂进去。

甚至想把清理动作拖到最后一步。

可石镜又接连吐出第二行、第三行拦字。

有的是说临时记录活得不够久。

有的是说你已经把这一份交去后面用了，前面又想顺手再改。

他写得越快，拦字越密。

到了最后，连他自己都开始生出一股很冲的闷气。

“它是不是管得太宽了？”他低声说，“我只是想先把这一轮数据挂住，等 `doctor` 跑完再清。”

这句话一出，长案边没有人立刻接。

因为这正是第十九章最容易让人误会 Rust 的地方。

像是它在拿一堆生硬规矩挡现实。

像是它只会说“不许”。

闻衡却在这时把第六章那张旧纸翻了出来，压到季循手边。

上面写着：

谁拿着，谁负责。

她指着那行字，只问了一句：

“你现在说得清，这些临时条目到底归谁，活到几时，谁还能继续碰吗？”

季循张了张嘴，没立刻答出来。

因为他忽然发现，自己方才那版“先挂着再说”的快路，恰恰就卡在这里。

表面看，它只是想少抄几份。

实际上，它把最要命的三件事一起含混了：

这一批临时条目是谁真正持有。

清理动作何时才算合法。

后面的深查骨到底是在读“活的当前状态”，还是在读“已经离场的旧影”。

闻衡见他没答，才继续往下说：

“内存安全（`memory safety`）不是说器从此再也不会出错。它是在逼你先把这些最容易靠运气混过去的账讲清。”

“哪几种账？”贺时进问。

“谁拥有。谁借看。谁收走。收走以后，谁绝不能再碰。”

她每说一句，就在纸上压下一行。

最后才补上最重的一句：

“若你说不清这些，就没有资格谈可信。”

屋里静了片刻。

最后还是沈见微把那张“快而轻”的草案轻轻推到了一边。

“别再让核心深查动作直接抓活的临时状态。”他说。

“那怎么查？”苏野平问。

沈见微没有绕，直接换了一种更笨、却更清楚的写法。

他先写下第四句解释：

先把这轮真要查的东西收成一份独立快照（`CheckPlan`），后面所有深查动作只吃这份快照

然后在石镜上落出新的骨架：

```rust
struct CheckPlan {
    manifest: Manifest,
    temp_entries: Vec<TempEntry>,
    cache_records: Vec<CacheRecord>,
}
```

季循盯着这版新骨架，先是愣了一下。

因为它一点也不炫。

甚至看上去有点笨。

该抄的抄进来。

该拿稳的拿稳。

先把这轮 `doctor` 真要看的东西收成一份自己的计划书，再让后面的核心检查动作对着它做判断。

沈见微继续写：

```rust
fn build_check_plan(...) -> CheckPlan
fn run_doctor(plan: &CheckPlan) -> DoctorReport
```

然后他点着这两行，慢慢解释：

“第一步，只负责把本轮要查的东西收齐。第二步，只对这一份已经站稳的快照做判断。临时目录是不是还活着，缓存原位后面会不会再变，都不该由后面那一步继续赌。”

韩砺年望着这版新骨架，像是终于把胸口那口旧气慢慢吐了出来。

“这才像把旧怪错真正堵在门外。”

“为什么？”程知序问。

“因为后面读的，不再是会变、会散、会被别人顺手清掉的活物。”韩砺年说，“它读的是这轮已经明明白白收住的一份快照。快照错了，是第一步的责任。判断错了，是第二步的责任。再不会混成一锅。”

苏野平还想再争一句“这样多抄一层总归慢”，可话到嘴边，又自己咽了回去。

因为连他也看见了，第十九章这一刀最重的不在“多抄”。

而在“从此谁也不能再靠含混的活状态糊过去”。

季循重新坐回镜前，按这版新骨架往下写。

这一回，临时目录扫出来的条目先被收进 `CheckPlan`。

历史缓存里这一轮真正要核对的部分，也被清清楚楚抄成自己的那一份。

等快照收齐以后，后面的 `doctor` 核心动作只拿着 `&CheckPlan` 往下走。

石镜没有再像方才那样接连吐出拦字。

不是因为它忽然变宽了。

而是因为这次，季循终于先把那笔责任账写清了。

临时输入不再直接借壳长存。

核心检查动作改吃显式快照。

“已经离场的东西不许继续读”也第一次被写成了北院人人看得懂的规则。

贺时进看着那条新规则，半晌才低声道：

“所以所谓安全，不是圣人不犯错。”

“对。”沈见微说，“安全只是让某些本来只能靠运气绕开的错，现在在边界上就先被拦住。”

程知序望着石镜里那份站稳的 `CheckPlan`，忽然觉得第十九章比前几章都更冷，也更实。

第十七章、第十八章，他们立的是门外能看见的规矩。

到第十九章，青炉开始立的是肉身里那层平日看不见、可一旦失位就会把一切都拖歪的秩序。

沈见微在文契第十四层落下最后一句话：

已经离场的东西，不配再被继续当作活物使用

石镜微亮，字痕沉入底层。

而季循望着那行字，第一次真正明白了“肉身不坏”这四个字为什么会落在这一章。

不是因为青炉从此金身不裂。

而是因为从今天起，它开始拒绝把那些本该早就离场的旧影，继续假装成还活着的答案。
