# 11 · 操作工作流

> 万构界项目的日常操作手册。每次会话的入口、路由、执行、退出 —— 一个文件，全覆盖。
> 最后更新：2026-06-21

## 一、每次会话入口（30秒）

启动：读 CLAUDE.md（如隔周）→ 读 harness/07_进度面板.md（永远第一步）→ 确定任务 → 查路由表 → 开始
结束：更新进度面板 → 标记"下次从哪继续" → git commit

## 二、任务路由表

### A. 审阅已有章节 ← 当前最高优先
- 审一章：调用 /review-chapter → 审校报告
- 审一批(5章)：调用 /audit-volume → Section审阅报告
- 验设定：调用 /check-canon → 设定验证报告
- 验跨卷：调用 /check-cross-volume → 跨卷验证报告
- 审阅优先级：明契卷(30章)→驭器卷→化形卷→简阵卷

### B. 写新章节
- Phase 1 准备：读章纲+卷设定
- Phase 2 设计：调用 /design-chapter
- Phase 3 写作：正文+术语标注+三问自答
- Phase 4 审阅：/review-chapter → 修改 → 提交
- 详见 harness/01_流水线.md

### C. 教学配套：调用 /gen-practice | 核查 supplements/00_配套索引.md
### D. 入门材料：调用 /gen-entry | 核查 supplements/ 下现有材料
### E. 维护：更新进度面板 | 核对文件名 | 术语检查 | 结构迁移 → harness/10_运维手册.md

## 六、铁律速查

1. 先工程后修辞：读者能说出"这里在处理什么真实工程问题"吗？
2. 设定可失守：世界观概念展示了失败形态吗？
3. 成长=责任升级：人物成长是责任扩容还是战力升级？
4. 术语注英文：每个中文CS术语每次出现注了英文原名吗？
5. 不替换工程术语：没把Cargo叫成"货册"吧？
