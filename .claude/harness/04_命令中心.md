> 统一任务路由。从这里出发，到达正确的工具、流程和参考文件。

## 一、使用方式

当你不确定"这个任务该怎么做"时：

1. 在下方任务表中找到你的任务
2. 按"路由"列执行
3. 按"产出"列确认完成

## 三、常见任务组合

### 3.1 "推进写作"（高频）

```
1. 查进度面板 → 确定下一批章（5章）
2. 对每章：执行流水线 Phase 1→2→3
3. 批量 Phase 4：/audit-volume (Section 级)
4. 过 Review Gate → Commit Gate
5. 更新进度面板
```

### 3.2 "回来继续"（高频）

```
1. 读 06_会话协议.md §恢复会话
2. 读 07_进度面板.md → 定位未完成任务
3. 从最早的未完成章继续流水线
```

### 3.3 "全卷审阅"（中频）

```
1. /audit-volume（全卷级）
2. 对照 09_集成验证.md 执行跨卷检查
3. 逐条修改
4. 更新进度面板
```

### 3.4 "新卷启动"（低频）

```
1. 读 10_运维手册.md §新增一卷
2. 创建 workspace/XX_卷/ 五层结构
3. 创建 supplements/XX_卷/ 三件套
4. /gen-character → 建立人物阵型
5. /design-chapter → 建立首批章纲
6. 更新 harness 各文件
```

## 六、命令中心使用原则

1. **先查此表，再动手**：不确定该用什么工具时，回来查路由表
2. **按流水线走，不跳步**：即使是"简单"章节也走完整的 Phase 1→4
3. **过了门再提交**：Commit Gate 是最后一道关，不过不提交
4. **更新进度面板**：每完成一章，更新两处（卷索引 + 进度面板）
5. **遇到新任务类型**：如果路由表中没有覆盖，先判断能不能拆成已有任务组合；如果不能，更新此表
