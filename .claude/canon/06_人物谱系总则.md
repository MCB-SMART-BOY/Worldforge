# 人物谱系总则

## 一、人物体系总原则

### 1. 人物不是职业表
人物是面对同一文明病理、给出不同回答的人。

### 2. 成长不是战力升级
而是：
- 从会修到会守
- 从自己知道到别人也能接
- 从局部能力到公共秩序

### 3. 冲突优先写成道路冲突
最有力量的冲突不是脾气对撞，而是不同文明回答之间的张力。

### 4. 人物必须承担代价
后续写人物时，不仅要写"他主张什么"，还要写：
- 他把代价留给了谁
- 他最怕失去哪一种解释权
- 他是否真的愿意交火给后来者

## 三、九大基础人物原型与两类特殊位

### 1. 起炉者
决定不再满足于修补，而要亲手起炉构器的人。

### 2. 镜像者
与主角一样有能力、甚至更强，但对文明难题给出另一种答案的人。

### 3. 守门者
长期守着某个器、阵或门的人，承受旧史和现实代价。

### 4. 同门者
与主角并肩成长，但不只是附和的人。

### 5. 使用者
真正依赖器或阵的人，使工程选择产生真实后果。

### 6. 继承者
后来真正要接火的人，是"未来是否存在"的检验者。

### 7. 审契者
对边界、文档、测试、规则极度敏感的人。

### 8. 观象者
最懂运行现实的人，能从迹、脉、势中看见真相。

### 9. 渡桥人
最擅长处理迁移、兼容与新旧秩序过渡的人。

### 10. 失传者
不是单独的一种道心，而是一种叙事功能位。
他通常握着一段断掉的旧史、失效的接口、无人再懂的古法，逼迫主角面对"若此火断在此处，会怎样"。

### 11. 诱惑者
不一定是反派，而是不断把主角往"短期最优""先用再说""先别写明白"的方向拖的人。
诱惑者代表世界对侥幸的奖赏机制。

## 五、人物关系最小闭环

一卷若想真正成立，主角最好至少同时面对：

1. 一个比自己更强、但道路不同的镜像者
2. 一个真正吃到后果的使用者
3. 一个代表未来的继承者
4. 一个承受旧债的守门者

如果这四个位缺失，人物冲突很容易沦为立场宣讲。

## 八、新增原型：修补者（The Fixer）

### 定位
修补者是创始者时代之后出现的第一个人物原型。他们不是角色阵型中的固定位置，而是一条贯穿四卷的隐藏人物链——每一卷的"诱惑者"都可能是修补者谱系中的一员。修补者横跨整个历史的暗线，在不同的基座上以不同的名字继续同一项工作。

### 核心信念
四蚀是缺陷。完美继承是可能的。后来者的痛苦可以通过制度、文档和自动化来消除。

### 核心困境
修补越多，后来者越依赖修补。依赖久了，后来者停止追问"为什么需要修补"——他们只问"怎么修补得更快"。修补者的善意在不经意间剥夺了后来者的判断力。

### 谱系
第一个修补者至今仍在。他在不同的基座上继续工作。他的方法被传承——每一代都有新的修补者。他们不一定是直接师生，但共享同一个信念。

四卷中的每一个"诱惑者"都可能是这个谱系的成员：

| 卷目 | 诱惑者 | "先这样"的本质 |
|---|---|---|
| 明契卷 | 贺时进 | 效率优先——契约可以后补 |
| 驭器卷 | 谢催成 | 先用再说——边界可以后画 |
| 化形卷 | （化形卷诱惑者） | 先跑起来——标注可以后加 |
| 简阵卷 | （简阵卷诱惑者） | 先统一口径——差异可以后处理 |

他们的"先这样，效率优先"不是懒惰，是对修补的信仰。他们真诚地相信：只要修补系统足够完善，后来者就不需要再承受前人承受过的痛苦。

### 与主角的关系
四卷的每一个主角都是修补者的后继者。他们都在做修补的工作。但他们各自在某个时刻意识到修补的极限——

- 沈见微意识到：契约的清楚本身就是新黑箱
- 纪承钧意识到：runbook 需要考古前提，而有些世界付不起考古的代价
- 周栖野意识到：速度的产物如果不被标注前提，就是下一个脚本林
- 傅远洲意识到：制度不能替人做凌晨两点的判断

——并最终在终局超越"修补 vs 放任"的二元对立，通过"放弃"来创造真正的继承。

### 修补者谱系的核心悖论
修补者的悲剧不是他们错了。恰恰相反——他们是对的，但他们的"对"只在特定条件下成立。当条件改变时，修补本身就变成了需要被修补的东西。而修补者是最难看见这一点的——因为他们太擅长修补了。

## 九、新增原型：候补执约人（Covenant Candidate）

### 定位
候补执约人不是角色自己选择的身份。它是世界底层机制自动识别的标记——当一个来自特定道的人，在自己的世界里证明了某种交接方式，并被另一个人的方式伤害过后，世界底层自动将其标记为"候补执约人"。

四卷的四个主角各自在不知情的情况下获得了这个标记。

### 触发条件
候选标记的触发需要同时满足三个条件：

1. **在自己的道里走到某种交接方式的尽头**——不是精通，而是走到看见它的边界
2. **被另一个道的候补人的方法伤害过**——不是误解，而是真正承受了对方方法的代价
3. **意识到自己的方法如果成为法则，会消灭另一种人**——不是恐惧，而是认识到自己的"对"会排挤别人的"对"

### 四人的标记时刻

| 主角 | 标记时刻 | 触发事件 |
|---|---|---|
| 沈见微 | 收到纪承钧的传讯之后 | 意识到契约的清楚是新黑箱——使用者在契约面前停止了自己看路 |
| 纪承钧 | runbook 在息壤炸了之后 | 意识到 runbook 需要考古前提——不是所有世界都付得起考古的代价 |
| 周栖野 | 模块在驿河炸了之后 | 意识到标注标准不可跨语境——正确但被信任的标注比没有标注更危险 |
| 傅远洲 | 被周栖野质疑后 | 意识到制度不能替人做凌晨两点的判断——制度的空白处才是人的位置 |

### 标记的意义
候补执约人的标记不是荣誉，也不是诅咒。它是一个信号：这个人已经看见了自己道路的边界，并且愿意承认边界之外还有别的道路。

标记本身不赋予任何能力。它只做一件事：当四个候补执约人同时在场的时刻，世界底层会开放"终局对话"——关于继承究竟是什么的对话。

## 十、四卷主角交互关系表

四卷主角不是孤立行动。他们的方法互相入侵对方的世界，每一次入侵都是一次被迫的重新审视。

| A → B | 入侵方式 | A 的方法在 B 的世界里的后果 | B 从中学到什么 |
|---|---|---|---|
| 沈见微 → 纪承钧 | 青炉诊断结果 | 契约正确但炸了玄枢——写清楚的契约在驭器的世界里变成了"你不必理解，你只需遵守" | 写清楚不够——清楚是新黑箱 |
| 纪承钧 → 周栖野 | 迁移 runbook | runbook 在息壤炸了——需要考古前提的方法扔进没有前提的世界，不是帮助，是陷阱 | 方法有前提——前提不满足就失效 |
| 周栖野 → 傅远洲 | 模块标注 | 标注在驿河不足导致事故——"先做出来"的模块在简阵的世界里变成了"来不及标注"的债务 | 标注不可跨语境——少是诚实，错是灾难 |
| 傅远洲 → 周栖野 | on-call 制度 | 制度的"替人判断"与空白的"让人判断"正面碰撞——两种方法在同一个事故里同时暴露代价 | 制度的空白处才是人——制度是地板，不是天花板 |

### 入侵的后果链
上表中的每一次入侵都不是单向的。A 的方法在 B 的世界里失败后，B 的回应又会反向影响 A 的道路。四人形成一个闭环：

```
沈见微 → 纪承钧 → 周栖野 → 傅远洲 → 周栖野（回环）→ ... → 终局四人同时在场
```

这条链不是因果链——是**互相暴露边界**的链。每个人都在被入侵之后，不得不重新审视自己信奉的东西。

## 十一、人物关系的深层结构

### 修补者谱系与候补执约人的交汇
修补者谱系是纵向的——贯穿历史，从第一个修补者到四卷的诱惑者，再到四个主角。

候补执约人是横向的——在同一时间平面上，四个来自不同道的人互相标记。

两条线的交汇点是终局：四个候补执约人同时在场时，他们不是要否定修补者的信仰，而是要超越"修补 vs 放任"的二元对立。他们发现：真正的继承不是传下你选的东西，而是传下你放弃的东西——以及你放弃的理由。

### 从"修补"到"放弃"
这不是一个反修补的故事。这是一个关于"修补的善意何时成为后来者的天花板"的故事。四个主角的弧线不是停止修补——而是学会在修补的同时，为后来者留下不修补的权利。

## 十二、四次入侵的详细机制

### 第一次入侵：沈见微 → 纪承钧

**入侵物**：青炉依赖诊断报告 v0.3.1
- 沈见微在明契卷中写的自动诊断工具
- 扫描系统依赖关系，标注"已退场依赖"和"可安全废弃"
- 报告包含免责声明："未知依赖不在检查范围内"

**玄枢断火事故链**：
小宿域管理员收到报告 → 删除 legacy-report-gateway → 该接口是玄枢外部依赖链上第四环（玄枢→北岭→旧结算系统→此接口）→ 跨四个系统，无人知晓 → 玄枢断火

**纪承钧的传讯**："你写的不是契约。你写的是：一种让后来者停止自己看路的东西。"

**沈见微领悟**：契约的清楚本身就是新黑箱——足够清楚的契约让使用者停止追问。

**保留的伤痕**：纪承钧的传讯贴在青炉公共记录板上，沈见微加注"此人用他的断火教了我一件事"。

---

### 第二次入侵：纪承钧 → 周栖野

**入侵物**：xirang-data-feed 迁移 Runbook v1.0
- 纪承钧为息壤写的17步迁移手册
- 前提P1："迁移者已确认下游依赖方清单"
- 此前提依赖息壤存在"依赖声明文件"——息壤不存在

**失败**：季晚禾走到第三步，无法确认下游依赖方。按runbook规则标记"待确认"，不继续。迁移未完成。

**周栖野的话**："你把你世界的前提，当成了所有世界的前提。"

**纪承钧领悟**：runbook需要考古前提。他把玄枢的考古成果当成了理所当然。

**保留的伤痕**：炸掉的runbook被保留在息壤公共记录板，标注"关于一个在别处成功的方法，如何在此处失效"。纪承钧回玄枢后在所有runbook第一页加了前提声明。

---

### 第三次入侵：周栖野 → 傅远洲

**入侵物**：息壤稳定骨模块 `seasonal-settlement-validator`
- 林过川遗留的火种，周栖野迁入稳定骨
- 文档齐全（基座兼容声明、输入输出、错误提示）
- 缺失：峰值负载标注——因为在息壤语境下不关键
- 林过川原始代码中的全量数据加载逻辑

**事故**：部署到驿河 → 默认512MB上限 → 北岭11个集群 → 2.8GB内存 → OOM

**周栖野的回应**：不加"峰值负载"标注栏。在模板最上面加语境声明——"此标注基于息壤典型使用场景。如果部署为长期服务——以下标注可能不充分。"

**傅远洲领悟**：默认值过期了。写默认值的人不知道三年后的世界是什么样。标注有语境——前提变了，标注就不够了。

**保留的伤痕**：傅远洲在默认值审计表上标注512MB"已过期"。周栖野在息壤模板上加语境声明。

---

### 第四次碰撞：傅远洲 → 周栖野

**性质**：对话，非事故

**核心分歧**：
- 傅远洲的"四项必填"：选择——判断什么最重要
- 周栖野的"不标注"：诚实——承认不知道什么该标

**傅远洲的领悟**：制度是地板不是天花板。制度能保证有人接，不能保证接的人多写一行。而那一行才是后来者真正需要的。

**双方处理**：
- 傅远洲：模板第一页加判断声明——"此选择可能不完整。如果你认为某项应在必填层——先写理由。后来者可以同意或不同意。但他们会知道这里有人做过判断。不是默认值。"
- 周栖野：息壤公共记录板加规则——引用红色标签者须声明。炸了第一个找引用者。

---

### 入侵的底层意义

四次入侵揭示同一个结构：**每个主角的方法——在他的世界里被证明有效——在另一个世界里因为前提不成立而失效。**

不是谁的方法更好。是**所有方法都有前提。前提是语境化的。语境变了——方法的有效性就变了。** 跨语境的交接，不是把方法写得更全，是把前提写得更清楚。前提之外——承认不知道。

## 十三、终局机制：放弃与史约

### 触发条件
远古校验程序 `covenant-check.legacy-world` 检测到四个不同层次的人各自走到方法的尽头并被另一个人的方法伤害过后，自动将告警内容从"请求执约人介入"变为"候补执约人已就位"。

### 四人收到的召唤
各自公共记录板上的旧伤痕浮现——沈见微板上的纪承钧传讯、纪承钧runbook上周栖野的注、周栖野标签旁傅远洲的话、傅远洲制度第一页上周栖野的话。附带一个地址。

### 修补者的揭示
修补者在他的旧屋中向四人揭示：史约不是被"写"出来的。是"放弃"出来的。创始者留的不是空白——是一个机制。必须有人愿意让自己的方法不被写进世界底层。史约才能诞生。

### 四人的放弃声明（各约100-150字）
- 沈见微：放弃"写清楚就是一切"→契约附废弃声明
- 纪承钧：放弃"runbook是完整地图"→runbook第一页加前提声明
- 周栖野：放弃"速度自足"→火种附出生声明
- 傅远洲：放弃"制度充分"→制度旁保留空白行

### 史约的诞生
远古校验程序自动生成确认："史约已就。非约。约者弃也。弃者留路。路非唯一。后来者见此约者——知有过往者不以此路为唯一路。可行。"

### 修补者的离去
