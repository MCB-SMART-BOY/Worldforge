# 明契卷 · 青炉

> 从一场发版事故开始，学怎么写清楚边界和承诺。
>
> 命令成功不等于秩序成立。
>
> **120章 | 12卷 | 对象层级：念→约→图→文→骨→器→阵→门→史**

---

## 🎭 人物

| 角色 | 名字 | 定位 |
|---|---|---|
| 主角 | **沈见微** | 起炉者——青炉前身工具群的实际救火者、局部维护核心 |
| 镜像者 | **裴照川** | 传奇修补者、危机止火人、旧工具链事实上的隐形总顾问 |
| 守门者 | **韩砺年** | 旧工具链维护者、门内接口守门人 |
| 审契者 | **闻衡** | 测试、review、发布说明与门规校验的核心把关者 |
| 继承者 | **季循** | 新入门年轻构师，未来青炉的第一代接火人 |
| 同门者 | **苏野平** | 化形之道同门——脚本群、临时自动化与应急补丁的主要提供者 |
| 使用者 | **程知序** | 日常构建、发版执行与事故回滚的直接使用者代表 |
| 渡桥人 | **顾迁衡** | 旧脚本入口、兼容层、迁移桥与弃用路径设计 |
| 诱惑者 | **贺时进** | 短期绩效代表——最会把"先给大家用上"说成现实正义 |
| 失传者 | **梁故川** | 已退场的前代维护者，隐性约定仍埋在工具链根部 |

> 苏野平、程知序、闻衡、顾迁衡是跨卷人物。如果你先读的明契卷——没关系，他们会在后面的卷里自己解释自己。
