# 《万构界·明契卷》入卷说明

这不是现实世界里的程序员故事套了一层皮。

《万构界》是一个以工程文明为根的奇幻世界。在这里，器、阵、门、史都真实存在；宿域、共构坊、问心台、断史库、渡桥司也都是世界内本来就有的秩序结构。

阅读《明契卷》时，先记住四件事就够了：

1. 这是“奇幻文明”小说，不是现代办公室小说
2. 现实工程词会保留，例如 `README`、`release`、`rollback`、`Cargo`、`crate`
3. 世界观术语负责解释这些器与术在文明中的位置，而不替代它们
4. 本卷真正要写的，不是主角多会写器，而是秩序能不能被后来者接住

入卷时最常见的几个词，可以先这样理解：

- 石录：项目的历史主脉，接近 `Git`
- 问心台：审契与守契之地，接近 review、test、CI 合在一起的裁定关
- 外史：项目向外界立名的那一层，接近 version、release、changelog
- 渡桥：新旧秩序之间的临时桥，接近 compatibility layer、shim、adapter
- 门规：一门共同承认的守边界之法

如果只想先抓住卷一的入口，那就记一句：

**《明契卷》写的是，一群人如何在断桥潮里，停止靠少数人暗中续命，转而试着把一套秩序真正写给后来者。**
