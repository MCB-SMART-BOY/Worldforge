## 卷级设定

- **语言**：Java（企业级生态——Spring/annotation/设计模式）
- **核心道**：守序之道——"秩序不是被设计的——是沉积的。每一行旧代码都是一次决策——只是决策的理由已经丢了。"
- **工程命题**：legacy system migration / institutional memory / organizational knowledge / COBOL interop
- **核心张力**："沉默的秩序比没有秩序更难改——因为它还活着——只是没人知道它为什么活着。"
- **四相主相**：史（历史的沉积）+ 契（被遗忘的约定）
