## 二、样场正文

第二天一早，门里最难听的那批话都已经传回来了。

有人说青炉把事情做重了。

有人说这套规矩只适合闲时，不适合活人真要交付的时候。

还有人更直接：

“是不是以后凡事都得 Rust 化，才算文明？”

那句话被抄在白板最上面，像一根故意往人脸上戳的刺。

苏野平站在桌边，先把那根刺捏住了。

“我替大家把话说得更明白一点。”他说，“难道以后写个小脚本也得先把所有失败路径、资源边界、review 口径全摆上？难道试法的时候也要背着这么重的壳跑？难道慢和难，现在都能直接叫作文明了？”

贺时进靠在另一边，没替谁缓和。

“我只关心现实。”他说，“如果这套路只能在高纪律团队里成立，那它到底是工具，还是少数人的理想器？你总不能把一门里的训练度，当成全世界都会自动满足的前提。”

桌上还摊着昨夜留下的几份材料。

退桥日历。

迁移说明。

一张外侧投诉汇总。

还有那份让很多人真正开始不耐烦的延期清单。

顾迁衡把手按在最边上的一页冷史上，没先看谁，先看词。

“你们别把问题说得太整齐。”他说，“有些东西，不会因为你把核心层换成 Rust 就立刻变轻。旧核还在，ABI 还在，FFI 还在，守门 runbook 还在。那不是一句‘明契化’就能抹平的重量。”

他把几张纸分开摆成三堆。

“这一堆，是重器旧边界。”

“这一堆，是试法和临时桥。”

“这一堆，是守夜、交付和运行。”

“它们不是同一类病，也不该用同一把刀。”

闻衡站在白板前，把最上面那句刺眼的话划成了两半。

左边写：

`哪一层必须重？`

右边写：

`哪一层不该假重？`

她转过身，语气很平。

“如果今天答不出这两个问题，那《明契卷》确实会变成宣传册。”

程知序把外侧的反馈汇总翻到最后一页，第一次在这场争里替门外的人把话压得足够具体。

“我不要你们替我选信仰。”她说，“我只要两件事。第一，哪一层出了错，代价会直接打到使用者脸上。第二，哪一层今天还只是试法，别包装成我可以拿去押窗口的公共承诺。”

这句话让屋里安静了一瞬。

因为它把所有争论里最容易飘掉的东西又拉回了地上。

不是喜欢什么语言。

不是讨厌什么语言。

是门外的人到底该把哪一层当成真的。

沈见微这时才走到白板前。

他没有先替 Rust 说话。

他先在左边那列下面写了四行字：

`寿命长`

`多人协作`

`故障代价高`

`边界危险重`

“满足这四条的地方，”他说，“就值得把代价前置。值得先写失败，先写资源归属，先写行为承诺，先写后来者能不能复走。因为那里的模糊，不会只伤今天写代码的人，它会伤一串以后根本没到过现场的人。”

他停了一下，又在右边那列下面写了另外三行：

`高不确定试法`

`验证成本高于沉淀收益`

`只是薄壳编排`

“满足这三条的地方，不必强推明契。”他说，“如果你今天只是为了试法、为了找方向、为了验证一个还不知道值不值得留下的想法，先用更轻的器没错。错的是把试法说成定器，把薄壳说成核心，把临时路说成公共承诺。”

苏野平看着那几行字，像是终于等到了自己真正想听的半句。

“所以你承认，不是所有东西都该 Rust。”

“当然不是。”沈见微说。

“脚本、notebook、一次性试法链，本来就更接近化形之道。它们负责的是找路，不是替所有后来者把路永久担下来。”

他在白板边上又补了一行：

`试法层：先快，但必须承认自己只是试法。`

顾迁衡接了过去。

“那旧核接壤呢？”

“那更像驭器之争。”沈见微说，“不是换门语言就能消失的。你得承认重器的历史重量，承认 wrapper、adapter、runbook、观象和接火阶梯的必要。那里最重要的不是姿态纯净，是边界写清，谁能动、谁别碰、出了事谁来接。”

他又写下一行：

`重器边界：先立界，不许把危险装成已经驯服。`

贺时进皱着眉，还没有被说服。

“那守运层呢？值班、交付、扩域、多团队协作，这些难道也都要按你这套最重的来？”

“不是。”沈见微说，“那更像简阵之治。真正的重点是责任图、观象、发布秩序、回滚规则和 ownership。那里要的是让复杂回到该被看见的位置，而不是把所有层都硬压成一种材料。”

他补上最后一行：

`守运层：先看流转和责任，不许用统一口径压平真实差异。`

白板这时终于不像一场语言争吵了。

更像一张迟到很久的分层图。

核心层。

试法层。

重器边界。

守运层。

每一层都在往不同方向要秩序。

每一层也都可能在说谎。

闻衡看着那张图，替所有人把最后那句最容易失真的话钉住。

“所以今天的裁定不是‘Rust 最强’。”

“是，”沈见微接住她，“哪一层必须重，哪一层可以轻，哪一层若继续模糊，就会把债压给别人。”

苏野平没有再继续抬杠，只是指着“试法层”那一行问：

“那我这边的快路，什么时候不再算无辜？”

沈见微看着他。

“当它开始被别人当成长期可信入口的时候。”

“当它开始躲开失败说明的时候。”

“当它开始不肯承认自己只是临时桥的时候。”

“到那时，它就不再只是化形，它已经在偷偷冒充明契。”

这句话让苏野平第一次安静了几息。

因为那正是他最擅长、也最不愿承认的一种赢法。

贺时进把双臂抱在胸前，目光却已经从反驳变成了核算。

“所以你最后要的，不是一门语言的统治。”

“不是。”沈见微说。

“我要的是，每一层都被放到更合适的位置。”

“核心别再把模糊当灵活。”

“试法别再把临时当永恒。”

“重器别再把秘义当传火。”

“守运别再把压平当简。”

屋里终于没有人再把这场话题往“你到底是不是 Rust 信徒”上拖。

因为白板上的那张图已经比口号更难反驳。

它没有替任何道路封王。

它只是第一次把不同的重和轻，放回了各自该承担的地方。

沈见微把笔放下时，忽然觉得自己终于从“选道的人”往前走了一步。

不是走到更纯。

而是走到更稳。

## 三、当前结论

这个样场已经把第二十九章最关键的三件事压实了：

1. 明契之道被明确从“总答案”退回到了“某类病理上的必要答案之一”
2. 驭器、化形、简阵三道各自承担的工程层次第一次被清楚分位
3. 主角的成熟已经从“我选什么”推进到了“我知道何时不该强推此道”

当前更适合的用法是：

1. 作为第29章正式正文的设计回看稿，检查“何时该用 Rust，何时不该用 Rust”的分层裁定是否仍然清楚
2. 对照卷外配套与后三卷起步材料，回看这张分层图是否已经回写成跨卷判断尺
3. 保留为“避免把明契之道写成万能答案”的关键设计参照
