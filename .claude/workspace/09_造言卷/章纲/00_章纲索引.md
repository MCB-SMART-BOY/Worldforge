## 卷级设定

- **工程命题**：DSL / parser combinator / compiler design / language workbench / linter/interpreter
- **核心张力**："语言不是工具——是权力。有语言的人能写规则——没有语言的人只能承受规则。造言——是给还没有语言的人——一个声音。"
- **四相主相**：念（从概念到语言）+ 约（语言作为契约）
- **与前卷关系**：第一阶段四种语言各自走到了尽头——造言是第五种可能——不是替代现有的——是给现有覆盖不到的场景——造新的

## 卷一「无声」Ch 1-10

| 章 | 标题 | 核心 |
|----|------|------|
| 1 | 没有语言 | 一个团队面对一个前所未有的问题领域——现有的四种语言各自差了那么一点——"C++太底层——Python太慢——Go太简单——Rust太重" |
| 2 | 不适合的代价 | 用不适合的语言硬写——"代码能跑——但每一个后来者都需要重新理解——为什么这里用这种方法——而不是更自然的方法" |
| 3 | DSL的种子 | 团队里有人写了一个小解析器——"不是为了造语言——是为了让自己不用重复写同样的逻辑" |
| 4 | 被需要的声音 | 使用这个小解析器的人越来越多——"它不是语言——但它在变成语言" |
| 5 | 语言的重量 | 造语言——不是写一个解析器就完了——"文档/测试/错误消息/版本/兼容性——语言的承诺——比代码的承诺更重" |
| 6-10 | 决定造言——不是因为它酷——是因为现有语言覆盖不了这个领域——卷尾："造言不是创造——是回应——回应那些还没有语言的人" |
