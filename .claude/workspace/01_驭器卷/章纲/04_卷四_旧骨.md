### 第31章：旧骨

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：旧核考古——CMakeLists.txt的考古学
- **张力曲线**：悬疑型（进入最深代码层→'已经没人知道为什么这样写'→幽灵变量→旧骨不只是代码，是环境依赖的化石）
- **角色焦点**：纪承钧（进入旧核——面对'已经没人知道'的代码）；陆踏痕（考古——追溯到CMakeLists.txt中的幽灵变量）
- **六拍骨架**：
  1. 纪承钧第一次进入玄枢最深的代码层——旧核。代码在此沉积了十几年
  2. 发现第一处'旧骨'：一段代码，写于八年前——没有人知道它为什么这样写。只知道改了之后——有三个外部系统会坏
  3. 旧骨和空位的区别：空位是'有人知道但没传'，旧骨是'已经没人知道了'。连钟守玄也不知道——'这段代码在卫千枢来之前就有了'
  4. 陆踏痕试图追溯——发现唯一能追溯到的是CMakeLists.txt中的一个条件判断。那个条件判断引用的变量——在整个代码库里搜不到定义
  5. 钟守玄：'那个变量——可能在某个已经清空的旧机器上。'——旧骨不只是代码，是沉积了十几年的环境依赖
  6. 旧骨不是垃圾——是化石。每根骨头都曾经是活的东西。只是活的东西死了——留下的骨架还在支撑整个系统
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第32章：CMake地狱

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：构建系统——CMake的隐式依赖
- **张力曲线**：崩塌型（改一行include→全门编译失败→CMake的隐式依赖→幽灵变量追溯到2017年的注释→'工具升级了，使用方式没有'）
- **角色焦点**：纪承钧（陷入CMake地狱——改一行全崩）；陆踏痕（追踪幽灵变量——花了三个时辰）；沈照痕（'工具升级了，使用方式没有'）
- **六拍骨架**：
  1. 纪承钧试图修改一个CMakeLists.txt——只改了一行include路径。玄枢编译失败了——不是改错的地方失败，是在完全无关的地方失败
  2. CMake的隐式依赖：一个变量的值在五个CMakeLists.txt之间传递——没有一个显式的声明。值从哪来的——只能靠人脑追踪
  3. 'CMake地狱'的本质：不是CMake不好——是CMake允许你写任何东西，包括无法追踪的东西。自由度变成了不可见性
  4. 陆踏痕花了三个时辰追踪这个变量——最终在一个从未被include的.cmake文件中找到它的定义。那个文件的注释：'# 不要动这个值——不知道为什么但是动了会坏。——2017年。'
  5. 沈照痕：'这不是CMake的问题——是没有构建系统的时候，人们用环境变量传递信息。CMake来了——但他们继续用同样的方式。'
  6. 工具升级了——但使用工具的方式没有升级。新工具被用成了旧工具
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第33章：卫千枢的指纹

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：传奇宗匠——功绩作为障碍
- **张力曲线**：双峰型（发现卫千枢的SFINAE修正→天才级别→但没有注释→陆踏痕：'有注释——两个时辰就够了'→宗匠的陷阱）
- **角色焦点**：纪承钧（面对传奇宗匠的遗迹——敬畏和恐惧交加）；陆踏痕（'如果有注释——两个时辰就够了'）；钟守玄（解释卫千枢的逻辑——'看代码就知道'）
- **六拍骨架**：
  1. 纪承钧在旧核中发现一处精妙的修正——一个模板特化用SFINAE解决了隐式转换问题。没有注释——只有结果
  2. 修正本身是正确的——但它的存在让后来者无法理解为什么这段代码的类型系统行为如此奇怪。修正掩盖了问题——而不是解决了问题
  3. 陆踏痕试图理解这段模板代码——花了四个时辰。得出结论：'如果这里有注释说'因为XX原因做了这个特化'——两个时辰就够了。'
  4. 钟守玄：'卫千枢不是不写注释——他写的注释比谁都多。但他的注释——在修正本身面前，他觉得不需要解释了。因为'看代码就知道'。'
  5. 纪承钧意识到：宗匠的陷阱——当你强到一定程度，你会忘记'不是每个人都和你一样强'。你的代码对你自己来说显而易见——对后来者来说是迷宫
  6. 卫千枢的指纹不是'错误'——是'太正确以至于不需要解释'。而这种'不需要解释'本身——就是最大的障碍
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第34章：为什么会这样写

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：理解债务——代码的'为什么'丢失
- **张力曲线**：悬疑→认知型（陆踏痕指着代码问'为什么传指针不传引用'→57处'为什么债务'→钟守玄：'你继承的是代码+所有没被写下来的为什么'）
- **角色焦点**：陆踏痕（建立'为什么债务'记录本——57处，能回答不到20处）；纪承钧（被问住了——不是不知道，是无法确认）；钟守玄（'你继承的是代码+所有没被写下来的为什么'）
- **六拍骨架**：
  1. 陆踏痕指着一处代码问纪承钧：'为什么这里传指针而不是引用？'纪承钧沉默了
  2. 不是不知道答案——是答案在代码之外。可能因为当时的编译器不支持引用做参数。可能因为调用方只接受指针。可能因为写的人习惯用指针。每一种可能都合理——但没有一种能被确认
  3. 纪承钧开始系统性地标注'为什么债务'：57处代码——能回答'为什么这样写'的不到20处
  4. 陆踏痕建立一个'为什么债务'记录本——每一处标注：代码位置、表面行为、'为什么'——空白。这个空白可能永远不会被填满
  5. 钟守玄看到这个本子——说了一句：'你继承的不是代码。是代码+所有没有被写下来的为什么。后者——比前者重得多。'
  6. '为什么会这样写'不是一个问题——是所有继承者的第一个问题。而大多数时候——没有答案
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第35章：平台矩阵

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：ABI/跨平台——结构布局、调用约定
- **张力曲线**：倒钩型（macOS上行为不同→追溯ABI差异→平台矩阵：15/21未知→'我们把能跑当成了正确'→ABI是对外承诺）
- **角色焦点**：纪承钧（发现macOS行为不同——追溯ABI差异）；沈照痕（建立平台矩阵——15/21标注未知）；钟守玄（承认——'我们把能跑当成了正确'）
- **六拍骨架**：
  1. 纪承钧试图在第二个平台上验证玄枢的构建——发现同样的代码在macOS上行为不同
  2. 根因：ABI差异——结构体在Linux上的内存布局和macOS上不一样。一个隐式依赖假设了Linux的布局——在macOS上悄悄错了
  3. 不是bug——是没有跨平台构建的文化。玄枢从第一天就在Linux上跑——'跨平台'从来不是需求，直到外部系统开始在macOS上调用它
  4. 沈照痕建立平台矩阵：七个平台 × 三个编译器版本 = 21种组合。其中15种标注'未知'——'不是不能测——是不知道哪些组合在被使用'
  5. 陆踏痕：'所以玄枢的'能跑'——只在特定的星象下？'钟守玄：'是的。我们一直都知道。但我们把'能跑'当成'正确'。'
  6. ABI不是技术问题——是'对外承诺'的问题。如果玄枢向外部保证行为一致——那跨平台差异就是背契
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第36章：链接器的秘密

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：链接器（linker）——链接顺序的隐式依赖
- **张力曲线**：悬疑型（链接顺序秘密→五年前试出来的→readelf/nm考古→'试出来的答案替代了理解'→被锁定的顺序）
- **角色焦点**：纪承钧（发现链接顺序秘密）；陆踏痕（用readelf/nm考古——追溯符号依赖）；钟守玄（'没有人愿意再花两周'）
- **六拍骨架**：
  1. 纪承钧发现玄枢的链接顺序是固定的——不能改。'改一个顺序，符号解析就炸。'但没有人知道为什么这个顺序是对的
  2. 追溯到根源：五年前，一个链接顺序问题导致运行时符号冲突。解决方法是试出来一个'不冲突的顺序'——锁定，从此不改
  3. 不是没有更好的解决方案——是'不冲突的顺序'一旦被锁定就成了'不能动的顺序'。符号解析的底层机制——没有人真正理解
  4. 陆踏痕试图用readelf/nm追溯符号依赖——发现有些符号来自静态库，有些来自共享库。静态和共享之间的初始化顺序——未定义行为
  5. 钟守玄：'五年前——我们花了两周才试出这个顺序。没有人愿意再花两周去理解为什么。'——'先让它跑'的代价：五年后——连试的人都没有了
  6. 链接器的秘密——不是秘密。是'试出来的答案替代了理解'。而答案一旦被锁定——理解就永远不会发生
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第37章：卫千枢的选择

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：守缺者铺垫——写下来的代价
- **张力曲线**：情感揭示型（钟守玄谈卫千枢→'他写过一次注释——三年后发现所有人只读注释不读代码。注释里有一个错误——没有人发现。'→守缺者谱系铺垫）
- **角色焦点**：钟守玄（揭示卫千枢的完整故事——为什么他不再写注释）；纪承钧（理解但不等于同意——需要找到自己的答案）；陆踏痕（'理解了，但不等于同意'）
- **六拍骨架**：
  1. 钟守玄终于开始谈卫千枢：'他不写注释——不是因为懒。是因为写了之后——人们不再自己看代码。'
  2. '他写过一次。一段模板代码——他写了详尽的注释。三年后他发现——所有人引用那段代码时，只读注释不读代码。注释里有一个错误——没有人发现。因为没有人读代码。'
  3. 从那以后，卫千枢不再写注释。'他宁愿后来者自己摸——也不想给他们一张可能错的地图。'
  4. 纪承钧：'但这不是注释的问题——是'注释被当成真理'的文化问题。'钟守玄：'对。但他没有能力改变文化。他只能改变自己的行为。'
  5. 陆踏痕：'所以他的选择不是最好的选择——是他在他的时代里，唯一能做的选择。'——理解了，但不等于同意
  6. 卫千枢的选择——和他留下的'写出来反而更危险'——不是教条。是他的困境。纪承钧需要找到自己的答案
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第38章：钟守玄认识他

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：两派线索——守缺者谱系开始浮现
- **张力曲线**：倒钩→揭示型（'卫千枢和我是一条路上的'→修补者谱系第一次系统揭示→两种方法同一条路→'链还在等下一环'）
- **角色焦点**：钟守玄（揭示修补者谱系——自己和卫千枢都是链上的人）；纪承钧（'有没有第三种方法？'）；陆踏痕（记录——'链还在等下一环'）
- **六拍骨架**：
  1. 钟守玄第一次正面确认：'卫千枢——和我是一条路上的。我们都在修修补者的路。'
  2. '修补者'这个称呼——纪承钧和陆踏痕都是第一次听到。'修补者不是一个人。是一代一代人。每一代都在修——每一代都没修完。'
  3. 钟守玄：'卫千枢选了和我不同的方法——他选的是——修到最好，然后不写。我选的是——修到够用，然后在心里记住所有修过的地方。'
  4. 两种方法——同一条路。守缺者的两种形态：卫千枢的'不写'和钟守玄的'不传'。目标相同——让后来者自己思考。代价相同——后来者被挡在门外
  5. 纪承钧：'那有没有第三种方法？'钟守玄：'有。修补者在找。已经找了很多代了。'——'他找到了吗？''没有。所以路还在。'
  6. 陆踏痕在记录本上写：'修补者——不是一个人。是一条链。钟守玄和卫千枢是链上的两环。链还在等下一环。'
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第39章：旧骨不烂

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：收束——旧骨的悖论
- **张力曲线**：收束→认知型（旧骨全景→既是功绩也是障碍→'不是怕改坏——是怕不知道往哪里回'→向卷五开门）
- **角色焦点**：纪承钧（收束——旧骨既是功绩也是障碍）；钟守玄（'不是怕改坏——是怕不知道往哪里回'）
- **六拍骨架**：
  1. 卷四收束。旧核中发现的每一根旧骨——都既是功绩也是障碍
  2. CMake的隐式依赖、卫千枢的无注释修正、链接器的秘密顺序、平台矩阵的未知格——每一样都是某个时代最聪明的解决方案。它们共同构成了旧骨
  3. 旧骨不烂——不是因为坚固。是因为它是活的东西死后的骨架。去掉任何一根——整个系统可能坍塌。但保留它们——后来者就永远进不来
  4. 钟守玄：'你现在明白了——为什么没有人敢动。不是怕改坏了。是怕改坏之后——不知道往哪里回。'
  5. 纪承钧把所有旧骨的发现放进'接火阶梯'的第一层：后来者需要先看见这些骨头——然后再决定怎么办
  6. 向卷五开门：旧骨之上——是秘义。那些钟守玄不肯写的、卫千枢不肯注的——口传知识。那是下一层
- 📝 **路标章**：对应旧Ch05。保留核心场景，在120章结构中扩展前后文。

### 第40章：旧骨之后

- **核心对象层**：[见Section总览]
- **核心相与失守**：式 → 失式
- **工程锚点**：卷尾收束——从考古到接火
- **张力曲线**：攀升→开门型（完成旧核考古报告→'看清楚了。然后呢？'→不是所有旧骨都能修→只能被理解、被包裹、被慢慢替代）
- **角色焦点**：纪承钧（'看清楚了。然后呢？'）；陆踏痕（标注考古深度——'待后来者发现'）
- **六拍骨架**：
  1. 纪承钧完成旧核考古报告——标注了所有已知的旧骨、未知的空白和'不能动'的区域
  2. 但在报告最后一页——他写了一个问题：'看清楚了。然后呢？'
  3. 不是所有旧骨都能被'修'——有些只能被理解、被包裹、被慢慢替代。接火不是一次性行动——是持续几代人的过程
  4. 陆踏痕在考古报告的空白处写：'此报告基于当前考古深度。更深处的旧骨——待后来者发现。'

  6. 向卷五开门：传的方法——就是下一Section的主题。宗匠的口传知识——那些不肯被写下来的东西
