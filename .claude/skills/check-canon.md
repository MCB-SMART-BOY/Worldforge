# /check-canon — 世界观一致性校验

校验新增设定/章节/人物是否破坏已有世界观骨架。
**同时检验两个维度：世界内一致性 + 读者可及性。设定再精妙，如果新读者在第一页就被术语淹没，设定也是失败的。**

## 参数

`content` — 待校验内容（粘贴或文件路径）
`content_type` — `setting` | `chapter` | `character` | `event`

## 校验清单

### 铁律一：不轻易新增第五相

- [ ] 内容是否引入了新的顶层法则（超出式/流/契/史）？
- 若引入了新概念 → 必须证明它不能归入现有四相
- 若无充分证明 → 拒绝新增，建议挂靠：式 / 流 / 契 / 史

### 铁律二：新概念挂靠旧骨架

若内容引入了新世界观概念：
- [ ] 它归哪一相（式/流/契/史）？
- [ ] 它作用于哪一层级（念/约/图/文/骨/器/阵/门/史）？
- [ ] 它与哪个核心机构相关？
- [ ] 它与旧概念的父子/并列关系是否清晰？

若以上四条任一答不上 → 概念需重新设计或丢弃。

### 铁律三：每个概念都有失守形态

- [ ] 每个新引入的概念是否说明了"坏了会怎样"？
- 若只描述了理想形态 → 这只是修辞装饰，不应进入正式设定
- 必须补充：它失守时表现为哪种四蚀（失式/乱流/背契/断史），具体症状是什么

### 铁律四：世界观词汇不替换现实术语

扫描内容中是否出现：
- [ ] 用了世界术语替代 Cargo/crate/trait/Result/CI/tracing/service 等现实工程词？
- [ ] 用了世界术语替代 Git/branch/release/deploy/runbook 等操作词？
- [ ] 用了世界术语替代 ownership/borrowing/concurrency/FFI 等概念词？

→ 世界术语只能解释这些词在文明中的位置，不能替换它们本身。

### 铁律五：工程冲突优先

- [ ] 核心冲突是否来自工程现实（边界失控/依赖失衡/承诺失信/历史断裂/运行失象/债务沉积）？
- [ ] 是否避免了纯粹玄幻对抗？
- 若冲突本质是玄幻 → 重新设计冲突来源

### 铁律六：读者认知负荷检查（⚠️ 新增）

- [ ] 本章/设定引入的新世界观术语数量？（每章 ≤ 3 个新术语）
- [ ] 每个新术语首次出场时，是否在 200 字内通过角色体验给出够用解释？
- [ ] 是否存在连续两个自然段都引入新术语？（连续术语轰炸 = 读者认知超载）
- [ ] 如果不借助术语表，一个第一次读的人能否在读完前 500 字后说出"这是什么样的世界"？
- [ ] 是否有"定义式句子"（"XX 是 YY"）超过两句以上？（超过 → 说明文味道过重）

### 铁律七：与现有设定的冲突检查

扫描内容是否与以下文件发生实质冲突：
1. `.claude/canon/01_万构界总纲与四相法则.md` — 四相四蚀定义
2. `.claude/canon/02_对象层级_机构_域与宿域.md` — 层级链和机构
3. `.claude/canon/03_诸道总纲_道统名录.md` — 道统体系
4. `.claude/canon/04_诸道显世史与历史地图.md` — 历史顺序
5. `.claude/canon/05_共构机制_工程映射_冲突规则.md` — 冲突规则
6. `.claude/canon/08–12` — 对应卷的卷级设定

## 冲突裁定顺序

若发现冲突，按以下优先级裁定：
1. `.claude/canon/01–05` 底层设定（最高优先级）
2. `.claude/canon/08–12` 卷级设定
3. `.claude/canon/14` 明契卷章级蓝图
4. `.claude/canon/18` 四主道映射
5. `.claude/canon/15` 写作铁律

## Gotchas

- **设定完美主义**：为世界观的一致性而牺牲故事的可读性。设定是骨架，不是牢笼。如果一段设定验证完美但读者读起来像说明书，设定仍然需要改写。
- **术语滚雪球**：一个概念的解释需要引用另一个概念，那个概念又需要引用第三个……解药：不是每个世界概念都需要在首次出场时被"完全解释"。够用即可。
