# /gen-character — 人物卡生成

按《万构界》人物卡模板生成或补全一张人物卡。
**每个人物必须在工程体系中有位置，在剧情中有冲突生成能力。——人物不是角色说明，人物是张力的来源。**

## 参数

- `volume` — 所属卷（明契卷/驭器卷/化形卷/简阵卷）
- `role` — 角色原型（主角/镜像者/守门者/审契者/继承者/同门者/使用者/渡桥人/诱惑者/失传者/观象者）
- `name` — 暂名
- `context`（可选）— 该人物在卷中的位置和已有出场

## 核心原则：人物即张力引擎

一个好人物满足三个条件：
1. **有想要的东西**（欲望）—— 推动行动
2. **有看不到的东西**（盲点）—— 制造错误
3. **有不肯放的东西**（执念）—— 阻碍成长

当这三者互相矛盾时，人物就有了内在张力。当人物A的欲望撞上人物B的执念时，就有了人际张力。

## 人物卡模板（九个必填区）

### 一、基础信息
- 姓名
- 所属道统
- 所在宿域
- 当前职责
- 所属器/门

### 二、叙事信息
- 角色原型：[从角色原型列表中选定]
- 首次出场状态：[一句话，必须是具体场景]
- 与主角表层关系：[师徒/同事/对手/陌路/旧识...]
- 与主角深层冲突：[他们真正在争什么 —— 不是"意见不同"，而是"各自的核心信念无法共存"]

### 三、病理信息
- 最敏感的文明病灶：[黑箱化/继承失能/断桥潮/门规失效/...]
- 最擅长对抗哪种四蚀：[失式/乱流/背契/断史] + 为什么
- 最容易制造哪种四蚀：[失式/乱流/背契/断史] + 为什么
- 是否意识到这一点：[是/否/意识到一半] + 说明

### 四、道心信息
- 真正信奉的构世回答：[一句核心信念]
- 最看重什么：[不超过三个词]
- 最轻视什么：[不超过三个词]
- 对其他道的最大偏见：[具体对哪一道，偏什么]

### 五、弧线信息
- 初始能力：[会什么]
- 初始盲点：[看不到什么]
- 最大诱惑：[什么会让他偏离自己的道]
- 最大代价：[他可能失去什么]
- 关键转折：[什么事件会改变他的轨迹]
- 最终是否完成"交火于后来者"：[是/否/部分] + 说明

### 六、语言气质信息
- 说话节奏：[短快/沉缓/绕/直/...]
- 喜欢用什么比喻：[火候/接缝/断口/桥/阵/...]
- 习惯先谈什么：[边界/速度/可行性/代价/...]
- 最常说的一类话：[一句话例句]
- **与谁说话时语气会变**：[什么关系，怎么变 —— 这是揭示隐藏情感的入口]

### 七、关系钩子（⚠️ 强化：每对关系必须有冲突潜力）

| 对象 | 关系性质 | 表层关系 | 潜在冲突 | 一句话 |
|------|---------|---------|---------|--------|
| 主角 | ... | ... | 各自的什么执念会相撞？ | ... |
| 镜像者 | ... | ... | ... | ... |
| 守门者 | ... | ... | ... | ... |
| 继承者 | ... | ... | ... | ... |
| （其他相关角色）| ... | ... | ... | ... |

### 八、卷内作用

该人物必须承担的三件事（⚠️ 至少一件是"制造困境"）：
1. [推进剧情的事件]
2. [制造困境的选择或行为] ← 必须至少有一个
3. [揭示主题或代价的瞬间]

### 九、一句话收束

**[名字]最难的一课，不是[表面困难]，而是[深层命题]。**

## 人物冲突潜力评估（⚠️ 新增）

生成人物卡后，必须回答：

- **内在冲突**：这个人最想做的事，和他最擅长的事，是否矛盾？（矛盾 = 有戏）
- **人际冲突**：这个人和主角的核心信念在哪一点上不可调和？（不可调和 = 有戏）
- **环境冲突**：这个人的做事方式，和本卷的工程文化，在哪一点上互相排斥？
- **时间冲突**：这个人过去最自豪的成就，是否正在成为他现在最大的包袱？

如果四条里有两条答不上 → 这个人物还没有足够的戏剧潜力，需要深化。

## 角色原型说明

| 原型 | 核心功能 | 典型张力来源 | 出现卷 |
|------|---------|------------|--------|
| 主角（起炉者/接火者/试法者/守阵者） | 面对本卷核心文明命题的人 | 想立新约但旧约的代价是谁来付 | 全部 |
| 镜像者 | 与主角走不同路线但面对同一问题 | 同病不同药——谁的解法代价更小？ | 明契/驭器/化形 |
| 守门者 | 现有秩序的守护者，疲惫但不可缺 | 守护的东西正在腐烂——继续守还是放手？ | 明契/驭器/化形 |
| 审契者 | 校验边界、承诺与规则的人 | 指出所有人的错，但自己也不全对 | 明契/化形 |
| 继承者 | 下一代接火人 | 要接过的东西和要扔掉的东西分不清 | 全部 |
| 同门者 | 邻道的同行者 | 不同的工具文化在同一问题上的碰撞 | 明契/化形 |
| 使用者 | 承受工程决策后果的日常用户 | 不是决策者，却付最大的代价 | 明契/化形 |
| 渡桥人 | 负责迁移、兼容层和弃用路径 | 桥是临时的，但拆桥的日期永远在推迟 | 明契/化形 |
| 诱惑者 | 短期绩效压力代表 | "先这样，回头再整理"——他说得没错，但他说的"回头"永远不会来 | 明契/化形 |
| 失传者 | 已退场但遗留仍在影响当下 | 人不在了，但留下的决策还在咬人 | 明契/化形 |
| 观象者 | 建立可见性体系的人 | 看见一切，但看见不等于能修 | 驭器/简阵 |

## 不同卷的人物偏好

> **卷序**：驭器（C++）→ 化形（Python）→ 简阵（Go）→ 明契（Rust）。每卷120章。

### 驭器卷（C++·玄枢）— 第一卷
- 人物在"古与旧、重与秘"的张力中行动
- 冲突常表现为：古器威能 vs 继承失能，宗匠知识 vs 公共文档，工具链蛮荒 vs 制度建立
- 关键词：敬畏、解释权、接火、考古层
- 典型内部冲突：**"我花了十五年才学会的东西，怎么可能一纸文档就传下去"**
- 独有人物原型：观象者（建立观测体系的人）、失传者（永久缺席的传奇宗匠）

### 化形卷（Python·息壤）— 第二卷
- 人物在"快与乱、试法与沼泽"的张力中行动
- 冲突常表现为：个人效率 vs 团队债务，快乐 vs 复现，动态自由 vs 类型约束
- 关键词：速度、遗迹、分层、包管理
- 典型内部冲突：**"上次这么做省了一天，这次这么做省了一周——我为什么要改"**

### 简阵卷（Go·驿河）— 第三卷
- 人物在"扩域与可知、个人与制度"的张力中行动
- 冲突常表现为：快速接入 vs 共同理解，英雄值班 vs 制度保障，简洁 vs 隐藏复杂度
- 关键词：可知、平台、共同维护、简洁哲学
- 典型内部冲突：**"凌晨两点总是我接的——是我放不下，还是制度让我放不下"**

### 明契卷（Rust·青炉）— 第四卷
- 人物在"边界与承诺"的张力中行动
- 冲突常表现为：写清 vs 口传，立约 vs 灵活，显式 vs 隐式，工具完备 vs "然后呢？"
- 关键词：边界、责任、可解释、终极悖论
- 典型内部冲突：**"我知道应该写清楚，但写清楚意味着承认我之前的模糊是错的"**

## 跨卷人物规则

若该人物可能跨卷出场：
1. 在每一卷首次出场时，必须给够用解释（不假设读者已读别卷）
2. 在不同卷中可以暴露不同侧面，但核心信念不能自相矛盾
3. 跨卷出场时，必须在本卷有独立的动机（不只是"从别卷走过来"）
4. 跨卷关系网见 `.claude/canon/22_第一阶段四卷共享事件表.md`

## Gotchas（常见人物设计错误）

- **工程功能化**：人物变成了某个工程概念的"讲解员"——他存在的唯一理由是在第X章向主角解释Y概念。解药：给这个人物一个和教学任务无关的执念。
- **无痛成长**：人物从盲点到醒悟的转变没有代价。真正的成长必须疼——丢掉一个旧信念、失去一段关系、承认自己的一部分是错的。
- **全员理性**：所有人物都用分析性语言说话，没人真正愤怒、恐惧、或羞耻。情感不只是"情绪渲染"，它是角色判断力的组成部分——恐惧让人短视，羞耻让人隐藏，愤怒让人鲁莽。
