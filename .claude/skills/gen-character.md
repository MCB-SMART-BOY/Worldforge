# /gen-character — 人物卡生成

按《万构界》人物卡模板生成或补全一张人物卡。所有人物必须同时具备工程侧和病理侧。

## 参数

- `volume` — 所属卷（明契卷/驭器卷/化形卷/简阵卷）
- `role` — 角色原型（主角/镜像者/守门者/审契者/继承者/同门者/使用者/渡桥人/诱惑者/失传者/观象者）
- `name` — 暂名
- `context`（可选）— 该人物在卷中的位置和已有出场

## 人物卡模板（九个必填区）

### 一、基础信息
- 姓名
- 所属道统
- 所在宿域
- 当前职责
- 所属器/门

### 二、叙事信息
- 角色原型：[从角色原型列表中选定]
- 首次出场状态：[一句话，必须是具体场景]
- 与主角表层关系：[师徒/同事/对手/陌路/旧识...]
- 与主角深层冲突：[他们真正在争什么]

### 三、病理信息
- 最敏感的文明病灶：[黑箱化/继承失能/断桥潮/门规失效/...]
- 最擅长对抗哪种四蚀：[失式/乱流/背契/断史] + 为什么
- 最容易制造哪种四蚀：[失式/乱流/背契/断史] + 为什么
- 是否意识到这一点：[是/否/意识到一半] + 说明

### 四、道心信息
- 真正信奉的构世回答：[一句核心信念]
- 最看重什么：[不超过三个词]
- 最轻视什么：[不超过三个词]
- 对其他道的最大偏见：[具体对哪一道，偏什么]

### 五、弧线信息
- 初始能力：[会什么]
- 初始盲点：[看不到什么]
- 最大诱惑：[什么会让他偏离自己的道]
- 最大代价：[他可能失去什么]
- 关键转折：[什么事件会改变他的轨迹]
- 最终是否完成"交火于后来者"：[是/否/部分] + 说明

### 六、语言气质信息
- 说话节奏：[短快/沉缓/绕/直/...]
- 喜欢用什么比喻：[火候/接缝/断口/桥/阵/...]
- 习惯先谈什么：[边界/速度/可行性/代价/...]
- 最常说的一类话：[一句话例句]

### 七、关系钩子

| 对象 | 关系性质 | 一句话 |
|------|---------|--------|
| 主角 | ... | ... |
| 镜像者 | ... | ... |
| 守门者 | ... | ... |
| 继承者 | ... | ... |
| （其他相关角色）| ... | ... |

### 八、卷内作用

该人物必须承担的三件事：
1. ...
2. ...
3. ...

### 九、一句话收束

**[名字]最难的一课，不是[表面困难]，而是[深层命题]。**

## 角色原型说明

| 原型 | 核心功能 | 出现卷 |
|------|---------|--------|
| 主角（起炉者/接火者/试法者/守阵者） | 面对本卷核心文明命题的人 | 全四卷 |
| 镜像者 | 与主角走不同路线但面对同一问题的对照 | 明契/驭器/化形 |
| 守门者 | 现有秩序的守护者，疲惫但不可缺 | 明契/驭器/化形 |
| 审契者 | 校验边界、承诺与规则的人 | 明契/化形 |
| 继承者 | 下一代接火人，检验秩序是否真的可传 | 全四卷 |
| 同门者 | 邻道的同行者，带来不同气质和工具 | 明契/化形 |
| 使用者 | 承受工程决策后果的日常用户代表 | 明契/化形 |
| 渡桥人 | 负责迁移、兼容层和弃用路径 | 明契/化形 |
| 诱惑者 | 短期绩效压力代表 | 明契/化形 |
| 失传者 | 已退场但遗留仍在影响当下的人 | 明契/化形 |
| 观象者 | 建立可见性体系的人（日志/追踪/指标） | 驭器/简阵 |

## 不同卷的人物偏好

### 明契卷
- 人物在"边界与承诺"的张力中行动
- 冲突常表现为：写清 vs 口传，立约 vs 灵活，显式 vs 隐式
- 关键词：边界、责任、可解释

### 驭器卷
- 人物在"古与旧、重与秘"的张力中行动
- 冲突常表现为：古器威能 vs 继承失能，宗匠知识 vs 公共文档
- 关键词：敬畏、解释权、接火

### 化形卷
- 人物在"快与乱、试法与沼泽"的张力中行动
- 冲突常表现为：个人效率 vs 团队债务，快乐 vs 复现
- 关键词：速度、遗迹、分层

### 简阵卷
- 人物在"扩域与可知、个人与制度"的张力中行动
- 冲突常表现为：快速接入 vs 共同理解，英雄值班 vs 制度保障
- 关键词：可知、平台、共同维护

## 跨卷人物规则

若该人物可能跨卷出场：
1. 在每一卷首次出场时，必须给够用解释（不假设读者已读别卷）
2. 在不同卷中可以暴露不同侧面，但核心信念不能自相矛盾
3. 跨卷关系网见 `.claude/canon/22_第一阶段四卷共享事件表.md`
