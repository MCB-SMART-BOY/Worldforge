# /check-cross-volume — 跨卷引用检查

检查跨卷引用是否遵守四条铁律，确保每卷可独立阅读。
**同时检查：跨卷引用的入门友好度——一个从别卷进入的读者，会不会在本卷的第一章被"你必须知道"的潜台词劝退。**

## 参数

- `source_volume` — 发起引用的卷
- `target_content` — 被引用的内容（人物/事件/概念/机构）
- `context` — 引用所在的章节和上下文

## 四条铁律检查

### 铁律一：互文只能增益，不能写成本卷成立前提

- [ ] 如果读者没读过被引用的卷，本章的核心情节是否仍然成立？
- [ ] 被引用的内容是否是"加分项"而非"必要条件"？
- 若引用是必要条件 → 必须在当前卷内补充够用解释，或改为可选引用

### 铁律二：共享事件必须按本卷主角的代价和病理重新叙述

- [ ] 共享事件是否从本卷主角的视角重新呈现？
- [ ] 是否突出了本卷特有的病理视角（而非简单复述原卷内容）？
- [ ] 代价归属是否与本卷的人物和项目绑定？
- 若只是复述 → 重写，确保本卷有自己的视角和代价

### 铁律三：跨卷概念首次出场时必须在本卷内给出够用解释

- [ ] 这个跨卷概念是否在本卷首次出现时做了够用解释？
- [ ] 解释是否足够让未读别卷的读者理解该概念在本卷中的作用？
- [ ] 解释是否自然嵌入剧情（而非生硬插入一段说明文）？
- 若解释不足 → 补充嵌入式的概念说明

### 铁律四：卷尾接口只能指向"后续放大"或"另一侧反照"

- [ ] 卷尾是否出现了"你必须先读某卷才能理解"的表述？
- [ ] 卷尾接口的语气是"邀请"还是"门槛"？
- [ ] 是否使用了以下禁止措辞？
  - "详见X卷"
  - "如前卷所述"
  - "请先阅读X卷"
  - "在X卷中已经解释过"
- 若出现禁止措辞 → 替换为"后续放大"或"另一侧反照"的邀请语气

## 入门可及性检查（⚠️ 新增维度）

跨卷引用最容易制造"入门壁垒"。新增检查：

- [ ] **首章洁净度**：本卷第 1 章中有没有引用其他卷的角色/事件/概念？如果有，数量几何？是否在出场同时给出了足够让新读者不困惑的解释？
- [ ] **跨卷人物首次亮相**：本卷引用的跨卷人物首次出场时，是否像一个"新角色"一样被建立（有独立的出场场景、独立的动机展示），而非像一个"你该知道他是谁"的旧识？
- [ ] **跨卷机构提及**：如果本卷提到了其他卷的机构/项目（青炉/玄枢/息壤/驿河），第一次提及时是否用一句话说清了它和本卷的关系？
- [ ] **情感前置条件**：是否假设读者已经有了对某个人物/事件的"情感预设"？（如"读者应该已经在前卷中关心这个人了"）→ 危险。必须在当前卷内重新建立情感连接。
- [ ] **术语陡增**：跨卷概念 + 本卷新概念的叠加是否导致某一章的术语密度超过警戒线（>3 新术语/章）？

## 跨卷人物检查

若引用/出场了跨卷人物（当前已知跨卷人物：苏野平、程知序、闻衡、顾迁衡、顾迁舟）：

- [ ] 人物首次在本卷出场时是否给出了独立的角色建立（不依赖别卷的人物卡）？
- [ ] 人物在本卷中是否展现了新侧面（而非简单复用原卷形象）？
- [ ] 人物在本卷中的行动是否有本卷特有的工程理由？
- [ ] 一个从未读过别卷的读者，是否能在这个人物的首次出场中明白：他是谁、他为什么在这里、他想要什么？（⚠️ 新增）

## 跨卷机构/概念检查

若引用了跨卷机构（青炉/玄枢/息壤/驿河）或跨卷概念：

- [ ] 首次提及时是否做了简短但足够的背景介绍？
- [ ] 是否说明了该机构/概念与本卷项目的具体关系？
- [ ] 介绍是否通过场景而非旁白完成？（⚠️ 新增）

## 共享事件检查

对照 `.claude/canon/22_第一阶段四卷共享事件表.md`：

- [ ] 本卷引用的共享事件是否在该表的允许范围内？
- [ ] 是否满足了该事件的"单卷自足最低要求"？
- [ ] 是否与该表中其他卷的叙述发生了事实冲突？

## Gotchas

- **跨卷自豪感**：作者因为精心设计了跨卷人物网，所以想让每个读者都"get 到"——在每一卷都塞满对其他卷的引用。但新读者不觉得这是彩蛋，只觉得这是门槛。克制。每卷的前 3 章尤其要克制。
- **"你该认识他"病**：跨卷人物出场时，作者下意识省略了建立过程——因为你（作者）已经认识他了。解法：每次跨卷人物出场，假装这是你第一次写他。
