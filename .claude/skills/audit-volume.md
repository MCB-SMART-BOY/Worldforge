# /audit-volume — 整卷审计

对一卷已完成正文做系统性复盘。
**审计六个维度：情节逻辑 · 术语口径 · 教学顺序 · 跨章一致 · 跨卷合规 · 节奏与读者旅程（⚠️ 新增）。**

## 参数

- `volume` — 卷名
- `scope`（可选）— `full`（全卷）| `logic`（仅情节逻辑）| `terms`（仅术语口径）| `teaching`（仅教学顺序）| `cross`（仅跨卷引用）| `pacing`（仅节奏与读者旅程）

## 审计维度

### 一、情节逻辑连贯性

逐章检查：
- [ ] 每章的核心工程概念是否按合理顺序引入？（后面用到的概念，前面是否已建立？）
- [ ] 人物弧线是否连续？（人物的认知/能力变化是否有跳跃？）
- [ ] 每章的问题是自然从前一章生长出来的，还是生硬切换？
- [ ] 五个关键锚点是否足够有力：
  1. 开局事故 — 读者第一眼能否看见病？
  2. 第一转折 — 主角从"补缝"转向"立约"的理由是否成立？
  3. 中段真相 — 是否暴露了体系最脆弱的位置？
  4. 高潮代价 — 主角是否真正放弃了"只有我能修"？
  5. 卷尾继承场景 — 后来者能否不依赖主角独立推进？

### 二、术语口径统一

- [ ] 同一世界观概念在全卷中是否使用一致的名称？
- [ ] 真实工程术语的使用是否准确且一致？
- [ ] 新术语首次出现时是否有足够解释？
- [ ] 有没有用世界观术语替换了应该保留的工程术语？
- [ ] 跨卷人物/机构/事件的称呼是否与 `.claude/canon/` 一致？

### 三、教学顺序审查

对照 `.claude/canon/20_四卷学习目标_项目目标_思想命题对照表.md`：
- [ ] 本章引入的概念是否匹配该卷的教学目标？
- [ ] 难度曲线是否合理？（不会突然跳跃到高级概念）
- [ ] 每个概念的引入是否伴随了对应的"坑"（让读者看见它坏了会怎样）？
- [ ] 章末是否留下了可延伸的思考入口（但不强迫读者去读别卷）？

### 四、跨章伏笔与回收

- [ ] 前章埋下的问题/冲突/人物是否在后章得到合理回收？
- [ ] 是否存在"提出了但从未回应"的伏笔？
- [ ] 是否存在"后章突然出现但前章毫无铺垫"的概念或人物？

### 五、跨卷引用合规

逐条检查跨卷引用是否满足四条铁律：
1. [ ] 互文只能增益，不能把另一卷写成本卷成立前提
2. [ ] 共享事件是否按本卷主角的代价和病理重新叙述？
3. [ ] 跨卷概念首次出场时是否在本卷内给出够用解释？
4. [ ] 卷尾接口是否指向"后续放大"而非"必须先读前卷"？

### 六、节奏与读者旅程（⚠️ 新增维度）

#### 6.1 全卷张力曲线

逐章标注张力峰值，绘制全卷张力曲线：

| 章 | 张力峰值 (1-5) | 峰值事件 | 呼吸点 |
|----|-------------|---------|--------|
| 01 | [1-5] | [什么事件] | [有无] |
| 02 | [1-5] | ... | ... |
| ... | ... | ... | ... |

检查：
- [ ] 全卷是否有一条上升的总张力趋势（后1/3的章均张力应高于前1/3）？
- [ ] 是否有连续三章以上同为低张力（1-2）？（有 → "泥泞中段"风险）
- [ ] 是否有连续三章以上同为高张力（4-5）？（有 → "读者麻木"风险）
- [ ] 最高张力章（全卷高潮）是否在倒数第 2-3 章的位置？
- [ ] 最后一章是否有"合上书的余韵"（张力回落，情感沉淀）？
- [ ] 第一卷的第一章是否张力过高（4-5）？（如果是 → 入门暴力警告）

> **120章尺度提示**：`连续三章`阈值适用于Section级检查（10章/组）。全卷120章级——检查是否连续5章以上同为低/高张力，或是否跨Section边界时持续同张力模式（如Section三末三章+Section四前三章=连续六章低张力）。Section是自然呼吸单元——跨Section边界应伴随张力变化。

#### 6.1 补充：120章尺度处理建议

全量逐章张力标注工作量极大。建议按Section分批处理（10章/组）：
1. 每个Section标注：最高张力章、最低张力章、Section内张力走向（上升/下降/峰谷交替）
2. 12个Section合成全卷后检查跨Section连续模式
3. 仅在发现连续模式异常时，才对该Section做逐章细化标注
将此原则适用于6.2（认知负荷曲线）和6.3（情感弧线），同样以Section为单位统计。

#### 6.2 读者认知负荷曲线

逐章统计新引入的世界术语和工程概念数：

| 章 | 新世界术语 | 新工程概念 | 累计术语负担 | 判定 |
|----|----------|----------|------------|------|
| 01 | [N] | [N] | [N] | ✅/⚠️ |
| ... | ... | ... | ... | ... |

检查：
- [ ] 前 3 章的术语密度是否被控制在 ≤ 3 个新世界术语/章？
- [ ] 工程概念的引入是否均匀分布（而非集中在某几章）？
- [ ] 是否有"术语定义章"（整章主要用于解释术语）？（有 → 改为分散嵌入）

#### 6.3 情感弧线

追踪主角/核心人物的情感状态地图：

| 章 | 主角情感状态 | 触发事件 | 变化方向 |
|----|------------|---------|---------|
| 01 | [状态] | [什么] | [→ 什么] |
| ... | ... | ... | ... |

检查：
- [ ] 主角的情感状态是否发生了可辨识的变化？（平线 = 没有人物弧线）
- [ ] 情感变化是否有"倒退"？（成长不是直线——应该有反复、怀疑、退步）
- [ ] 最低情感点（"最黑暗的时刻"）是否出现在高潮章之前？
- [ ] 最后一章的情感状态是否与第一卷形成有意义的对比？

#### 6.4 入门可及性（全卷视角）

- [ ] 第 1 章的前 500 字：新读者能否定位（在哪/谁的视角/发生什么）？
- [ ] 前 3 章结束时：读者能否回答"这个世界的核心冲突是什么"？
- [ ] 前 5 章结束时：读者能否说出至少一个角色的"他最怕什么"？
- [ ] 全卷中是否存在"不读术语表就看不懂"的章节？

### 七、各卷特有审计

> **阅读/写作顺序**：驭器→化形→简阵→明契。每卷120章（12卷×10章）。详见 `.claude/canon/23_四卷120章总蓝图.md`。

#### 驭器卷（C++·玄枢）— 第一卷
- [ ] 玄枢的古器属性是否始终可感（不只是设定，而是场景中的重量）？
- [ ] 守门者的"不敢退休"是否始终有具体的工程原因（而非情绪渲染）？
- [ ] 继承者的成长线是否贯穿全卷（陆踏痕从空白记录本到值守日志）？
- [ ] **六维工具链演化**：构建/版本管理/静态分析/调试/测试/文档的每次进化是否由痛苦事件驱动？
- [ ] **考古层**：被时代抛弃的工具（autotools/lint/RCS/CppUnit/Purify）是否作为"文明化石"呈现而非"落后技术"？
- [ ] **史约锚点**：残码发现(Ch47-48)、修补者揭示(Ch104-105)是否在正确章位？
- [ ] **入侵事件**：被青炉诊断报告炸(Ch75-78)、runbook炸息壤(Ch94-97)的跨卷回声是否正确？

#### 化形卷（Python·息壤）— 第二卷
- [ ] 息壤的"沼泽"是否在每个阶段都有不同的具体表现？
- [ ] "快"的价值是否得到了公正呈现（不只是批判速度）？
- [ ] 三层分治的出现是否有足够的铺垫？
- [ ] **包管理演化弧线**：pip→venv→requirements.txt→poetry→uv 的每一步是否由复现性痛苦驱动？
- [ ] **uv处理**：是否作为"暂时最好的归宿"而非终极方案呈现？
- [ ] 类型系统渐进演化（动态→Type Hints→mypy→Pydantic）是否自然融入剧情？
- [ ] **史约锚点**：三段残码同一行原因(Ch26-28)、失传者谱系(Ch105-106)是否在正确章位？
- [ ] **入侵事件**：被runbook炸(Ch55-59)、入侵驿河(Ch85-88)的跨卷回声是否正确？
- [ ] **跨卷对话**：傅远洲↔周栖野(Ch95-98)的制度vs空白对话是否到位？
- [ ] **核心放弃**：放弃"速度自足"(Ch107)的情感准备是否充分？

#### 简阵卷（Go·驿河）— 第三卷
- [ ] 驿河的扩域压力是否逐章递增？
- [ ] 每个服务的接入/故障/修复是否都有可追溯的工程逻辑？
- [ ] "平台"从个人英雄到制度的转变是否自然？
- [ ] **并发模型演化**：goroutine→channel→goroutine泄漏→structured concurrency 的每一步是否合理？
- [ ] **可观测性**：从"绿色=活着"到"三视图"的演化是否痛苦驱动？
- [ ] **简洁哲学边界**：43项模板→4项+判断声明的过程是否展示了约定vs制度的张力？
- [ ] **Java前传伏笔**：是否在终段埋下"约定够不够？那是守序之道要回答的"？
- [ ] **史约锚点**：远古告警首次出现(Ch25-26)、温故来512MB(Ch69, 74)的修补者谱系是否正确？
- [ ] **入侵事件**：被化形模块OOM(Ch65-68)的跨卷回声是否正确？
- [ ] **成阵**：四人召集+四大放弃+史约诞生(Ch102-110)的情感张力是否到位？
- [ ] **第一阶段总收束**：共约→向第二阶段开门(Ch111-120)的余韵是否充分？

#### 明契卷（Rust·青炉）— 第四卷
- [ ] 青炉起炉的动机是否在每个阶段都有足够的工程理由？
- [ ] Rust 特性（所有权、trait、unsafe 等）是否作为"对问题的回答"而非"语法展示"出现？
- [ ] **终极悖论**："拥有所有正确工具≠拥有所有正确答案"是否在沈见微的弧线中被证明？
- [ ] Cargo作为包管理回答、borrow checker作为valgrind/sanitizer回答、trait作为template/protocol回答——这些跨卷回声是否清晰？
- [ ] 每一章是否都能独立阅读（不假设读者读过前面三卷）？
- [ ] **史约锚点**：旧注释"此处逻辑不应被文档化"(Ch35-36)、梁故川遗产(Ch95-98)、旧注释回响(Ch115-118)是否贯穿？
- [ ] **入侵事件**：诊断报告v0.3.1(Ch77-78)→入侵物诞生→炸了玄枢(Ch105-108)的因果链是否正确？
- [ ] **核心放弃**：放弃"写清楚就是一切"(Ch109)与简阵卷Ch107四人放弃是否在叙事上形成同步？
- [ ] **修补者终言**："写清楚你为什么这样写"(Ch116-117)是否作为四卷共同终点呈现？

## Gotchas

- **节奏盲区**：审计时只看逻辑连贯性，不看节奏曲线。一卷 120 章如果每章都是"问题→分析→解决→总结"的同一节奏，逻辑上无误但读者会在第 5 章开始走神。
- **入门遗忘**：用"已经读过前卷的读者"的视角审计。必须有一轮审计是假设"这是读者翻开的第一卷第一章"来做的。
- **情感弧线缺失**：主角从头到尾都是同一情感状态（沉稳、冷静、理性）——这在工程上是合理的（一个好的工程师应该冷静），但在叙事上是灾难性的。人物的情感必须有起伏。
