# 术语速查：世界观 ↔ 工程原型

> 新读者快速参考——不需要记住全部，读正文时随手查。

## 世界层

| 世界术语 | 工程原型 | 说明 |
|---------|---------|------|
| 道 | 编程语言 | C++/Python/Go/Rust——每种语言是一个文明路径 |
| 式 | structure | 结构、边界、骨架——系统怎么组织的 |
| 流 | runtime/flow | 资源、状态、代价——系统在跑的时候发生什么 |
| 契 | contract | 承诺、文档、测试——说了什么，别人信了什么 |
| 史 | history/versioning | 版本、迁移、兼容——过去怎么活到现在 |
| 蚀 | corrosion | 四相出问题——失式/乱流/背契/断史 |
| 域 | domain | 一个独立的工程系统范围 |
| 宿域 | home domain | 一个道的主场 |
