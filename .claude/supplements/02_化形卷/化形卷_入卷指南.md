# 化形卷 · 入卷指南

> 如果你先读的驭器卷——欢迎来到第二个世界。如果你从化形卷开始——也没问题。

## 你在进入什么

化形卷的故事发生在一个叫**息壤**的地方——不是一台古器，是一片**脚本沼泽**。Python 写的——快、灵、乱中有用。这里的"火"不是服务运行状态——是探索的速度。"我这边能跑"是这里最常说的话——也是所有问题的源头。

这里的主人公周栖野是息壤最快的人。谢催成（诱惑者）一直在奖赏他的速度。但沼泽在生长——每一个"先让它跑"的脚本都在变成后来者的障碍。叶藏拙（守门者）有一本账本——记录着每一个被沼泽绊倒的后来者的名字。

这里的"桥"是跨系统的适配层——wrapper、adapter、shim。和玄枢一样——搭的时候都是"临时的"，后来都活了好几年。

这里的"遗迹"是一个叫林过川的人留下的几千个脚本。文件名从 `script.py` 到 `script_final.py` 到 `script_REALLY_FINAL_USE_THIS.py`。他的 README 只有三个字："对不起。"

## 核心人物

- **周栖野**——主角。最快点火的人——也必须最先学会止损。
- **叶藏拙**——守门者。记录沼泽生长的人，替所有走失的后来者说话。
- **宋既明**——审契者。不能复现就不算存在。
- **季晚禾**——使用者。Ch11 被沼泽吞没——Ch102 独立走通。
- **白又新**——继承者。从零开始——不需要问任何人。
- **林过川**——失传者。最亮的灵感只剩一地无人敢碰的目录。

## 与驭器卷的关联

从驭器卷来的读者会认出顾迁舟（渡桥人）、纪承钧的 runbook、以及"前提可能不成立"这句话在另一个世界以另一种语言重写。不需要重读驭器卷——每个跨卷角色和事件首次出场时都有足够解释。

## 阅读建议

- 卷一「点火」（Ch1-10）：建立世界观——从"这边能跑"到沼泽意识
- 卷二–卷三（Ch11-30）：沼泽测绘和遗迹考古——林过川脚本林是不容错过的考古悬疑
- 卷四–卷六（Ch31-60）：制度建立——三层息壤、桥账、删桥
- 卷七–卷九（Ch61-90）：工具链和验证——typing、CI、hypothesis、跨域OOM
- 卷十–卷十二（Ch91-120）：道争和收束——红色标签规则、放弃速度自足
