# 草稿模板

> 新格式（叙事型）实践单样本。靶向尚未成文章节，保留作为后续扩展模板。

## 格式说明

新格式包含五段：
1. **工程概念清单** — CS术语 + 英文原名表格
2. **四蚀判断** — 本章结算哪种蚀 + 判断依据
3. **三问自检** — 🩻蚀 😣谁 🛤️路
4. **叙事练习** — 工程视角重述场景
5. **跨卷追踪** — 跨卷引用来源与去向
