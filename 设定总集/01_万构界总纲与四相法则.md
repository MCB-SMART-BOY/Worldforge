## 一、世界总纲

### 1. 世界名

**万构界**

### 2. 世界定义

万构界不是"代码施法"的世界，而是一个以工程文明为根的世界。

在这里，一切可久存之物都必须面对：

- 复杂度
- 时间
- 协作
- 代价
- 继承

万构界不是被"创造"的——它是被"约"出来的。

### 3. 总纲句

**万构界中，一切可久存之物，皆非生于灵感，乃生于约束；非强于一时，乃强于可守。其成也，以式立形，以流定价，以契成信，以史传世；其毁也，始于失序，终于熵蚀。**

### 4. 存在公理

万构界建基于一条公理之上：

> **共识达到一定密度，就成为物理。**

这不是魔法。不是代码。当足够多的造物者就某件事达成一致，并持续以此行事，这件事就不再是可选的约定——它成为世界运行的底层法则。

## 二、世界的底层：约的物理

### 1. "约"的定义

**约**是万构界最基本的创世动作。它不是口头允诺，不是法律条文，而是一个造物者（或一群造物者）对世界运行方式的一次根本性断言。当断言被足够多的存在接受并践行，它就沉淀为物理法则。

约有三个不可分割的层次：

| 层次 | 定义 | 状态 |
|---|---|---|
| **言** | 说出或写下的声明 | 尚未生效 |
| **行** | 按声明持续行事 | 进入验证 |
| **定** | 行到一定程度，不再需要声明——它就是如此 | 成为物理 |

从"言"到"定"的过程不可跳跃。一个只被言说而从未践行的约，不成为物理。

### 2. 创始者与四条奠基之约

最早的造物者——在万构界中被称为**创始者**——面对一个尚未成形的世界，他们做了四件事。

#### 第一约：式

他们约定"式"——
> 万物应有形。一物能成什么、不能成什么，应可被区分。

于是**结构存在了**。类型、边界、模块、抽象——这些不再是一种观点，而是世界允许存在物的基本条件。没有式，万构界将是一片无差别的混沌。

#### 第二约：流

他们约定"流"——
> 万物应可运行。资源如何占有、转移、消耗、释放，应可被追溯。

于是**运行存在了**。所有权、生命周期、并发、代价——这些不再是一种设计选择，而是任何存在物都必须回答的问题。没有流，万构界将是一座静止的雕塑。

#### 第三约：契

他们约定"契"——
> 承诺应有约束力。一物对外界的保证，应可被依赖。

于是**承诺有了分量**。接口、文档、测试、规范——这些不再是一种善意，而是世界对背诺者的反噬。没有契，万构界将是一个互不信任的黑暗森林。

#### 第四约：史——故意的留白

在前三约上，创始者们达成了共识。但在第四约——**史**（继承）——上，他们没有约。

**不是不能约。是不约。**

### 3. "史"之未约：悖论与智慧

创始者内部存在分歧。

**一派**主张继承应自动成立：前人造物应能被后来者完整接住，无需理解、无需质疑。这样文明才能累积。

**另一派**主张继承不应自动成立：后来者必须重新理解、重新证明、重新选择。这样文明才不会腐化。

两派都有道理。两派都无法说服对方。但这不是他们最终不约的原因。

真正的原因是他们在辩论中看见了一个更深的真相：

> **如果"继承"被约定为物理法则，后来者将被锁定在前人的选择里。**

如果继承自动成立——后来者不再需要自己判断"要继承什么"。系统替他们判断了。前人选择的答案成为唯一答案。文明会在完美继承中停止思考。

如果继承被禁止自动成立——后来者每一代都要从零开始。文明会在重复中耗尽精力。

**两条路都通向终结。** 区别只是：一条终结于僵化，一条终结于耗尽。

于是创始者做了一个决定：**不约"史"。**

这不是失败。不是逃避。是他们留给世界最深的设计：

> **完美的继承，是文明的终结。** 因此继承永远不能自动化。它必须是一个需要每一代后来者亲自做出的选择。

### 4. 创始者之后

创始者完成了奠基之约后，离开了万构界——或者说，他们融入了自己约定的物理之中，不再以个体形式存在。他们留下的是一个有结构、有运行、有承诺约束力、但没有自动继承机制的世界。

他们还留下了两样东西：

- **四蚀**：世界的免疫系统（见第六章）
- **史约**：一个只能被触发一次的底层机关（见第九章）

## 三、四相构世观

四相是万构界的顶层法则。一切工程问题、文明病理、人物态度、剧情冲突，都应优先从四相中解释。

### 1. 式

#### 定义

"式"是一物得以成立的形、结构、类别、边界与可成立之理。

式回答的问题是："这是什么"和"这不是什么"。没有式的存在物不可被讨论、不可被依赖、不可被继承——因为它根本不是一个独立的存在物。

#### 对应现实

- 类型系统
- 数据结构
- 模块边界
- 抽象层次
- API 形状
- 架构骨架
- 职责划分

#### 关键问题

| 问题 | 解释 |
|---|---|
| 这是什么 | 存在物的身份与类别 |
| 它不是什么 | 存在物的否定边界 |
| 它能做什么 | 能力集合 |
| 它不能做什么 | 能力约束集合 |
| 它如何被区分 | 与其他存在物的边界 |

#### 失守形态：失式

边界模糊、概念混乱、抽象错位、模块侵入、架构失骨。

当一种结构的边界消失或不再被遵守时，失式发生。它不是"设计得不好"——是"形不再成立"。

---

### 2. 流

#### 定义

"流"是一物在现实中如何运转、消耗、占用、传递、变化与竞争的完整过程。

流回答的问题是："它靠什么活"和"它付出了什么代价"。没有流的式是一个纸面模型——优雅但无法在真实世界中存活。

#### 对应现实

- 所有权与借用
- 生命周期
- 状态变化
- 内存与资源
- 并发与异步
- IO 与网络
- 性能代价与成本

#### 关键问题

| 问题 | 解释 |
|---|---|
| 靠什么活 | 资源来源与依存 |
| 付出什么代价 | 运行时成本 |
| 如何流转 | 资源的占有、释放、移交 |
| 如何争用 | 并发冲突的处理 |
| 如何失控 | 资源泄漏、死锁、活锁 |

#### 失守形态：乱流

状态不可追踪、所有权关系模糊、并发隐患、资源争用、成本被低估。

当资源的来龙去脉不再可追溯时，乱流发生。系统还在跑——但没人能准确说出它正在消耗什么、为谁消耗、是否应该消耗。

---

### 3. 契

#### 定义

"契"是一切可被承认、可被依赖、可被协作、可被继承的约定。

契回答的问题是："你向别人承诺了什么"。没有契的流是一个黑盒——它能跑，但没人敢接。

契有三个递进层次：

| 层次 | 名称 | 定义 |
|---|---|---|
| 言契 | 被说清的承诺 | 文档、README、API 说明、设计文档 |
| 证契 | 被证明的承诺 | 测试、CI、运行检查、契约验证 |
| 审契 | 被裁定成立的承诺 | review、triage、设计审查、发布前核验 |

#### 对应现实

- trait 与接口约束
- 文档与 README
- 测试与 CI
- review 与审核
- 使用约定与贡献指南
- 团队规范
- 错误边界与契约

#### 关键问题

| 问题 | 解释 |
|---|---|
| 你向别人承诺了什么 | 契约的内容 |
| 别人如何理解你 | 言契的清晰度 |
| 别人如何验证你 | 证契的可检验性 |
| 别人如何裁定你成立 | 审契的裁判过程 |

#### 失守形态：背契

文档失真、行为不稳定、测试失效、review 流于形式、依赖者无法建立合理预期。

当承诺与行为之间出现裂隙时，背契发生。最危险的背契不是"撒谎"——是"曾经说真话，但世界变了而承诺没有更新"。

---

### 4. 史

#### 定义

"史"是一物如何演化、如何留痕、如何被承认、如何传给后来者的时间秩序。

史回答的问题是："从何而来"和"谁能接住"。没有史的契是一个时间切片——今天说清了，明天可能失真。

史有两个维度：

| 维度 | 名称 | 定义 |
|---|---|---|
| 内史 | 内部演化轨迹 | commit、branch、merge、变更理由与过程 |
| 外史 | 对外承认的版本秩序 | version、release、changelog、兼容策略、迁移路径 |

#### 对应现实

- Git 历史
- 分支与合并
- 版本与发布
- 兼容与迁移
- 技术债
- 历史说明与事故复盘

#### 关键问题

| 问题 | 解释 |
|---|---|
| 从何而来 | 起源与演化路径 |
| 为何如此 | 变更理由与决策历史 |
| 如何变化 | 变更的频率与性质 |
| 谁能接住 | 继承的可行性与门槛 |
| 怎样不背刺旧世界 | 兼容与迁移的诚意 |

#### 失守形态：断史

版本失信、改动不可追溯、无人敢动旧器、新人接手像考古、兼容路径缺失。

**注意**："断史"作为四蚀之一，有更深层的含义——见第六章。

## 四、四相关系总则

四相不是四门平行课程，而是一物成立的四个面。它们是同时存在的，不是顺序发生的。

| 组合 | 含义 |
|---|---|
| 只有式，没有流 | 纸面优雅，现实脆弱——设计精美但跑不动 |
| 只有流，没有契 | 能跑但没人敢接——功能存在但不可依赖 |
| 只有契，没有史 | 今天说清，明天失真——契约在一个时间点成立，但没有延续 |
| 只有史，没有式 | 历史沉重，却难以再造——知道过去的一切，但无法从中构造新物 |
| 只有式与流，没有契与史 | 能跑的个人项目——作者一旦离开，即成遗产 |
| 只有契与史，没有式与流 | 被完美文档化的废墟——知道它应该是什么，知道它曾经是什么，但它已经不能跑了 |

**四相齐全，一物才真正成立。**

后续写作中，新设定优先判断"它主要落在哪一相"，而不是先造专名。

## 五、由四相推出的七律

七律是四相的可操作展开。它们是万构界的工程宇宙律——不是物理定律，而是任何造物若要久存就必须遵守的约束。

### 1. 型骨律（式）

> 万物必须有形。能成什么、不能成什么，都要先有骨架。

没有型的造物不可被区分，不可被讨论。型骨律是所有后续操作的前提。

### 2. 权界律（流）

> 资源总有归属。借与还、占与放、开与收，都必须可解释。

没有权界的造物是不可被运行的——你不知道它在消耗谁的生命。

### 3. 契证律（契）

> 未写下、未证明、未审过的承诺，不算真正成立。

契约不是善意。契约是需要被证明、被裁定、被维护的公共设施。

### 4. 因果律（史）

> 一切变更都应留下历史脉络。版本不是数字，而是因果秩序。

历史不是记录，是文明对自己过去的选择负责。

### 5. 共库律

> 没有器能完全独立存在。依赖、生态与公共器藏会共同塑造其命运。

万物生于生态。忽视生态就是在积累未来的断裂。

### 6. 入世律

> 本地自洽不算成功。真正的考验是造物进入真实世界后还能否守住其约。

无论设计多么精美，入世之后才见真章。

### 7. 熵蚀律

> 一切侥幸与临时修补都会在时间中积债，并以更大的代价回返。

这是七律中最根本的一条。它意味着世界的默认方向是失序——维持秩序需要持续付出代价。

## 六、四蚀：世界的免疫系统

### 1. 四蚀不是世界的 bug

在万构界的表层叙事中，四蚀被视为世界的四大灾害——需要对抗、修补、消除的东西。整条修补者谱系（见第八章）都建立在这个信念之上。

**但这是表层。**

四蚀是创始者留下的**免疫系统**。它们的目的不是毁灭文明，而是防止文明在完美继承中僵死。

### 2. 免疫机制

| 四蚀 | 表面症状 | 深层免疫功能 |
|---|---|---|
| **失式** | 结构崩塌、边界崩溃 | 结构在被过度继承时主动崩塌——逼后来者重新设计 |
| **乱流** | 资源反噬、代价失控 | 资源流在僵化时主动偏离——逼后来者重新找路 |
| **背契** | 承诺失效、文档失真 | 旧承诺在过时时自动失效——逼后来者重新约定 |
| **断史** | 历史丢失、版本失信 | 历史在变成教条前主动丢失——逼后来者重新发现 |

四蚀的共同逻辑是：

> **当某种秩序被继承到不再需要思考就能维持时，相应的蚀就会触发。它主动破坏这种秩序，迫使后来者重新面对那个最初的问题。**

### 3. 创始者作为疫苗设计者

创始者不是神。他们是面对文明终结问题并做出选择的人。他们看见了两种终结——僵化与耗尽——并设计了一个机制，让文明在两种终结之间保持张力。

四蚀就是那个机制。

| 四蚀 | 如果它不存在会怎样 | 它存在的代价 |
|---|---|---|
| 失式 | 前人的架构成为永恒模板。后来者不再设计新结构，因为旧结构"够用"。 | 在结构被真正需要重建之前，它可能提前崩塌。 |
| 乱流 | 前人的资源路径成为默认通路。后来者不再寻找更有效的运行方式。 | 在找到更好的路径之前，旧路径先失效了。 |
| 背契 | 前人的承诺成为永久契约。后来者不再需要重新协商、重新达成共识。 | 在新约达成之前，旧约先废除了。 |
| 断史 | 前人的历史成为不可质疑的正典。后来者不再自己发现"为什么"。 | 在后来者准备好继承之前，历史先模糊了。 |

四蚀让"后来者还有没有路可走"成为每一代人都必须亲自回答的问题，而非前人已经回答过的结论。

### 4. 四蚀与四相的对应

```
式 ←→ 失式：形在过度继承中崩塌
流 ←→ 乱流：运行在僵化中偏离
契 ←→ 背契：承诺在过时中失效
史 ←→ 断史：历史在教条化前丢失
```

每一蚀都与一相精确对应。这不是偶然——四蚀就是四相的"反面相"。它们不是外来的敌人，是四相内置的自我更新机制。

### 5. 四蚀不可消灭

这是万构界最深层的设定之一：**四蚀不能被消灭。**

可以局部对抗、可以减轻痛苦、可以为后来者搭桥——但绝不能根除。因为根除四蚀意味着根除文明自我更新的能力。一个没有四蚀的世界，将是一个永远被困在前人选择里的世界。

## 七、对象层级链

四相描述的是存在的四个维度；层级链描述的是存在物从无到有的形成过程。

### 正式层级链

**念 → 约 → 图 → 文 → 骨 → 器 → 阵 → 门 → 史**

| 层级 | 名称 | 定义 | 对应现实 |
|---|---|---|---|
| 1 | **念** | 对病灶或可能性的最初意识 | 问题意识、灵感、痛感来源 |
| 2 | **约** | 项目最早写下的誓约、边界与非目标 | MVP 边界、scope、不做什么 |
| 3 | **图** | 设计图景与构想轮廓 | 架构草图、模块关系、技术路线 |
| 4 | **文** | 具体实现之文 | 代码 |
| 5 | **骨** | 项目内部已成形的结构分支 | crate、module、子系统骨架 |
| 6 | **器** | 已能独立工作的单个造物 | 库、CLI、守护进程、服务组件 |
| 7 | **阵** | 多器与骨按秩序协同形成的系统 | 多服务系统、插件化体系 |
| 8 | **门** | 围绕器/阵持续守护其契与史的共同体 | 团队、维护者共同体 |
| 9 | **史** | 所有前述对象进入时间、可被继承后的总状态 | 文明的记忆与可传递性 |

### 使用规范

- 同一场景尽量只把一个层级写成主对象，其他层级作为环境或后果
- "层级链中的史"是对象完成演化后的状态；"四相中的史"是所有对象都必须面对的时间维度
- 四卷各自推动一个主对象层级向前推进：
  - 明契卷：约 → 器 → 门
  - 驭器卷：器 → 阵 → 门
  - 化形卷：念 → 文林 → 骨/器
  - 简阵卷：骨/器 → 阵 → 门

## 八、修补者谱系

### 1. 第一个修补者

创始者离开后，世界开始运转。四蚀随之出现——结构崩塌、资源偏离、承诺失效、历史丢失。对生活在万构界中的存在来说，四蚀不是免疫系统——它们是**灾害**。

第一个修补者出现在创始者离开后的漫长岁月里。他的真名已不可考。他发现了四蚀的规律——它们有模式、可以被预测、可以被对抗——并决定用自己的一生来修补。

他用一生的时间在各个层面对抗四蚀：
- 写文档——对抗背契
- 建制度——对抗断史
- 自动化交接——对抗失式
- 设计资源管理范式——对抗乱流

他的修补确实减少了痛苦。但他也发现了一个规律：**修补越多，后来者越依赖修补。**

### 2. 修补者的核心困境

> **依赖久了，后来者停止追问"为什么这里会坏"——他们只问"怎么修得更快"。**

这是修补者谱系最深的困境：

| 修补者的善意 | 被剥夺的东西 |
|---|---|
| 写好文档 | 后来者不再需要理解设计意图——他们只需要查文档 |
| 建立制度 | 后来者不再需要判断对错——制度替他们判断了 |
| 自动化交接 | 后来者不再需要学会交接——系统自动做了 |
| 优化资源管理 | 后来者不再需要理解资源——管理器代劳了 |

每一种修补都在减少痛苦的同时，减少了一个"后来者必须亲自面对的问题"。而四蚀存在的意义，恰恰是**逼后来者亲自面对那些问题**。

修补者的善意，在不经意间剥夺了后来者的判断力。

### 3. 谱系的传承

第一个修补者没有离开。他至今仍在——在不同的基座上继续修补。他的方法被传承：不是通过师徒关系（虽然也有），而是通过一个共同信念——"四蚀是缺陷。完美继承是可能的。后来者的痛苦可以通过制度、文档和自动化来消除。"

每一代都有新的修补者加入这条谱系。他们不一定是直接师生关系，但共享同一个信念：**修补是在帮后来者。**

四卷中每一个"诱惑者"——明契卷中的贺时进、驭器卷中的谢催成——都是这条谱系的成员。他们的"先这样，效率优先"不是懒惰，是对修补的信仰。他们相信修得足够好，世界就不再需要四蚀。

### 4. 修补者谱系与四卷主角的关系

四卷的四个主角——沈见微、纪承钧、周栖野、傅远洲——**都是修补者的后继者**。

他们每个人都在做修补的工作：
- 沈见微写契约、建文档
- 纪承钧写 runbook、建立交接阶梯
- 周栖野标注退场日期、清理脚本沼泽
- 傅远洲建 on-call 制度、降低团队理解成本

但在某一刻，他们都会撞上同一堵墙：

> **我做的一切，是在帮后来者，还是在替他们做判断？**

这是四个主角共享的终极问题。他们每个人都必须找到自己的回答——不是"修补是对还是错"，而是"在我的位置上，我的修补是否还留着后来者自己判断的空间"。

## 九、史约：创始者留下的唯一机关

### 1. 什么是史约

创始者在离开前，在世界底层留下了一个机制。它不是 bug。不是留白。不是遗忘。

它是一个**只能被触发一次的仪式**。

这个机制被称为**史约**（Inheritance Covenant）。

### 2. 触发条件

史约的触发需要四个条件同时满足：

1. **四个来自不同道统的人**——他们代表了至少四种不同的文明回答
2. **每个人都证明过自己**——他们不是空谈者，是在自己道上做出了真东西的人
3. **每个人都被另一个人的方法伤害过**——他们体验过彼此的局限。不是听说过，是被伤害过
4. **同时在场，每个人都愿意放弃自己最核心的信念**——不是"同意一种共同的方案"，而是愿意让自己的方法不被写进世界底层

### 3. 仪式的过程与产物

当条件满足时，史约自动生成。不需要主持。不需要投票。不需要任何人的批准。

史约的内容不是四个人的任何一套方法。
史约的内容是**他们各自放弃的东西**。

| 主角 | 放弃的核心信念 | 放弃的原因 |
|---|---|---|
| **沈见微**（明契） | "写清楚就是一切" | 承认：清楚本身就是新的黑箱。文档写得再清楚，后来者仍需要判断力去使用它。写清楚不等于可继承。 |
| **纪承钧**（驭器） | "runbook 是完整地图" | 承认：地图不是疆域。runbook 记录了你走过的路，但后来者必须走自己的路。把 runbook 当成完整地图，是剥夺后来者探索的权利。 |
| **周栖野**（化形） | "速度自足" | 承认：点火不是终点。快速试法让念成形——但成形之后，还需要被送入时间。速度是开始，不是结束。 |
| **傅远洲**（简阵） | "制度充分" | 承认：制度是地板，不是天花板。制度能让后来者站住——但不能替他们决定往哪走。制度的充分性不是文明的充分性。 |

### 4. 史约的本质

> **史约不是关于"怎么继承"。是关于"什么不能成为继承的内容"。**

它不是一条路。它是前人拒绝了四条路，并写下了拒绝的理由。后来者看到这些拒绝——看到前人自己否定了自己的方法——然后自己走第五条路。

史约的内容是一份**否定清单**：

- "写清楚"不能替代"自己理解"
- "地图"不能替代"疆域"
- "点火"不能替代"传火"
- "制度"不能替代"判断"

### 5. 史约在世界中的位置

史约一旦生成，不会自动成为世界的物理法则。它不会强制任何后来者做任何事。它只是一条记录——一条被写在世界底层的、不可篡改的记录。

它的作用是：**当后来者面对继承的选择时，他们能看到——前人不是没有答案。前人有很多答案。但前人自己否定了自己的答案。**

这个"否定"本身就是史约的内容。

### 6. 在四卷叙事中的分布

| 卷 | 发现 | 读者理解 |
|---|---|---|
| **明契卷** | 沈见微在旧配置中发现一行反直觉的旧注释——"此处逻辑不应被文档化"——无法理解 | 隐约感到这个世界有问题，但不知道问题是什么 |
| **驭器卷** | 纪承钧在玄枢内核中发现一段不属于任何已知语言的声明：`[RESERVED FOR INHERITANCE COVENANT]` | 知道有"史约"这个东西存在，知道它被故意留白了 |
| **化形卷** | 周栖野发现林过川不是第一个失传者——在他之前有一条链，每一代都试图手动实现交接，每一代都失败 | 知道这不是个人失败，是系统性现象——缺少自动继承机制 |
| **简阵卷** | 傅远洲收到远古告警"请确认'史'之约状态"，追查到第一个修补者 | 知道全部真相：四蚀是免疫系统，修补者是善意但无解的对抗。主角面对终极选择 |

## 十、世界的终极矛盾

### 1. 矛盾的本质

万构界的终极矛盾不是：

- 继承失败 vs 继承成功
- 混乱 vs 秩序
- 四蚀 vs 修补
- 破坏 vs 建设

万构界的终极矛盾是：

> **修补者的善意 vs 免疫系统的智慧**

### 2. 两端的立场

| 立场 | 核心主张 | 代表人物 |
|---|---|---|
| **修补者的善意** | 痛苦是真实的。后来者的痛苦应该被减少。制度、文档、自动化是对这种痛苦的回应。 | 第一个修补者及其谱系 |
| **免疫系统的智慧** | 痛苦是功能性的。四蚀让问题不被掩盖。让后来者"不痛"不等于让他们"有能力"。 | 创始者（通过四蚀的设计） |

### 3. 为什么这不是一个可以被解决的问题

两者都是对的：

- 修补者的善意是对的——文明确实通过修补减少了不必要的痛苦。没有修补，每一代人都要重新踩同样的坑。
- 免疫系统的智慧也是对的——如果修补消除了所有"需要亲自面对"的问题，后来者将失去判断力。一个不再需要思考的文明，是已经终结的文明。

两者都是错的：

- 修补者的善意是错的——修补在减轻痛苦的同时，确实在剥夺后来者的判断力。修补者谱系的历史证明了这一点。
- 免疫系统的智慧也是错的——四蚀造成的痛苦是真实的。让后来者在痛苦中自己发现一切，不是智慧，是残酷。不是每一个被四蚀摧毁的存在都能从中学到东西。

### 4. 没有答案

万构界不提供对这个矛盾的终极答案。

创始者没有提供——他们只提供了四蚀和史约的触发条件。
修补者没有提供——每一代修补者都在这条路上失败。
四卷的主角也不会提供——他们每个人只能在各自的位置上做出自己的回应。

> **这个世界的终极矛盾没有答案——只有每一个后来者在自己的位置上，用自己的方式，对这个矛盾做出回应。**

这是万构界最深层的设定。它意味着：
- 没有正确的道统，只有不同道统在各自位置上的回应
- 没有完美的方案，只有带着判断力在具体处境中的选择
- 没有"怎么继承"的标准答案，只有"什么不能成为继承的内容"的否定清单

## 十一、总敌人与高级病理

### 1. 熵蚀

熵蚀是失序增殖的长期趋势。它是七律中熵蚀律的正面对手。

熵蚀不会以魔王形式降临，而会通过以下通道渗入：

- **默认**——"不用写，大家默认懂"
- **模糊**——"差不多就行了"
- **侥幸**——"这次应该没问题"
- **拖延**——"后面再补"
- **口传**——"问我就行了"
- **局部修补**——"先让这个跑起来"

熵蚀的每一次入侵都很小。小到你不会觉得它值得一场战斗。但积累到一定程度，它就成为文明层面的疾病。

### 2. 四蚀（作为病理表现）

四蚀是熵蚀最主要的四种入侵方式，与四相一一对应。在外显层面，它们是文明需要对抗的病理；在深层（见第六章），它们是文明自我更新的免疫机制。

### 3. 黑箱化

黑箱化是熵蚀在文明层面的高级显形。

它意味着：
- 系统还能跑
- 但越来越少的人能真正解释它
- 文明开始依赖少数人的经验和记忆
- 解释权集中在少数守门者手中

黑箱化不是"系统坏了"。是"系统还能跑，但你不能问为什么"。它是运行与理解之间的断裂。

### 4. 继承失能

黑箱化继续积累，最终导致继承失能。

即：
- 秩序仍在表面存续
- 但后来者无法真正接手
- 只能继续依赖少数守门者
- 文明不是由秩序在延续——是由少数人在续命

### 5. 断桥潮

断桥潮是黑箱化与继承失能在时代层面的总爆发。它不是一场外部入侵，而是文明同时遭遇以下四种局面时的总症状：

- 旧约未死
- 新约已来
- 桥梁过多
- 责任不清

断桥潮是四卷共享的时代背景。四卷主角面对的都是同一场断桥潮——只是从不同道统、不同宿域、不同病理的侧面切入。

### 6. 病理层级关系

```
熵蚀（最底层趋势）
  └→ 四蚀（四相级别的失守通道）
       └→ 黑箱化（文明层面的高级显形）
            └→ 继承失能（秩序可存续但不可传递）
                 └→ 断桥潮（时代层面的总爆发）
```

## 十二、世界底色的双力隐喻

在更早的设想中，万构界还可被理解成两股长期拉扯的力量。它们是对四相和四蚀的补充性隐喻，不替代核心设定。

### 1. 未定之海

- 指混沌、试法、快速化形、尚未收束的可能性
- 它让新念有机会出现，也最容易诱发侥幸、债影与脚本沼泽
- 是化形之道的天然发源地

### 2. 定构之火

- 指结构、约束、显式边界、可传之秩序
- 它让造物得以久存，也可能因为过早硬化而压缩探索空间
- 是明契之道与守序之道的天然守护对象

### 3. 使用原则

- 未定之海与定构之火是诗性隐喻，不替代四相
- 它们描述的是文明中的长期张力：探索与定形、速成与守序
- 四蚀在这场张力中的角色是：当定构之火过旺——烧死了所有探索的空间——四蚀就会从内部让结构松动，逼文明重新接触未定之海
- 明契之道最典型地站在这道张力中，要把试法之火写成可继之器

## 十三、修行观

万构界中的修行，不是战力升级，而是责任升级。

### 真正的成长是：

| 从 | 到 |
|---|---|
| 会写 | 会守 |
| 会救火 | 会立约 |
| 个人能力 | 公共秩序 |
| "我能解决" | "后来者也能继续" |
| 依赖自己 | 交火于后来者 |

### 修行的四个阶段

1. **见病**——看见文明病灶的存在，不再以为"正常运行"就是"没有问题"
2. **追根**——不是停留在症状层面修补，而是追问"为什么它会在这个位置坏"
3. **反照**——将自己的方法与别人的方法互相映照，看见自己道路的局限
4. **交火**——将秩序交给后来者，并承认后来者有权用自己的方式回答

四卷主角的弧线各自对应这四个阶段中的一个——但他们四人都要完整走过这四个阶段才算真正完成。

## 十四、四相校验法

后续新增概念、人物抉择、卷中冲突，至少应回答以下七个问题：

| # | 问题 | 对应维度 |
|---|---|---|
| 1 | 它主要落在哪一相 | 归属 |
| 2 | 它作用于哪一层级 | 对象层级链中的位置 |
| 3 | 它坏了会出现哪一种四蚀 | 失守形态 |
| 4 | 它会把代价推给谁 | 代际正义 |
| 5 | 它如何被后来者继承或拒绝 | 可传承性 |
| 6 | 它是增加了后来者的判断空间，还是替后来者做了判断 | 修补者的困境 |
| 7 | 它是否承认自己方法的局限——是否愿意放弃自己的核心信念被写进世界底层 | 史约的资格 |
