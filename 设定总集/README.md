# 万构界设定总集 README

## 1. 这个目录是什么

这里是《万构界》`00–22` 核心设定文件的统一主目录。

现在的目录口径是：

- `设定总集/00–22`：核心设定主文件
- 项目根目录：只保留项目入口、工作区和配套目录

这样做的目的，是把核心设定真正集中起来，避免继续散在项目根目录。

如果你要统一阅读、总览、交接或继续重构设定，优先从这里进入。

## 2. 这一组文件到底在服务什么

这 23 份文件共同承担四层任务：

### 第一层：解释万构界为什么成立

也就是：

- 世界是什么
- 四相是什么
- 为什么会有黑箱化、继承失能和断桥潮

### 第二层：解释四卷为什么这样排

也就是：

- 为什么第一卷是明契，而不是别卷
- 为什么四卷不是并列寓言，而是同一条事件链上的四段观察窗

### 第三层：解释小说怎么和教学同时成立

也就是：

- 正文负责什么
- 卷外配套负责什么
- 一卷里到底要教什么、推进什么、证明什么

### 第四层：约束后续新增内容不要把骨架写散

也就是：

- 新设定挂在哪个旧骨架上
- 新章节在结算哪一种四蚀
- 新人物在把代价留给谁

## 3. 世界观最核心的骨架

如果你只记住这一套设定里最重要的几件事，应该先记住下面这些。

### 1. 万构界是什么

万构界不是“代码施法”的世界，而是一个以工程文明为根的世界。

一切可久存之物都必须面对：

- 复杂度
- 时间
- 协作
- 代价
- 继承

### 2. 四相是什么

万构界的一切核心判断，优先从四相解释：

- `式`：结构、边界、骨架、分类
- `流`：资源、运行、状态、代价、争用
- `契`：承诺、文档、测试、规则、协作
- `史`：版本、迁移、兼容、发布、继承

### 3. 世界为什么会坏

四相失守后，会出现四蚀：

- 失式
- 乱流
- 背契
- 断史

四蚀继续积累，就会长成更高层病理：

- 黑箱化：系统还能跑，但越来越少的人能解释
- 继承失能：后来者无法真正接住
- 断桥潮：旧桥未死、新桥已来、过渡结构失衡

### 4. 万构界里的成长是什么

成长不是战力升级，而是责任升级：

- 从会写，到会守
- 从会修，到会立约
- 从个人能力，到公共秩序
- 从“我能解决”，到“后来者也能继续”

## 4. 第一阶段四卷和四门语言

当前第一阶段四卷固定为：

1. 《万构界·明契卷》
2. 《万构界·驭器卷》
3. 《万构界·化形卷》
4. 《万构界·简阵卷》

对应语言映照是：

- 明契之道：Rust
- 驭器之道：C++
- 化形之道：Python
- 简阵之道：Go

这一顺序不是按显世史排，也不是按常见新手顺序排，而是按《万构界》自己的概念发生顺序排：

- 明契卷：先立判断尺
- 驭器卷：再追病根
- 化形卷：再补生长侧
- 简阵卷：最后结系统总账

四卷整体结构是：

**见病 → 追根 → 反照 → 结账**

## 5. 四门语言在这一套设定里分别承担什么知识入口

### Rust / 明契之道

这里最重要的不是“语法更难”，而是：

- 为什么边界要先写明
- 为什么失败路径不能靠猜
- 为什么资源归属和长期维护必须前置

高频知识点：

- 所有权、借用、生命周期
- `Result` / `Option`
- `Cargo` / `workspace`
- `unsafe` / `FFI`
- 测试、文档、review、release

### C++ / 驭器之道

这里最重要的不是“更底层更强”，而是：

- 为什么古老重器值得敬畏
- 为什么重器容易长成少数人的秘义
- 为什么“只有我会修”会变成文明风险

高频知识点：

- build system
- ABI
- `FFI`
- profile / dump / trace
- wrapper / adapter
- runbook

### Python / 化形之道

这里最重要的不是“写得快”，而是：

- 为什么试法、notebook 和脚本真实有价值
- 为什么它们又最容易长成未来沼泽
- 怎样区分实验层、固核层和入世层

高频知识点：

- script
- notebook
- environment
- dependency lock
- package 化
- typing
- reproducibility

### Go / 简阵之道

这里最重要的不是“简单”，而是：

- 为什么规模化协作里真正的难题是共同理解成本
- 为什么表面简单常常只是把复杂藏到运行期
- 怎样让服务阵变得可共同维护

高频知识点：

- goroutine
- channel
- context
- service boundary
- deploy / rollback
- logs / tracing / metrics
- ownership / runbook

## 6. `00–22` 文件怎么分层看

### `00–07`：世界观基座

适合回答：

- 万构界的法则是什么
- 高层术语是什么意思
- 人物原型从哪里来

文件作用：

- `00`：总览与使用方法
- `01`：世界总纲、四相、四蚀
- `02`：层级链、机构、域与宿域
- `03`：诸道总纲与正式道统
- `04`：显世史、断桥潮、古道与新道冲突机制
- `05`：共构机制、工程映射、冲突规则
- `06`：人物谱系总则
- `07`：术语索引与关系总表

### `08–12`：四卷卷级设定

适合回答：

- 四卷各自讲什么
- 四卷主项目是什么
- 每卷的病理、人物阵型和卷尾产物是什么

### `13–18`：推进、命名与写作铁律

适合回答：

- 现在最该先做什么
- 一章一卷该怎样压
- 新内容不该破坏什么
- 系列命名怎么统一
- 四门语言的工程特性和玩梗来源是什么

### `19–22`：统摄性蓝图

适合回答：

- 整个项目到底教什么
- 四卷怎样共同组成一套教学型长篇
- 卷外配套如何分工
- 四卷共享的事件链是什么
