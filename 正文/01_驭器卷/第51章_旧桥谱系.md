# 驭器卷 · 第51章 · 旧桥谱系

残码的事过去几天后，纪承钧把注意力转到了另一个方向。

不是向内——向玄枢旧核更深处。是向外——向玄枢连接外部系统的那些"桥（bridge）"。卷五的考古翻出了残码——一份从比四道更早的时代传来的"继承之约"。但玄枢不只是被自己的旧代码围着。它还连着外面的世界——北岭设备集群、协阵扩域的子阵订阅方、外部调用方的跨道依赖——每一条连接都是一座桥。每一次玄枢断火，桥上的东西也一起断了。

纪承钧从接火阶梯的铁柜上取下一叠纸。纸的最上面——是他几天前写在残码页旁边的问题。"玄枢对外有多少条桥？每一条——是谁搭的？什么时候搭的？当时说的——是临时还是永久？"

他看向陆踏痕。"你上次翻 build_all.sh 的时候——有没有翻到关于桥的东西？"

"有一些。旧构建脚本里有几行——像是为了兼容外部系统加的。但那些行没有注释。不知道是在接什么。"

"那就从那里开始。"

· · ·

陆踏痕用 Git 石录（version control history）追溯每一条桥的第一次提交（first commit）。不是一次追溯——是几十次。每条桥的 commit message 他一个个打开读。纪承钧在旁边记录。

第一条桥——wrapper——连接玄枢核心和北岭设备集群。commit message：「临时方案——等新版本出来就删」。提交日期：十一年前。提交者：一个早已不在玄枢的名字。

"十一年。"陆踏痕盯着那行字。"Git 石录本身也才十几年的历史。这条桥——几乎是和 Git 同岁的。"

第二条桥——shim——在玄枢和一个协阵扩域的旧子阵之间。commit message：「先搭上——回头再拆」。提交日期：九年前。提交者：另一个不在的名字。

第三条——「临时的。不要依赖。——七年前的。」第四条——「紧急——北岭接口变了，先这样接上。后面整理。——五年前。」第五条——「不保证稳定。只保证能跑。——四年前。」第六条——「同上。——三年前。」

陆踏痕停住了。"第六条。commit message 是'同上'。他连写清楚这是什么都不愿意了。"

"因为前面已经有五条了。"纪承钧在纸上画了一道线。"第六条的人——看到前五条都没拆——就知道第六条也不会被追究。桥越多——搭桥越轻率。"

他们继续。一个下午——纪承钧的纸上列满了。不是五条。不是十条。

十七条。

· · ·

沈照痕带着观测面板（observability panel）的数据过来的时候，天已经黑了。

他把一张石镜拓片放在纪承钧的旧石案上。拓片上是一列数字——每条桥在过去一个月内被调用的次数。

"这条——最老的那条 wrapper——每月被调用三万次。"沈照痕的手指在数字上点了点。"没人知道它还在被用。因为调用方不直接调它——他们调的是 wrapper 后面的接口。但 wrapper 夹在中间——每一次调用都经过它——每一次 wrapper 都在静默截断不符合它假设的数据。"

"它假设什么？"

"它假设输入永远是非负整数。两年前——北岭的一个系统升级了——开始传浮点数（floating-point number）。wrapper 截断了——尾数丢了——但恰好——在那边的使用场景里——丢掉的尾数不影响结果。不是 wrapper 设计得好——是恰好——用 wrapper 的人——恰好不依赖被截断的那部分数据。"

"恰好。"

"对。恰好。不是安全——是恰好。如果北岭升级的是另一个模块——恰好不成立——这条 wrapper 会在凌晨——炸掉所有依赖它的调用链。"

· · ·

那天晚上，纪承钧把十七条桥列成了一张表。表上每一行：

| 桥名 | 类型 | 出生时间 | 出生原因 | 最后活跃 | 依赖方数 | 退场日期 |
|------|------|---------|---------|---------|---------|---------|
| 北岭-wrapper | wrapper | 11年前 | "临时方案" | 活跃 | 3 | — |
| 协阵-shim | shim | 9年前 | "先搭上" | 活跃 | 1 | — |
| ... | ... | ... | ... | ... | ... | ... |

十七行。每一行的"退场日期"那一栏——空白。

他算了一下。十七条桥的平均年龄——四点七年。最老的那条——十一年。十一年前——Git 还没被发明。那条桥的历史——没有 commit 记录。它的"出生证明"——是旧文件柜里的一个文件夹备份——封面上贴着一张褪色的标签，上面手写着四个字：「北岭接口」。

陆踏痕站在表旁边。看了很久。

"十七条桥。十一条的 commit message 里有'临时'两个字。六条有'等新版本'。四条有'回头拆'。一条——第六条——直接写了'同上'。十条的提交者已经不在玄枢。最老的那条——搭桥的人离职七年了。"

他停了一下。

"没有一条的 commit message 里有退场日期。没有一条。不是忘了写——是没有打算退。'临时'——只是搭桥时让自己心安的说法。不是对后来者的承诺。"

· · ·

沈照痕从观测台那边过来。他刚才一直在看桥的运行时数据。

"还有一件事。"他把另一张拓片放在表上。"这十七条桥——不是独立的。它们之间有依赖。wrapper 的输出——被 shim 当作输入。shim 的输出——进了 adapter——adapter 再转给北岭。这是一条链。不是十七座孤立的桥——是一张网。拆一座——链断了——其他桥上的东西——也掉下来。"

"就是说——"

"就是说——不能一座一座拆。要拆——得看懂整张网。"

纪承钧沉默了一会儿。然后把桥谱系表翻到背面——开始画桥之间的依赖关系。不是直线——是网。十七条桥——有的串联——有的并联——有的既是串联又是并联——取决于从哪个角度看。

画完之后——整张纸像一张蜘蛛网。每一根丝——都是某个人在凌晨——写下"临时"——然后搭上去的。

· · ·

两天后。顾迁舟来了。

顾迁舟是化形卷（Python·息壤）的人——渡桥人（bridge keeper）。他在化形卷那边管着一本桥账——记录息壤连接外部系统的所有桥。他的腰上挂着一本旧册子——册子的封面写着"桥账——息壤"——里面是一页页桥的记录：搭桥时间、类型、依赖方、退场日期。每一页——退场日期那一栏——都填着。

纪承钧在玄枢的值守卫室接待他。钟守玄也在——坐在角落里，手里捧着一杯白开水。

顾迁舟把桥账放在桌上。翻开第一页。

"化形卷那边——在拆桥。一年拆了六条。拆桥的前提——不是有勇气。是每座桥都有出生证（birth certificate）。搭的时候登记——退场日期写清楚——到期续——不续就拆。"

他看着纪承钧的桥谱系表。

"你这里——十七条——退场日期全是空的。"

"我们的桥——搭的时候都说'临时'。"

"化形卷那边也这么说。后来我们发现——只要允许搭桥的人不写退场日期——桥就永远不会拆。人希望桥是临时的——所以不写日期。不写日期——桥就变成了永久的。不是人骗人——是人的希望——骗了自己。"

他从桥账里抽出一页模板。模板上——搭桥时间、类型、依赖方、退场日期、续期条件——每一项都有。

"化形卷的制度——一条新桥——不填退场日期——不许搭。到期不续——自动进入拆除队列。你可以延期——但不能永久。延期最多两次。两次之后——必须写报告——解释为什么这座桥不能拆——有什么替代方案——替代方案什么时候落地。"

钟守玄在角落里开口了。声音不大——但在值守卫室里很稳。

"你们的制度——对临时的定义——是什么？"

顾迁舟转向他。"临时的——就是有明确的结束日期。没有结束日期的——不是临时的——是不愿意承认的永久。"

钟守玄喝了一口白开水。然后缓缓说了一句。

"在玄枢——临时的意思——是'暂时不管'。"

"那就是永久。"

钟守玄没有反驳。他把杯子放在膝盖上。过了好一会儿——才说了一句。"是。"

· · ·

那天下午，纪承钧和顾迁舟一起把十七条桥重新审视了一遍。

顾迁舟用化形卷的分类法——wrapper / adapter / shim / bridge / façade——给每条桥重新分类。不是按外观——是按结构脆弱性。哪类桥最容易出问题——哪类桥最难拆——哪类桥看起来稳定——实际上只是因为没人在意。

"wrapper 是最危险的。"顾迁舟说。"因为它夹在中间。调用方以为自己在调接口——实际上每一层都被 wrapper 截了。wrapper 的所有假设——都在它的代码里——但代码没有文档。如果假设被打破——静默失败——不是崩溃——是结果悄悄变错。静默失败最难发现——因为没有人被叫醒——直到有人发现账对不上。"

"那条最老的 wrapper——十一年——假设了非负整数。"

"两年前被打破了。"

"对——恰好没出事。"

"恰好。"顾迁舟在 wrapper 那一行上画了一个圈。"不是工程——是运气。我们不能靠运气。"

· · ·

傍晚。纪承钧把桥谱系正式放入接火阶梯的铁柜。在接火阶梯的第三层——判断框架——他开了一个新格。格子的标题：「桥谱系」。

格子里放了三样东西。

第一样——桥谱系表。十七条桥——每一条的类型、出生时间、出生原因、最后活跃时间、依赖方数量——和永远空白的退场日期栏。

第二样——桥的依赖网。那张画在表背面的蜘蛛网——被他抄正——标注了每条桥的脆弱性等级和关键依赖点。

第三样——顾迁舟留下的桥账模板。化形卷的格式。退场日期、续期条件、延期上限。每一栏——都在说——"桥——不是永久的。"

他在第三样的旁边——写了一段标注。

"桥谱系。玄枢对外十七条连接。分类方法来自化形卷渡桥人顾迁舟（wrapper/adapter/shim/bridge/façade）。每一条桥——出生时都被称为'临时'。平均年龄四点七年。最老的十一年。没有一条有退场日期。原因——不是因为桥不能拆——是因为制度允许搭桥的人不写退场日期。制度假设人会诚实地为'临时'设定终点。人假设'临时'就是暂时——不需要终点。两个假设互相给对方面子——结果——桥永远活下去。——纪承钧。——前提：此谱系基于 Git 石录和构建日志追溯。Git 之前的桥——历史不全。——待后来者补充。"

他退了一步。

铁柜上——最上面是留白。接火阶梯第二层是考古地图。第三层——现在多了桥谱系。

陆踏痕在旁边看着。然后说了一句话。

"十七条桥。每一条的 commit message——都像在看一面镜子。不是在看他们的'临时'——是在看——我们以后——会不会也写'临时'——然后不管它——让它活到十一年——等后来的人——在凌晨——撞上它。"

· · ·

那天深夜。顾迁舟在离开玄枢之前——在值守卫室和钟守玄对坐了一会儿。

"你守了多久？"顾迁舟问。

"十几年。"

"化形卷的守门者——叶藏拙——也守了很久。他说——守——不是不让桥断——是让桥断了之后——还有人知道怎么接。"

钟守玄看着手中那杯已经凉透的白开水。

"在玄枢——断了之后——接的人。以前是我。"

"现在呢？"

钟守玄看了看接火阶梯的铁柜。纪承钧还在那边——往桥谱系的格子里补充陆踏痕刚算出来的一组数字——每条桥每年引发的事故或困惑次数。

"现在——接的人——不止我一个了。"

顾迁舟在那页临走前的笔记上写了一行。然后合上桥账。走出值守卫室——走进玄枢凌晨散热塔的灰色轮廓里。

卷六开始。旧桥——不是被谴责的。是被看见的。从不可见到可见——是第一步。接下来——是什么样的桥——怎么拆——怎么让后来者——不需要搭同样的桥来追前人的临时。

章末——纪承钧在桥谱系表最下面——写了一行小字。

"接手的——你也要写。——纪承钧。前提：这行字——是从卫千枢的散页上抄来的。——现在——传给你。"
