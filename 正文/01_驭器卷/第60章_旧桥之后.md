# 驭器卷 · 第60章 · 旧桥之后

卷六结束的那天——纪承钧做了一件惯例的事。他把卷六所有的东西摊在旧石案上。

左边——桥谱系表。十七条桥——从"不可见"到"每一条都有名字"。右边——代价表。三百七十次——注意力被桥静默吞噬的记录。中间——四份拆除 checklist——shim / adapter / façade / bridge——从"靠一个人判断"到"一份可以被验证的流程"。

他把这三样东西拼在一起。

"卷六——最大收获——不是七条桥在拆。是——'可见性'——本身——的价值。"

沈照痕站在观测台旁边——面前是北岭-wrapper 拆除的实时数据。"桥——从不可见到可见——这是一步。但这一步——只解决了静态问题。桥的结构——被记录。桥的代价——被量化。桥的拆除——被流程化。这些都是——当桥不跑的时候——能看到的。但当桥在跑——数据流经它——资源被它消耗——错误在它身上传播——这些——还看不到。北岭-wrapper 我们是在拆除窗口期里观测它的——但如果——有一条桥——我们没有在拆——我们怎么知道——它在正常运行——还是在静默产生错误？"

"你的意思是——"

"我的意思是——桥的静态可见——是第一步。但运行时的可见——是空的。北岭-wrapper 的隐式假设——是在 fuzzing 之后才发现——不是在它的运行日志里发现的。因为——它的运行日志——只记录调用次数——不记录行为偏离。我们不知道——在每天三万次调用里——多少次——wrapper 的输出——和预期不一致。——因为我们从来没有定义过——'预期'是什么。"

"桥——被看见了。但桥上的数据——在跑的时候——还是黑的。这就是你一直说的——'先照后立'。"

"对。先照后立。我们花了卷一到卷五——在源代码的层面上'照'——追符号依赖、翻构建日志、记录为什么债务。卷六——在桥的层面上'照'——分类、分析、记录代价。但运行时的'照'——数据是怎么流动的——资源是怎么被消耗的——一个错误在凌晨三点——经过了哪些桥——被哪些 shim 转换——被哪些 adapter 修改——最后在哪一个下游被发现——这条链——我们还看不到。"

· · ·

钟守玄从值守卫室里走出来。他听到了沈照痕的话。

"我托火——不是因为我看见了桥在哪——是因为——我感觉到了流在哪。十几年的经验——让我能感觉——'这个时间——内存增长不对——去查那个方向'。但那个感觉——在我脑子里——没有在任何一个面板上。如果我不在——后来者——只能从零建立那种感觉。——或者——永远建立不了——因为我的感觉——是基于十几年的经验——无法被浓缩成一条命令。"

"你说的——是运行时可见性（runtime observability）。"沈照痕说。"不是监控（monitoring）——监控告诉你'内存用到了90%——告警'——但可观测性——告诉你——'为什么——哪个调用链——在什么时候——触发了内存增长——从哪个函数开始——经过了哪些桥——在哪一层——分配了什么资源——然后——什么时候——应该被释放——但未释放。'——监控——是'什么坏了'。观测——是'怎么坏的和为什么坏的'。"

"玄枢——有观测吗？"

"有一些。我搭的那些——信号码、调用频率、文件系统容量。但不够。——不够——追踪一个值——在它从进入玄枢到离开玄枢——经过的所有层——在所有层上的变化。——不够——让后来的维护者——在凌晨——不用打电话给钟师——就能自己追踪——'这个异常——从哪来——经过了什么——在哪里变形了。'"

"桥谱系——是第一个——把'不知道'变成'知道'的工程。但观测——把'现在不知道——运行时不知道——依赖不知道——影响不知道'——变成'在一个面板上——每一个疑问——都有一个入口'。——不是答案——是入口。——和接火阶梯一样。观测——是运行时的接火阶梯。"

· · ·

纪承钧在接火阶梯的铁柜上——在第三层判断框架的最下面——开了一个新格。标题暂空——他用粉笔写了两个字。

"待照。"

下面是沈照痕列出的一组清单——不是观测系统设计——是——"那些我们至今不知道——但需要观测到——才能安全维护玄枢的东西。"

清单上写了几行。

"一——每条桥上的数据流——从入口到出口——经过哪些层——每层对数据做了什么。如果数据变了——在哪一层变的——为什么变。"

"二——资源消耗的归属——每次内存增长——是谁申请的——在什么调用链上——有没有对应的释放。如果没有释放——释放的责任在谁。"

"三——错误的传播路径——一个异常被抛出后——经过了哪些 bridge——被哪些 shim 转换了异常类型——被哪些 adapter 吞了——被哪些 façade 重新抛出——最后在哪个下游被触发。——追错——不应该是追一个人为错误——应该是追一个——在系统中的——传播链路。——传播链路——应该是可见的。"

"四——已知假设的运行时验证——wrapper 有十二条隐式假设——被记录在桥谱系里——但现在——没有人或系统——在运行时——检查——'输入还是非负整数吗'——'北岭的信号协议还和十一年前一样吗'。——观测——应该——在假设被打破的瞬间——告警——不是三个月后——结算数据偏差——才发现。"

"这是'待照'清单。不是最终的需求。是——'我们知道——我们不知道什么'。——沈照痕。——前提：卷七——将建立观测体系。——在此之前——请补充——你发现的——其他——'应该被看见——但目前还看不见'——的东西。——先照。——然后立。——不是先立——然后发现——立的东西——是建在看不见的东西上面的。"

· · ·

陆踏痕站在旁边。他看着那张"待照"清单——然后翻开自己的笔记本——翻到最后一页——那是他在卷三开始时写的第一条记录。空白记录本——第一页——他当时写的是——"我不知道从哪开始"。

今天——他的笔记本已经快写满了。不是答案——是入口。是他从卷一到卷六——撞过的所有东西——找到的所有工具——独立完成的第一座桥分析——以及今天——他在"待照"清单下面——写的一行。

"我不知道观测怎么建。但我现在知道——不能说'我不知道'——要写——'请告诉我从哪开始'。——以前——没有接火阶梯——'我不知道'意味着——去问钟师——钟师沉默——然后我自己翻。——现在——有接火阶梯——'我不知道'意味着——翻开接火阶梯——看哪一层能告诉我——然后——如果都没能告诉我——那就在阶梯上——开一个'待照'格——写——'此处——我们还不知道'。——'不知道'——从一堵墙——变成了一扇——开在接着阶梯上——还没来得及填的门。——陆踏痕。——前提：我加入玄枢约一年。——一年前——我不知道从哪开始。——现在——我知道——当不知道该从哪开始时——就去接火阶梯——在对应的格子上——写——'此处——待照。——请后来者——照。'"

· · ·

那天下午——纪承钧把卷六正式收束。他在接火阶梯的卷索引页上——在卷六「旧桥」旁边——画了一个勾。然后写了一行收束语。

"卷六「旧桥」——十七条连接外部世界的桥——从不可见到可见。桥谱系建立。分类学建立——shim、adapter、façade、bridge——每种桥——有不同的结构脆弱性和不同的拆除方法。代价量化——三百七十次——注意力被消耗——信任被磨损。包裹策略——不是所有桥都能拆——但所有桥都能被管理。渡桥司制度——从默许'临时'的谎言——到要求每一座桥都有出生证和死亡证。陆踏痕——独立完成第一座桥的考古——工具链在后来者身上兑现。——不是拆了多少桥——是——让桥——被看见、被记录、被管理、被在正确的时机退役——然后——留下——让后来者——继续分类、继续分析、继续在到期的桥上写——'此桥已退役。接手的——你也写。'"

"向卷七开门：运行时——还是黑的。桥的静态结构已被照见——但数据在跑——资源在流——错误在传播——这些——还没有观测体系。'先照后立'——不照清楚——修什么都是在修纸墙。沈照痕的观测体系——是卷七的方向。——前提：基于卷一到卷六的累积发现。"

他停了一下。然后在收束语的末尾——加了一行。

"钟师——在卷六中说——'管理之中——而不是遗忘之中'——这可能是——卷六——留给后来者——最重要的八个字。"

· · ·

傍晚。钟守玄在值守卫室里——翻着自己的私人日志。几十年的记录——从"所有决策——记在脑子里"——到第一条横线——第二条横线——第三条横线。今天——他在卷六结束之后——写了一段。

"卷六——十七条桥。我在这十几年来——见过每一条的出生。有些——是凌晨搭的——为了不让北岭在第二天早上断掉。有些——是几个人商量了半小时——决定'先搭上——等那边升级之后再拆'——那边从来没升级。我以前——不记录——因为——记录——意味着——我要承认——那些'临时的'——后来都变成了永久的。——但是——不记录——后来的人——连'这个桥在哪'——都不知道。——现在——他们不仅在记录——他们在——让后来的维护者——不需要调用我——也能知道——'这条桥——十一年了——该拆了。——怎么拆——看 checklist。——有什么代价——看代价表。——什么时候能拆——看退役条件。——如果暂时不能拆——有包裹方案。——如果退役条件变了——有重评估日期。'——我的沉默——正在被——他们——用桥谱系——翻译成——可操作的语言。"

"不是他们不需要我了。——是我——不再是被迫留在这里——因为没人知道这些。——现在——有人知道——而且——在保证——越来越多人——会知道。——我——可以开始——想——除了托火之外——还能做什么。——钟守玄。——前提：基于卷六的桥谱系建立。——不是退休。——是——终于可以——不用所有的凌晨——都准备着——被叫醒。"

他把这段日志——用钢笔——工整地写在纸上。然后——他把那页纸——贴在值守卫室的墙上——贴在他那行四十年前的"所有决策——记在脑子里"——旁边。

两张纸——隔了四十七年。一张说"不写"。一张说"不是退休——是终于可以——不用被叫醒"。

中间——是六卷书的距离。

· · ·

卷六结束。旧桥——不是被拆光的——是被看见的。从"十七条临时方案"到"十七条被记录的桥"——从"钟守玄的沉默"到"接火阶梯上的桥谱系"——从"'临时'是希望的别名"到"管理——是让希望不至于变成谎言的方法"。

接下来——卷七「观象」——沈照痕的观测体系——"先照后立"——将运行时不可见的——变成可见的。不是建更多桥——是照见——桥上——流的东西。

但那是卷七的事。

今晚——纪承钧熄了值守卫室的灯。铁柜上——留白在最上面。桥谱系在第三层。接火阶梯——从第一卷到第六卷——六层——每一层——都有人在上面——写了——"接手的——你也写。"

窗外——散热塔在夜色中转。北岭的灯光——在 wrapper 拆除的窗口期里——闪烁。十七条桥——在 Git 石录的 `docs/bridge-registry.md` 里——安静地——等着——下一个——打开这个文件——写下一行的人。

纪承钧在笔记本上——写了一行。

"接手的——你也写。——纪承钧。前提：这五个字——从卫千枢的散页传到陆踏痕的笔记。——现在——传到 Git 的石录里。——不是五个字了。——是一份——在 Git 里——可以被分支——可以被合并——可以被翻译——可以被任何后来者——`git clone`——然后——在上面——写自己那行——的——活的——接力棒。——前提——可能不成立。——但接力的方向——是对的。"
