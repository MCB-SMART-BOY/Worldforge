# 驭器卷 · 第95章 · 第三步的前提

Runbook 发出后几天，纪承钧开始不安。

不是收到了什么消息——恰恰相反，什么都没收到。息壤那边没有回音。没有"收到了，谢谢"，没有"第三步我们不太明白"，没有"你的前提声明写得很好"。沉默——像沈见微的诊断报告发出后，在到达玄枢之前的那段安静。

他开始重新审视自己写的十七步。逐条。逐句。问自己同一个问题："这一步，在什么前提下成立？"

第三步——"确认所有下游依赖方已全部迁移，或已收到迁移通知并在窗口期内。如果依赖方无法确认，标记'待确认'——不可在确认之前拆除。"

在玄枢，这一步的前提是：依赖声明制度存在。外部依赖方地图存在。三十七个调用方中至少有十二个能说清自己在依赖什么。北岭的秦叔平能翻出十几年的接口记录。桥谱系记录了每条桥的依赖方数量。观没面板能追踪每条调用链的源头。这些前提在玄枢成立——因为纪承钧、钟守玄、沈照痕、陆踏痕花了卷三到卷八，整整六卷的篇幅，才把它们建立起来。

但在息壤——这些前提成立吗？

他翻开顾迁舟留下的桥账模板。那是化形卷渡桥人的记录格式——搭桥时间、类型、依赖方、退场日期。格式很清楚——但顾迁舟在模板的空白处写了一行小字："以下依赖方——据搭桥人自述。未经独立验证。息壤无系统化依赖追踪机制。"

顾迁舟知道。他在化形卷那边，在"先让脚本跑起来"的文化里，一个人维护着桥账——但他只能记录搭桥人告诉他的东西。搭桥人自己——可能也不知道桥上有多少人在走。因为息壤的脚本林（script forest）——那些成百上千的 Python 脚本——调用关系不是通过接口声明，而是通过 `import`、`subprocess.call`、甚至 `os.system()`——藏在字符串里，藏在运行时动态生成的命令里，没有任何静态分析工具能自动绘制完整的依赖图。

"第三步——在玄枢成立的前提，在息壤不存在。"

沈照痕站在观测台前，听着纪承钧的反思。他没有说"我早告诉过你"。他说的是另一句话。

"你的 runbook 不是错的。是需要考古前提的。你假设了一个已经被建立好的依赖地图。但息壤——可能还在地图都没有的阶段。不是他们不努力——是他们的工程文化，奖励的是'快速跑起来'，不是'确认所有依赖'。你写的第三步，在玄枢是常识。在息壤，是奢侈。"

"我把玄枢当成了'正常'。"

"每个人都把自己的世界当成正常。你在玄枢太久，忘了依赖声明制度是花了多长时间才建起来的。那不是起点——那是个成就。"

· · ·

纪承钧把十七步 runbook 摊在旧石案上。第三步，第七步，第十一步，第十五步——每一条都隐含了依赖声明制度的前提。第十五步甚至写了"更新渡桥司登记册"——渡桥司在化形卷那边的覆盖范围，他自己都不清楚。也许在息壤，根本没有渡桥司的登记员。也许季容的那套制度还没推广到那边。也许推广了——但息壤的桥太多、太老、太乱，登记册还没追上。

"我在给一个我不了解的世界写操作手册。我把我的手伸进了一个我不知道形状的机器里，然后说'按这个方向转'——但我不知道那个机器有没有齿轮，或者齿轮是不是反着转的。"

钟守玄坐在值守卫室的角落，手里照常一杯白开水。他听着纪承钧的反思，沉默了很久。然后开口。

"你现在知道，为什么我怕给别人写东西了。我写的，都是我脑子里的地图。别人没有我的地图，看了会走到沟里。不是地图错了——是地图没画它依赖的疆域。疆域在每个人脑子里，不在纸上。"

"但你不写，后来者连地图都没有。"

"对。所以不是不写——是写了之后，要告诉别人，这地图没画完。你写了前提声明，写了'玄枢的前提和息壤的前提可能不同'。这很好。但前提声明本身，也有前提——它假设读者知道'玄枢的前提'是什么。息壤的读者，从没来过玄枢，她读到'玄枢的前提和息壤的前提可能不同'——她不知道这意味着什么。因为她的世界里，没有'依赖声明'这个东西。她甚至不知道自己在缺这个东西。"

"那前提声明该怎么写？"

"不知道。但也许——不是写'前提可能不同'。是写'在我们这里，这一步能成立，是因为我们有以下几个具体的东西：桥谱系、依赖声明制度、外部依赖方地图。如果你们没有这些——这一步不适用。请先建立这些，或者跳过这一步，直接联系我们。'——不是抽象地承认局限。是具体地列出前提。"

纪承钧把这个想法记了下来。不是修改已经发出去的 runbook——改已经晚了，它在息壤的路上。但他可以在下一版，在所有未来的 runbook 上，把前提声明从抽象变成具体——不是"前提可能不成立"，是"以下前提在我们这里成立。请逐条核对在你的世界是否成立。如果不成立，这一步对你的世界——不适用。"

卷十还在继续。但纪承钧已经感觉到底下有一个东西在等着他。不是来自玄枢——是来自息壤。一份回信，或者一次沉默之后的爆炸。他不知道会是什么，但他知道——就像沈见微不知道 Makefile 注释里的 socket 一样——有一个他不知道的东西，正在他不知道的地方，朝着他的 runbook 走过来。
