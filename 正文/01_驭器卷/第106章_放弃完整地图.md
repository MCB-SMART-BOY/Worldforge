# 驭器卷 · 第106章 · 放弃"完整地图"

听完钟守玄的揭示之后，纪承钧一个人坐在控制台前。面前是所有 runbook——他写的，钟守玄写的，陆踏痕补充的。沉默了很久。比以往任何一次都久。

他的核心信念，从卷一开始建立的——"runbook 是完整地图，只要有好的 runbook，后来者就能自己走"——被三个事件击穿了。

第一个事件：沈见微的诊断报告炸了玄枢。一份做了所有对的事的文档，在一个不知道的语境里变成了灾难。不是内容错了，是内容依赖的前提在玄枢不成立。第二个事件：他自己的 runbook 炸了息壤。同样的事情，反过来。他做了所有对的事，十七步每一步都基于玄枢的扎实经验，但第三步依赖的前提——依赖声明制度——在息壤不存在。第三个事件：钟守玄揭示修补者故意留裂痕。修补者修到一半停下，不是修不好，是留下入口让后来者自己发现。那么多代人，每一代都在追求"完整"，而那个最接近答案的人，选择了留白。

三件事指向同一个结论。"完整"是不可能的。不是因为做得不够好——是因为疆域在每个世界里都不同，而地图永远只能画出一个疆域。跨过边界，地图就不准了。这不是能被"更努力"克服的局限——这是所有地图的本质局限。

他拿起笔，在每一份 runbook 的第一页写下了放弃声明。

"此 runbook 画于玄枢，大灾后第三年，基座为 Linux x86_64 + gcc 11 + CMake 3.22。以下内容的考古前提——在你的世界里可能不成立。如果不在——你来画。我在空白页等你。"

这不是投降。是承认。承认 runbook 不是完整地图，而是考古记录——某个人在特定时间、特定基座、有限已知范围内画的图。它的价值不在地图的完整，在地图上有画图人的脚印。后来者能看到他是怎么画的，他哪里走对了，哪里走错了，哪里根本没走过。

他放弃了"runbook 是完整地图"的信念。不是放弃 runbook。是把 runbook 从"真理"降级为"工具"——有前提、有边界、有空白页等后来者补充的工具。这个降级不是失败，是升级。更诚实的工具比更完美的幻觉有用。诚实不是"我很弱"——是"我知道我的地图的边界在哪里"。标注边界的地图，比假装覆盖一切的地图，对后来者更负责。假设地图完整而踩进深渊的人，比拿到一份标注了边界的残缺地图而选择绕路的人，摔得更重。

"我放弃的不是 runbook，是'完整'的幻觉。承认局限，不是背叛前人的积累——是让前人的积累变得安全。前人画的地图，后人看到边界，就知道过了那条线需要自己判断。前人没有标注边界的地图，后人以为全境安全，一直走到地图外面——然后摔了。标注边界，是对前人最好的尊重。不是否定他们画的部分——是让后来者知道他们画的部分在哪里结束。"

他在留白处加了一行："这里不是空的。是'此处——你来。'——前人只能到这里。后来者，你来——画你的部分。前提可能不成立。"
