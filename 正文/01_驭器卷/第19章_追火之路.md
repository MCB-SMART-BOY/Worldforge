# 驭器卷 · 第19章 · 追火之路

苏野平离开后的第五天，纪承钧在值守台的旧石案上铺开了三样东西。

左边：他画了两周的玄枢依赖图——两百多条线，二十三个外部系统，十七处"临时"标注。中间：苏野平留下的跨道依赖分析——七处值得追的箭头，每一处末尾都有前提声明。右边：钟守玄的口述记录——纪承钧花了四个晚上，把每次钟守玄提到卫千枢的片段拼在一起，按时间线排了一页。

三样东西拼在一起，拼出了一条路。

一条向下的路。

他把三样东西看了很久。然后从旧石案下摸出一叠空白纸，在第一页上写了标题：

"玄枢追火考古计划。"

下面是三段。每一段前面有一个数字。不是编号——是深度。

"壹——构建系统考古层。从手写编译命令到第一个 Makefile 的过渡。目标：找到构建依赖的原始继承链。已知：玄枢目前使用的构建流程是三代叠出来的——最底层还有 autotools（`自动化构建工具链`）的残余。关键节点：第一个 Makefile 是谁写的？为什么选择 Make 而不是别的？当时支持什么平台？这些选择——决定着今天的每一个构建警告（`warning`）是'可以忽略的'还是'必须修的'。负责人：纪承钧。助手：陆踏痕。工具：沈照痕提供的旧观测日志回溯（`historical monitoring log replay`）。"

"贰——知识断层考古层。从卫千枢离开到现在——玄枢经历了多少次断火事故？每一次断火的根因——是否和知识断裂有关？已知：过去五年中记录了十一次断火事件。其中七次——根本原因被标注为'配置漂移（`configuration drift`）'或'隐式依赖变更（`implicit dependency change`）'。但没有人标注——为什么这些漂移和变更——在它们发生之前——没有被任何人察觉。目标：追溯断层的最早征兆。关键节点：卫千枢离开的确切时间——和他离开时没有交接的东西。负责人：纪承钧。信息源：钟守玄的口述。前提：钟守玄的口述是这段历史唯一的活的记录。如果他的记忆有偏差——以下所有追溯可能不完整。"

"叁——残码考古层。"这一段的标题他写了又划掉，划了又重写。最后写的是——

"叁——残码考古层。钟守玄说：'等你准备好了，我告诉你。'前提：钟守玄已经准备好了。他已经开始说了。但我不知道他什么时候会说完。可能很久。可能永远不会说完。以下——等他。"

他把笔放下。

纸上是三条路。第一条他已经踏上去了一半——那些 Makefile 的残片，那些 autotools 的化石，那些在旧机柜底层压了十年的编译选项。第二条——他正在走。和苏野平的对话、和钟守玄的反复确认、对每一次"配置漂移"背后真正原因的回溯——每一步都在靠近断层。第三条——他在等。钟守玄说"等我准备好了"。他没有催。不是因为不敢。是因为他知道——钟守玄说"等"——是他能说出的最诚实的承诺。不是拒绝。是——"我现在还不够——但我正在让自己够。"

陆踏痕站在他身后，已经站了一会了。纪承钧没有发觉。

"我可以帮你翻旧文件。"

纪承钧回过头。陆踏痕手里端着两杯热的东西——不是茶，是从客舍那边的旧热水机打的白开水。他一直不好意思用钟守玄的值守室里那套老茶具。

"构建系统考古——第一层——我可以翻旧 Makefile。"陆踏痕把其中一杯放在纪承钧手边。"我在来玄枢之前，在边域的旧宿域修过两年的 autotools 项目。你能看懂的层——我可能看不懂。但 autotools 和 Make 的残片——我认得。"

纪承钧接过那杯水。

"你应该知道——翻旧 Makefile 不是翻代码。是翻考古。你可能会翻到一个十七年前的配置选项——没有人知道它为什么存在。但你知道如果误删它——玄枢的构建就会在某一个平台上失败——而在哪个平台上——你不知道。直到那个平台的人凌晨叫醒你。"

"我知道。"陆踏痕说。"我是从边域来的。边域的每一个系统都跑在'不知道还能跑多久'的旧配置上。我已经习惯了在翻旧东西的时候——不碰。只看。看完，标注——'此处存在。以下是我看到的。至于它为什么存在——待查。前提：我可能看漏。'"

纪承钧忍不住笑了一下。"你已经不需要我教了。"

"不是我学的。"陆踏痕把那杯水放下。"是苏野平留下的那最后一页——我在我的笔记本上抄了三遍。第一遍抄字。第二遍抄意思。第三遍——抄他为什么在每个结论前面写了前提。"

纪承钧低头看着面前的三层考古计划。他把"壹"和"贰"那两段撕下来，递给陆踏痕一份。

"第一层一起做。你负责翻旧的的构建文件——不只 Makefile，还有更早的。在玄枢，有些构建脚本不叫 Makefile——叫 `build.sh`、`compile_all`、`do_build`——名字是当时的人随手取的。没有任何命名约定。你翻它们——找到最早的一版。最早的——可能是一个人坐在这个台位上——那天凌晨——在断火之后——写的。"

"你怎么知道是在凌晨？"

"因为在玄枢——所有的第一次——都不是发生在白天。"

· · ·

沈照痕在第二天上午送来了观测日志。

不是打印件。是一块旧石镜——镜面有一道细长的裂纹，从左上角伸到中间。那是他几年前在玄枢旧日志库深处翻出来的。镜背上刻着一行字："玄枢运行日志——丙寅年三月至七月。"——那是十几年前了。

"这个时期跨了卫千枢离开的前后，"沈照痕说。"一边是他在的时候——构建系统的行为。一边是他离开之后——构建系统在没有他的时候的行为。你对比这两段——可能会看到——他走之前——构建警告出现但被修的时间；他走之后——同样的警告出现——被修的时间变长了。或者——从来没有被修。"

他把石镜放在纪承钧的旧石案上。镜面亮了——不是现代的亮。是那种老式石镜特有的、像透过一层旧玻璃看水底的亮。

"这是你要的第一层考古的证据。第二层——"他从随身的灰布袋里又掏出一个小一点的本子。"这是我自己记录的东西。从五年前开始——每次断火事故之后，我记录了关键时间点和外部系统的版本变更。没有做分析。但是——如果你需要交叉验证钟守玄的口述——这个——能帮你确认时间线。"

纪承钧接过本子。翻开。沈照痕的字很小——每一行都是一个时间和一个事件。没有解释。只有记录。

"第三层呢？"沈照痕问。

"等钟守玄。"

"他会说的。我看过他最近的值守日志。"

"什么日志？"

沈照痕顿了一下。然后从灰布袋最里面抽出一页纸。不是原件——是抄的。字迹很稳。纪承钧认识那个字——是钟守玄的字。但那不是值守卫室里的运行日志。那是写在钟守玄私人笔记本上的——沈照痕大概是唯一被允许翻的人。

纸上只有几行：

"今日纪承钧在铁柜上写了'前提'。陆踏痕也在笔记本里写了。苏野平走了。他留下的——不是一张图。是一个词：'前提可能不成立'。——这个写法以前在玄枢不存在。不是因为没有需要——是因为没有人知道可以这样写。卫千枢不知道。我四十几年也不知道。"

然后空了一行。更下面：

"第三层的路——是旧核残码。那个残码不是我写的。是卫千枢写的。他写的时候——没有写前提。他为什么没写——我可能知道。但我需要确认。确认之前——不说。这是对纪承钧说的。也是对卫千枢说的。——钟守玄。"

纪承钧看了很久。

然后他把那页纸折好，放进了苏野平留下的依赖分析同一层的铁柜格子里。

· · ·

那天下午，陆踏痕从旧构建区出来。脸上有一道灰。手里抱着一叠笨重的旧纸——不是打印件，是真正的纸。泛黄的，边缘卷了，有鼠咬的痕迹。有些页面上还有水渍——不知是雨还是什么打翻的。

"我找到了最早的 build 文件，"他说。声音里有一种复杂的情绪——像考古者挖到第一块骨头。"不是 Makefile。是一个 shell 脚本（`shell script`）。叫 `build_all.sh`。没有后缀约定。没有版本号。没有函数。从头到尾一百多行——每行一个命令。命令之间有注释——很少——但有一行。"

他把那叠纸翻到中间。指给纪承钧看。

那一行写着：

"# 以下编译顺序不要改。改了会炸。不是我说的。是卫千枢说的。卫千枢说他也问过更前的人。更前的人已经不在了。——佚名，丙申年冬。"

纪承钧看着那行字。

"丙申年。"他说。"比 autotools 还早。"

"对。比 Makefile 还早。那个时代——编译不是构建系统管的。是一个人——记住所有编译顺序——然后写进一个 shell 脚本——然后传给下一个人。那个'更前的人已经不在了'——就是断层。"

"不是断层。"纪承钧看着那行字，手指轻轻滑过纸面——"佚名——这个人——他不知道名字——但他写了'不是我说的'。他知道自己不是权威。他只是传递者。他写了传递链——谁告诉谁——链上最后一个人已经不在了——但他没有假装自己知道。他写了——'卫千枢说的。卫千枢说他也问过。更前的人已经不在了。'"

他抬起头。

"这就是前提。在苏野平发明这个词之前——在几十年前——这个人——已经在做了。不是用那个词。是用那种诚实。——前提——不是我说的。是更前的人说的。更前的人已经不在了。如果你知道更多——你来。"

陆踏痕看着那行褪色的字，沉默了很久。

然后他把那页纸放回铁柜。在柜门上新写了一句粉笔字：

"发现：丙申年佚名 shell 脚本。此人在几十年前已经写了前提。前提的写法——不是苏野平发明的。是玄枢本来就有的。只是后来丢了。后来——被苏野平从外面带回来——不是新的。是旧的——回来了。——陆踏痕"

纪承钧看着那句话。

"前提可能不成立。"

"什么前提？"

"你说'不是苏野平发明的'——这个前提可能不成立。也许玄枢的那个人——就是苏野平。不是同一个人。是同一种人。在任何时代——在任何道上——总有一个人——会在写东西的时候——多写一行——'这个——我不知道——你——后来的——你来。'苏野平不是第一个。那个佚名也不是。他们是同一条链上的人。"

窗外，散热塔的嗡鸣声在黄昏中变得更沉了。玄枢在跑。十四年前的"临时"适配层在跑。几十年前的 shell 脚本——已经被无数层新的构建工具覆盖——但它的精神——那种"这是我听说的——不是我的判断——你来验证"的诚实——在苏野平来玄枢五天之后——重新回来了。

不是外来的。是回家的。
