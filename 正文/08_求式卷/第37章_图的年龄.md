# 求式卷 · 第37章 · 图的年龄

小姑娘给"此处有龙"挂上观察栏锚点的第三天，她自己被写进了一份报告。

不是批评——是代谢图项目组的新报表里多了一列她看不懂的字：四境图册 v2.4，**图龄：三百一十天**。每口炉都有年龄，每张图也有？她去问小代，小代把定义投给她看：**图龄 = 距最近一次全量验证的天数 × 阅读热度加权。**炉子体检靠流量数据，图的体检靠读它的人——一张天天有人查、却三百多天没做过全量核对的图，比一张没人看的图危险一百倍。

"因为看的人越多，**它撒谎的成本就越高，而它已经很久没说真话了。**"小代把这条新指标的名字念得很慢，"图的年龄不是出生证明上的日期，是它上一次被世界对答案的时间。"

年检制立刻扩编到图：四境图册每季度做一次全量核对，机器扫结构、人抽查语义。第一次图检跑完，结果比炉检还难看——问题不在图上，在**图外面**。

校验器揪出了三百多份"民间印刷体"：各团队把 v1 和 v2 的打印版贴在工位墙上、机柜上、甚至消防通道里，有的已经贴了一年半。官方图册明明活着，这些化石却还在被当作现行真相引用——**官图年轻，民图苍老。**最夸张的一份 v1 打印图上有人手描了新炉子，笔迹的主人早就离职了，那几笔蓝墨水如今指着一口根本不存在的炉子。

版本漂移听证会上，真正的议题浮出水面：**v3 该不该立。**

要迁移，是因为四境图册的语言不够用了。这一年多里，平台上长出了太多新物种——代谢图的热区冷区、便路条的三档分级、继承契的承诺清单、特护名录、批注的血泪等级——**这些全都不在 v2 的数据模型里**。工程师们已经在用各种别扭的方式打补丁：热区数据挂在备注字段，承诺清单干脆另起一个系统。小代在会上说了句被记进纪要的话：**"图变老的方式不是线条褪色，是词不够用。世界的语法跑在了图的语法前面——这就是衰老的学名。**"

v3 立项全票通过。难的是下一个问题：**v2 怎么办？**

立项后的第一场词汇设计会，吵的不是画法，是**时态**。起因是一份再普通不过的待办：某道翻译门下月拆除——这条信息在 v2 里没有任何合法画法：画实线是撒谎（它还在），不画也是撒谎（图上看不出它将不在）。工程师试过三种画法，每一种都在某个时刻骗人。吵到最后，林见微在白板上写了一句话终结争论：**"静态的图对时间说谎，不管它画得多准。v3 的第一个新词不该是名词，该是时态。"**于是 v3 数据模型最底层多了一个所有构件共享的字段：生效区间。**每一条线都带着自己为真的那段时间活着**——"这道门将于下月拆除"第一次成为图上可画的真话。评审会上有人盯着那条带日期的虚线看了半天，说了句大实话："原来图也可以学会说'再见'。"

删？八千多处历史引用、审计追溯、还有那些印在纸上的民间版本，删了等于焚书。留？留着就会被继续误读——三百份打印体就是前车之鉴。立法小组翻出了日落条款的旧模板，把规则套在了图身上：**废止即发布，死亡要有葬礼，而尸体要立碑。**

于是有了**墓碑机制**：v2 不删，转入历史馆永久封存；封存的每一页顶部自动加盖一行不可擦除的墓志铭——"本图卒于 v3 生效日。生前所述，以 v3 为准。引用本页者，责任自负。"机器端同理：任何系统调用 v2 接口，返回的不是数据，是这行墓志铭加一个跳转链接。**旧版本不撒谎了——它只承认自己死了。**

墓碑机制上线第一周就"逮"到了人。商品上下文一个新人查旧接口撞回一行墓志铭，按链接摸到了历史馆的入口页面——然后他在留言区愣住了：封存才七天，那里已经留了几十条字。"v1 在役时我在这里加过第一个框""F-8 是我画的，它去年拆了，替它记一笔""谢谢 v2 陪我度过新手期"。**封存的是文件，封不住的是人来上过香。**管理员向立法小组请示怎么办，收到的批复只有一句话，后来被刻在历史馆门楣上：**"图有坟，说明读图的人记得死。记得死的人才配画活的东西。"**

封存那天出了个小插曲，也是这一章真正的钩子。小姑娘在清点印刷体时发现有份 v2 的打印版每周都在更新：别人家的打印图都黄得卷边，唯独 B3 值班室那份永远崭新，边角用胶带仔仔细细包着，新炉子用铅笔轻轻补在页边——**一个人在手工维护一份私人图册。**

按制度，民间印刷体一律回收。小姑娘去了两次都没收上来，第二次她没谈制度，只问了一句："为什么是这份？"

值夜的老运维沉默半天，说了一段让她回去想了整晚的话：

"v3 我看不懂了。不是字不认识——**是它说的东西越来越快，我的脑子还住在 v2 里。**炉子还是那些炉子，可你们给它们分了热区冷区、发了便路条、办了过继……我知道这些都是好东西。但我半夜三点起来救火的时候，我只认得我那张贴了胶带的图。**你把它收了，我就成孤家寡人了。**"

小姑娘把回收单撕了。她没违规——制度里写的是"回收印刷体以官方图册为准"，可没说封存当天必须收走最后一份。她在交接本上记了一行："B3 一份 v2，周更，人肉校验器，**建议保留至其读者自然迁移。**图是给活人用的，不能为了图的纯洁，把人的过渡期当垃圾清掉。"

第三天她带着一个方案重返 B3：不但不收那份贴胶带的打印图，还要返聘它的维护者——请老运维出任 v3 的**首位读者验收员**。规则简单得近乎苛刻：v3 每次改版上线前，必须让他在模拟的凌晨三点、睡眼惺忪的状态下完成一次真实排障；**他找不到路，版本就不许发。**老运维当场摆手说没这资格，小姑娘把回收单在他面前又撕了一遍："您不是资格，您是尺子。我们画了两年图，第一次想明白——**图的验收标准不该是像，是该他用得活。**"

这行字后来成了 v3 推广方案的第一条原则：**图册的迁移以人为单位，不以文件为单位。**而它也把一个更硬的问题摆上了台面——校验器能保证图是对的，可谁能保证**读图的人拿到的是新脑子**？

小代把这个未解问题抄进白板留白区，编号排在"忒修斯之炉"后面。他给新问题起的名字很直白：**换图容易换脑难。**
