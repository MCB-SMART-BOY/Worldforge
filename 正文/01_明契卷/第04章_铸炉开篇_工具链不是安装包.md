# 明契卷 · 第04章 · 铸炉开篇，工具链不是安装包

北院东角有一间很少拿来待客的小室。

屋里只有一台刚清过的守门机，一面薄石镜，一张长案。连角落里常见的旧火匣都被搬空了。程知序一进门便先看四周，确认得比谁都仔细——她甚至蹲下去检查了案脚后面，看有没有人偷偷塞了什么东西。

"这台真的清干净了？"

韩砺年靠在门边，脸色不太好看。

"照你们的意思清的。没有旧快照，没有旧补丁，没有私藏的补充纸，也没有谁常年留在机子里的暗门。"

他说到"私藏的补充纸"时，苏野平笑了一声，从怀里摸出一页灰蓝色旧符，夹在指间轻轻一晃。

"你直接说 `.local_release_env` 不就完了。"

季循听见那名字，下意识看过去。

那页灰蓝色旧符就是卷首事故里一直没人肯明说的东西之一。它不大，折起来只有两指宽，平时夹在旧案角里毫不起眼，可北院许多老机器之所以"看着什么都有"，靠的就是它在背后偷偷补那几口气。

沈见微把那页旧符从苏野平手里接过来。他没扔，也没撕，只是放到桌角最远的位置。

"今天谁也不许碰它。"

苏野平挑眉。

"你真打算从一台空机子开始？那你最好祈祷外面今日没别的火。"

"有火也得从这里开始。"沈见微说，"不然青炉还是只活在我们几个眼前。"

闻衡坐在长案另一侧，已经把新的记录纸摊开了。她的墨盒旁边搁着半块冷掉的饼——大概是昨夜值夜时没来得及吃的。她没抬头，只淡淡补了一句：

"今日的目标也别写虚。不是'装上 Rust'。是'让一个不靠熟人指点的人，第一次把一台空机子拉起来'。"

季循听着这话，心口忽然绷紧了一下。

昨日之前，他一直以为"装上"就是装上。直到卷首那夜，他才知道北院里有太多东西都是"看着在"——一换人、一换机子，就立刻只剩半截。

程知序把一张白纸推到他面前。

"你来。"

"我？"

"对。"她说，"今日若还是沈见微自己动手，那只是他又会了一次。只有你照着纸从头做出来，才算这张纸真能留给后来者。"

· · ·

季循坐到守门机前。石镜亮起，一片空白，干净得近乎冷酷。

他手心又有了点潮。

沈见微站在他身后，没有替他碰机子，只先开口：

"先别急着装。第一步，先看这台机子现在到底有没有 Rust。"

季循点头，照着纸上第一行敲下：

`rustc --version`

石镜沉了两息，只吐出一行冷字：

`command not found: rustc`

他又敲第二行：

`cargo --version`

还是同一句。

苏野平靠在窗边笑："这不就结了？空的。把那张补充纸一贴，再从我那边抄一份旧包过来，半刻钟都不用。"

"你这半刻钟，后面要别人拿几夜来还？"程知序头也没回。

苏野平摊手："可人要先活过今日。"

韩砺年这次没站苏野平那边，也没站沈见微那边。他只是看着那台空机子，声音发沉：

"现场真急的时候，大多数人不会先分这些层次。他们只会问一句——为什么别人那台能用，我这台不能用。"

"所以今日就该把这句答清。"沈见微说。

· · ·

他拿过另一张白纸，写下四行字，然后压到季循手边。

第一行：管安装和切换版本的工具——`rustup`

第二行：一整套彼此配好的工具——`toolchain`

第三行：把代码翻成程序的编译器——`rustc`

第四行：管项目、构建和依赖的工具——`cargo`

季循盯着那四行，看了比昨夜任何一张纸都更久。这一次，字没有故意把人挡在门外。

沈见微用指节轻轻点了点第一行。

"先记这个。很多人一提 Rust，就以为只要把一个包装上去就完了。不是。你真正要先碰到的，是负责安装和切换版本的工具——`rustup`。它不是 Rust 本身，它是管'你要用哪一版 Rust'的那个人。"

他又点第二行。

"而你装下来的，也不是一把单独的锤子。是一整套彼此配好的工具——`toolchain`。里面至少要有编译器，也要有管项目的工具。它们得是一套。版本对不上，后面全是暗坑。"

程知序接过话：

"也就是说，今日不是看你能不能把一个名字装进机子里。是看你能不能把这一整套关系装明白。"

闻衡在记录纸上添了一句：

`只写"安装成功"不算过关；能说明谁管安装、谁管编译、谁管项目，才算第一步说清。`

苏野平低头看了一眼，啧了一声。

"你们问心台的人写东西，真是一点都不肯让人舒服。"

"舒服不能替后来者省事。"闻衡说。她把那半块冷饼往旁边挪了挪，继续写。

· · ·

沈见微让季循继续。

"先装 `rustup`。装完之后，不要急着自我感动。先看它手里现在到底管着什么。"

季循照做。那几步并不复杂，却比他想的慢得多。空机子上每一步都很实在——没有老手替他踩平坑，没有暗门替他跳步骤。他不知道自己正在穿越基座（`foundation`）之间的边界：同一套工具，在不同的大地上会有不同的默认路径、不同的包管理器、不同的系统库版本。北院的老手们早就把这些差异内化成了本能——但从来没有人把它们写下来。每敲一行，石镜都会停一瞬，像在等他确认自己真的知道在做什么。

等到 `rustup` 真正落稳，沈见微让他再敲：

`rustup show`

石镜这次终于给了回应。一行行字往外吐，比先前那两声冷冰冰的"not found"长了不止十倍。

季循盯着，先看见的是 `rustup home`，再往下看，才发现真正要紧的不是"有了 `rustup`"，而是"当前到底有没有可用的工具链"。

"看懂没有？"沈见微问。

季循慢慢点头。

"它不是说 Rust 全装好了。它只是在告诉我——管这摊东西的人已经来了。可它手里现在有没有真正能用的那一套，还得往下看。"

闻衡抬眼看了他一下。这一次，她没有点头，也没有补注，只是继续往下写。

"继续。"她说。

· · ·

纸上的下一行写得更明白：

装稳定版工具链：`rustup toolchain install stable`

季循照着敲下。

苏野平看着那行命令，终于还是没忍住：

"你看，多绕。旧法里哪有人跟你讲什么 `rustup`、什么 `toolchain`。大家只会说——先装这个，再说。"

> "先装这个，再说。"沈见微把这六个字重复了一遍，声音很平，"北院这些年最会害人的，就是这六个字。"

屋里一下静了。

因为所有人都知道这话说得太准。太多东西就是死在"先装这个，再说"上。先装了，再说顺序。先跑了，再说前提。先救了，再说后果。等到真出事，谁都说不清最开始那一步到底偷偷借了谁的手。

稳定版工具链终于落下来的时候，季循竟有一点很轻的恍惚。

不是因为这一刻多么壮烈。恰恰因为它太平常。平常到像一件本就该如此的事。可北院过去许多年，恰恰没有把这种"本就该如此"的平常留给后来者。

沈见微让他再试：

`rustc --version`

这次石镜没再报错。冰白的镜面上安安稳稳亮出版本字样。

"这就是编译器——`rustc`。"沈见微说，"它在，说明你手里终于有了真正干活的那把刀。"

"可还不够。"季循接得比先前快了一点，"还得看 `cargo` 在不在。"

他自己敲下第二行：

`cargo --version`

石镜再次回字。

程知序这次才真正松了半口气。她走到季循身后，抬手点了点镜面上那两个版本号。

"记住这一刻。很多人以为把 `rustc` 装上了就叫装好了 Rust。不是。做项目时，你大多数时候碰到的是 `cargo`。它管项目骨架，管构建，管依赖——真正干活时再去叫 `rustc` 下场。"

季循听得很慢，却第一次没有被这些名字压得心慌。因为每个名字前面，都先有了一句人话。不是因为谁给他背诵了定义，而是他亲手在空机子上跑过了每一步——报错、补上、再跑、看到回字。

· · ·

韩砺年站在门边，一直没插话。到这时，他才低低开口：

"你们这套慢，是慢在把事拆明白。"

"对。"沈见微说。

"可现场最缺的，往往就是这点时间。"

"所以我们现在才要先把这一段时间花出去。"沈见微转头看他，"不然以后每次换新人、换机子、换一处环境，都得再拿更贵的时间去补。"

韩砺年没再顶。他只是看了一眼桌角那张没被展开的 `.local_release_env`，像看着一条自己守了很多年、如今终于不得不承认不能再靠它过日子的旧桥。

· · ·

沈见微把昨天立下的青炉目录抄片推过来。

"到这里还不算完。"

苏野平笑了："这还不算完？"

"不算。"沈见微说，"装上工具，不代表别人已经会用它们做同一件事。今日要看到最后一步。"

他把手指落到最后一行：

`cargo new qinglu`

季循看着那行字，忽然想起昨日断史库里那片比尘还静的旧史。那时他只觉得这是起炉。到了今日，他才真正明白：起炉之前，得先把点火用的整套家伙摆明白。

他照着敲下命令。

石镜里一行行新字往下落，像有人终于在一片空地上把梁、柱、门框依次立起。青炉的空架子成了。

但沈见微还是没让他停。

"进去。"

季循照做。

"再试一次构建。"

他这回没有问为什么，直接敲下：

`cargo build`

苏野平看着镜面上那串滚下去的字，抱着手臂叹了口气。

"你们这是真要把每一步都让外人看见。"

"不然呢？"程知序反问，"难道还要像以前那样，只让外人看见最后那句'已经好了'？"

镜面上的字停住时，屋里安静得连灯火轻轻响一声都能听见。

季循盯着最后那句完成回字，半天没挪开目光。他不是第一次看见一件事做成。可这是第一次，他知道自己为什么做成。也知道若把这台机子清空，再换一个和他一样刚进门的人来——只要纸还在，对方多半也能从头走到这里。

· · ·

程知序把那张记录纸拿过去，从头到尾看了一遍，最后只改了一句。

她把原本写着"青炉起炉成功"的那一行划掉，换成了：

`一台空机子已可独立装好 Rust 工具链，并能新建、构建最小项目。`

闻衡看完，点头。

"这一句才像承诺。"

苏野平低头望着那句，半晌才笑了笑。

"行。至少这回，连我也知道你们到底做成了什么。"

韩砺年走到桌边，把那张一直没展开的 `.local_release_env` 拿起来，看了片刻，忽然递给季循。

季循愣住。

"给我？"

"先留着。"韩砺年说，"不是让你偷偷用。是让你记住——北院过去就是靠这种东西省下眼前的力，才把后面的债越攒越大。"

他说完，顿了顿，又补了一句：

"今日你们这一章写得慢。但慢得值。"

沈见微没有接这句话。他只是把桌上的四行解释纸折好，压进青炉第一叠文契里。

他知道，从这一刻起，青炉才算真的碰到第一层骨。不是因为它已经有了什么惊人的能力。而是因为它第一次敢把"从哪里开始"写给别人看。

屋外风从东廊吹进来，卷得长案边那几页新纸轻轻起伏。

季循低头看着镜中还未散尽的字光，忽然有一种很迟来的踏实。卷首那夜，他第一次看见的是一群人如何靠熟手和暗门把火拖过去。而今日，他第一次看见的是另一种东西——不是谁来救火，而是把以后的人，先从火外接进门里。
