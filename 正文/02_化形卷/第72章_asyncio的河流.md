# 化形卷 · 第72章 · asyncio 的河流

入世层的`field-mapper`需要同时处理多个并发的API请求。同步版本（`synchronous`）每次只能等一个返回——一条请求卡在I/O上，后面的全部堵在门口。季晚禾在凌晨看到的面板——请求超时，重试，再超时——就是因为同步等待把一条链上的所有请求串成了单行道。

周栖野开始学异步编程（`asyncio`）。协程（`coroutine`）——`async def`定义的函数，可以暂停和恢复。事件循环（`event loop`）——调度所有协程的中央控制器，像一个调度员在多个任务之间切换。`await`——在协程中暂停，把控制权还给事件循环，让它去处理其他协程。

不是多线程。是协作式多任务。线程是操作系统强制切换——你不知道什么时候被切走。协程是自己主动交出控制权——`await`就是"我在这里等，你可以去处理别的"。

"不是更快——是更诚实。同步代码的问题不是慢——是等待的时候CPU几乎不做什么，但整个进程被阻塞了。异步让等待的时间被利用起来。`await`告诉你'我在这里等'——你不需要在脑子里模拟代码现在卡在哪个I/O操作上。"

化形之道的本质是流。`async/await`是把等待从不可见的诅咒变成可读的声明。
