# 化形卷 · 第91章 · 慢一步活得更久

三层运行，固核验证，语境声明制度化——息壤正在变慢。不是技术慢了，是流程多了。

季晚禾做一个小的数据清理，以前打开 notebook 写几行 pandas 就好。现在要多填 MRC、跑 mypy、等 CI 通过才能合进固核。"她不是在抗拒制度——制度确实保护了她。但制度也让她比之前慢。制度保护后来者——但减慢现在的人。这是不可避免的交换。制度不是免费的。它把'慢'从意外变成预期——从一个人的自我约束变成所有人的公共规则。"

周栖野在公共记录板上写了一份宣言，不是给团队——是给谢催成，也是给自己。"快是化形之道的起点——不是它的全部。我们从'先做出来'开始——但我们不能停在'先做出来'。因为停在那里就是沼泽。不是所有的东西都需要慢——但被依赖了的东西必须慢。固核慢因为有人在依赖，试法快因为没有人依赖。快慢的分配不由道决定——由依赖决定。"

试法层的 README 写得很清楚："不保证。随便试。快是这里唯一的规则。"试法层的快没有被消灭——它只是被放回了它应该在的位置。在无依赖的空间里快是安全的，在被依赖的空间里快需要先标注前提。

谢催成读了，沉默，离开。他没有反驳——因为宣言本身不是对他的攻击，但它动摇了他在息壤的唯一价值："快"。如果快不再是息壤的最高价值，谢催成的角色是什么？他的身份建立在旧规则上——规则在变，他的位置在松动。快与慢的道路开始分裂。不是共存——是选择。每个人选择站在哪一边——不是技术选择，是身份选择。
