# 化形卷 · 第79章 · 分层之后

卷八收束。三层息壤正式运转——不是设计图上的三个同心圆，是真实的目录、真实的晋升流程、真实的契约、真实的降级和退役机制。

入世层的 `field-mapper` 带着 API 契约对世界开放。固核层有了活着的晋升流程——不只是林过川的火种，还有团队正在维护的模块。试法层的标签让每一个走进去的人知道自己站在实验的土地上。不是所有东西都稳定，不是所有东西都永恒，但每样东西都有标签说明它是什么。

"分层之后——不是沼泽消失了。是沼泽被围起来了。试法层就是沼泽——它还是快的、自由的、不保证的。但它有边界了。边界外——固核层和入世层——有路，有承诺，有前提声明。沼泽没有消失——它只是被控制在它应该在的位置。快没有被消灭——快有了自己的空间。"

卷九「固核」——三层从运转走向优化。工具链的进化还在继续——mypy 全量覆盖、pytest 测试体系深化、asyncio 向 trio/anyio 过渡。但更深的问题是制度本身会不会成为新的黑箱。当晋升标准变成教条，当审契者变成新的守门人——制度也可能变成沼泽。不是现在——但值得被记住。
