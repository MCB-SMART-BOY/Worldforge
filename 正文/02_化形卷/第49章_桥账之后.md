# 化形卷 · 第49章 · 桥账之后

卷五收束。顾迁舟合上桥账。七条桥全部有了出生证和退场日期。可删的正在走退场流程，可迁的有了迁移指南和窗口期，不可删的被公开声明为永久——不再假装"临时"。

桥账被贴在了公共记录板旁边，和叶藏拙的沼泽记录、周栖野的三层图并排。沼泽记录是"我们有什么"——测绘墙上的红黄绿标。三层图是"如果秩序存在，它长什么样"。桥账是两者之间的连接——三层之间的通道，沼泽到秩序的传送带。三份文件贴在同一面墙上。不是完美的答案，是三个互相补充的视角。

"桥被写进了制度。制度不会让桥消失——但会让桥在消失的时候被记录，在存在的时候被管理，在退场日期到期的时候被检查。今天填的退场日期可能到时候不全对——有些桥会在日期之前就拆了，有些桥会需要延期。但到那个时候，有人会回来看这张桥账，问那个问题：'这座桥——应该拆了吗？'制度不是完美的计划，是定时回来的检查。不是一次性的清理，是持续的审视。"

但桥不是唯一需要管理的连接。三层之间的界面——试法层和固核层之间的晋升、固核层和入世层之间的 API 契约——也是连接，也需要管理。那些管理角色还没到位。顾迁舟管桥，但谁管晋升？谁管 API 契约？守界者还没出现。卷六会来——宋既明的方法论，季晚禾作为使用者的声音，对"快"的重新定义。"删桥"不是结局，"怎么让桥不再被搭"才是。卷六「删桥」——拆桥的实践和恐惧。
