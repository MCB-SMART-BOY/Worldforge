# 化形卷 · 第110章 · 后来者之前

卷十一最后一天，周栖野站在季晚禾走通的路上。从 Onboarding 的第一步到 MRC 的验证步骤，从 pytest 的测试输出到 Docker 的 `docker run`。这条路在一个月之前还是未标注的沉默——现在每一步都有路牌，每个路牌都有人名和日期，标注着"这里曾有人卡住——已修"。

"后来者之前——不是所有的路都铺好了，不是所有的坑都被填了。但有入口了，有路牌了，有让你知道'如果看到这个就是对的方向'的验证步骤了。白又新走过，季晚禾走过。他们是第一批——但不会是最后一批。这就是制度——它不是一次性建好然后永远不变的墙。它是每一代后来者走过之后在路边加一块路牌的活的系统。"

卷十二「后来者」——把钥匙交给白又新和季晚禾。不是一个人的传递——是一代人的传递。周栖野要去简阵了，带着红色标签规则，带着前提声明，带着"不是去教，是去学"的清醒。息壤会留在后来者手里——不是完美的，不是完整的——是诚实的。诚实是传火的前提，火不是追求不被熄灭——是传递的时候告诉下一个接火的人它的前提是什么。火种在固核，路在入口——后来者可以自己走了。
