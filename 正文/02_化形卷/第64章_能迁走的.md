# 化形卷 · 第64章 · 能迁走的

十二个火种逐个迁入固核层。代码审查确认没有隐藏依赖，补充测试定义了"对"的行为，补充 MRC 让独立使用成为可能，每个模块标注了原作者。

迁移过程中发现林过川的代码有隐式依赖——不是 import，是硬编码的路径、环境变量、系统工具的调用。这些东西在代码里，但不在任何声明文件里。这些依赖被逐一发现、记录、声明。每个火种的迁移都在替林过川完成他没做的事——不是改他的代码，是给他的代码补上他沉默掉的前提。

周栖野在每个模块的 `__init__.py` 里加了同一行注释。"Originally authored by Lin Guochuan (former maintainer). Migrated to xirang-core during the Fire Seed cleanup. Original code preserved in xirang-archive."

叶藏拙翻着更新后的固核层目录。"之前固核层里只有你和岑照渠的名字。现在有林过川的名字了。不是他的全部——但至少不是空白。不是'对不起'。"

火种迁入固核层是化形卷对"断史"最具体的回答。失传者的代码不是不可传的——是需要一个愿意花时间翻译的人。代价落在翻译者身上——白又新花了两天翻译一个 README，周栖野花了一周给十二个火种补文档和测试。但后来者不再需要付这份代价。林过川的名字现在在固核层里——不是作为失传者，是作为"他的火种还在跑"的证据。
