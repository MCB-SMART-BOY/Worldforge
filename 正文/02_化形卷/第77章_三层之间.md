# 化形卷 · 第77章 · 三层之间

三层已经运行了。但流转规则还不完整——有个固核模块的 mypy 警告数量在增长，作者没时间维护。怎么处理？

周栖野画了三层之间的所有箭头。lab→core 晋升：mypy、pytest、MRC、审契者审核。core→gate 入世：完整契约、semver、公示。降级：如果 core 模块连续两个审查周期不能满足标准，退回 lab。退役：如果 gate 模块不再被需要，弃用、归档。不只是往上——也有往下，也有退役。

唐野渡反对降级。"降级是惩罚。"

"不是惩罚——是诚实。如果固核层有东西不能维持稳定，它该回到试法层，而不是假装稳定。假装稳定才是对后来者真正的伤害——他们信任了固核的承诺，却发现承诺没有被兑现。降级是承认'我们现在做不到稳定'——承认局限比假装完美更值得信任。"

流转的完整性——不只是能晋升，还要能回落。不能回落的制度是不完整的，它只能装"向上"的故事，但工程的历史有上有下。有些东西在某个时代是稳定的核心，在下一个时代被更好的东西替代——它应该退役，不是被遗忘。三层之间的流转地图让每一个模块都有明确的位置和明确的前途——不是所有东西都该永远留在同一个地方，但每样东西都该知道自己在哪里、为什么在这里、可能去哪里。
