# 化形卷 · 第48章 · 测试 ≠ 信任

三十个测试全绿。`pytest`的输出面板上——三十个绿点排成一排。每一个旁边都有测试名称、耗时、通过标记。周栖野检查了一遍——全绿。部署到生产。

一个小时后。凌晨的备份任务因为磁盘满了——只生成了一个空文件。空文件被传进`field_mapper`。

`ValueError: Empty DataFrame`。

不是bug。是他的函数假设输入DataFrame非空。所有测试用例都提供了非空的DataFrame——因为他写测试的时候脑子里的场景是"正常流程"。正常流程不会有空文件。但异常流程有。凌晨的磁盘满了。监控没告警。备份任务静默失败。只产出了一个零字节的空文件。空文件被传进`field_mapper`。`pandas.read_csv`在文件为空时返回空DataFrame。空DataFrame上没有列。没有列就不能做字段映射。崩了。

三十个测试——全绿。一个都没有覆盖空文件场景。不是因为偷懒——是因为没想到。测试只能验证"作者想到了什么"。作者没想到的场景——测试不会提醒你。

· · ·

白又新花了五分钟。在函数入口加了一行：`if df.empty: return {}`。然后写了一个新测试：`test_parse_fields_empty_dataframe`——传空DataFrame，断言返回空字典。全绿。

"不是我们没做测试。是我们没想到。"他把那条新测试用例推到周栖野面前，"但现在我们想到了——测试帮我们记住了。下一次换人维护这个函数，换Python版本，换pandas版本——这个测试会告诉他：空文件这个场景，以前的人想过。"

"测试 ≠ 信任。测试是诚实。诚实地说'我测试了这些'，诚实地说'我没测试那些'。诚实比安全更重要——因为诚实让后来者知道安全区的边界。知道哪些行为是被验证过的，哪些还没被验证。全绿的测试套件可能会骗人——因为作者没想到的场景全是绿的——他只是没写那些测试。但诚实的测试套件不会。诚实的测试套件会在空白处标注：'此处未覆盖'。标注不是失败——是留给下一个被凌晨叫醒的人的起点。"
