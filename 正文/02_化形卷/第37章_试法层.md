# 化形卷 · 第37章 · 试法层

周栖野在公共记录板上正式建立了三层的第一层：试法层（xirang-lab）。

"xirang-lab：随便试。不保证任何东西。不承诺 API 稳定。不保证明天还能跑。唯一的规则是——你必须知道自己在这里，并且必须让后来者知道他们在这里。"

试法层是所有新想法的起点。任何人不需批准就可以在这里建新目录、写新脚本、导入任何包。实验不需要先写文档，不需要先锁定版本。自由是试法层的根本——但自由需要标签。之前的问题不是"实验太多"，而是实验产物被团队当成了稳定工具使用，而作者不知道被使用了。`field_mapper.py` 的第一个版本是实验——周栖野周末随手写的，没有测试，没有文档，没有 MRC。但三个月后被季晚禾用来做月度结算。

试法层的入口是一个特殊目录 `xirang-lab/`，里面所有东西都有自动生成的标签。"试法层代码——API 可能变更。不保证复现。如果需要稳定版本，参见固核层（xirang-core）。"标签让"这是实验"这件事不再是隐形的。之前——使用者以为自己是在用，其实一直是在尝试。区别只在——以前没有人告诉他们。

唐野渡抗拒。"标签会吓跑尝试的人。"

"标签会让尝试的人知道他们在尝试。不是在用。之前他们以为自己在用——其实一直在尝试。区别在——没有人告诉他们。你的恐惧是对的——标签确实会让人犹豫。但犹豫不是坏的。犹豫是人在进入不稳定区域之前停下来看一眼脚下的东西。之前的试法不给任何人犹豫的机会，因为入口和固核层的入口看起来完全一样。标签让入口不一样——不是更窄，是更诚实。"

试法层不是速度的监狱——是速度的路牌。它让"快"有一个明确的空间。在这个空间里，快是合法的、被保护的。走出这个空间，进入固核层之前——需要验证、文档、MRC。不是快被禁止了，是快的位置被明确了。
