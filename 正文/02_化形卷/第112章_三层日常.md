# 化形卷 · 第112章 · 三层日常

试法层继续长。三十三个新脚本提交，三个休眠标注自动触发。速度没有被限制——快在它的安全空间里继续着自己的节奏。

固核层继续稳。一次晋升审核通过，零个 mypy 警告。岑照渠的模块通过了第三次晋升审核——她不需要查标准了，标准已经在脑子里。第三方模块导入时不假思索地信任了 CI 的绿色标记。信任不是因为盲从，是因为每次信任都被验证过。

入世层继续守。API 正常运行，零个弃用声明触发。`field-mapper` 从 1.0.0 升级到 1.1.0——向后兼容，所有契约检查自动通过，迁移指南自动生成。外部调用方看到升级日志后在讨论贴上回了一个"已阅"。

三层从制度变成了习惯，从"需要遵守的规则"变成了"自然这样做的方式"。没人觉得三层是负担——就像没人觉得 git commit 之前的 lint 是负担。它不是额外的步骤——它就是步骤本身。

叶藏拙翻着他的账本。"三个月前每个月我会记录几十个'不能复现'。上个月三个。这个月零。不是一下子变零的——是一章一章降下来。Ch7 最多，Ch15 开始降，Ch50 降到个位数，Ch112 零。"零不是终点——零是制度在持续运行。制度没有让代码完美——制度让问题在变成事故之前被看见了。
