# 化形卷 · 第41章 · 桥不是路

顾迁舟到息壤的那天，腰上挂着一本旧册子。封面上写着四个字——"桥账——息壤"——字迹很瘦，像刀尖划过。他是顾迁衡的弟弟。和他哥一样，这辈子只做一件事：管桥。

他在息壤的公共记录板前摊开桥账。里面是七条桥的记录。每一条都有搭桥时间、类型、依赖方——和退场日期。每一页的退场日期那栏都填着。但填的都是已经过去了的时间。

"七条桥。全部没有有效的退场日期。"他把桥账翻到第一页，"最老的一条搭了快五年。搭的时候说的是'等那边修好就拆'。那边在第三年就修好了。没人来拆桥。"

第一条：`xirang-cpp-bridge`。Python 调用 C++ 模块的 FFI（`Foreign Function Interface`）包装层。搭了快五年。当时玄枢的旧接口还在用——需要一个翻译层让息壤的Python脚本能调用玄枢C++代码。说好的是"等玄枢新接口出来就拆"。新接口在第三年就出来了。桥还在。没人来拆。

第二条：`xirang-excel-adapter`。Excel导入导出桥。第三条：`xirang-old-api-shim`，旧API兼容层。第四条，R语言统计桥。第五条，旧数据库连接器。

第六条：`xirang-temp-migration`。周栖野自己认出了这个名字。他三年前搭的。"两周的临时方案。"他在桥账上看到了自己当年的搭桥记录——字迹还是他自己的。"两周。"顾迁舟在退场日期那栏补了一行："实际寿命：三年。原因：方案生效了。没人想动。"

周栖野沉默了。三年。他每次经过这个桥都看到了它的名字。每次都想"该拆了"。然后每次都有更紧急的事。紧急的事永远比重要的事排在前面——因为紧急的事有人催，而退场的桥不会催人。

第七条：`xirang-unknown`。不知道谁搭的。不知道搭来干什么。没有Git提交记录。没有作者。没有任何文档。只有一条部署日志——"hotfix - 凌晨三点十七分"。三年了，它一直在跑。没有人知道它在桥接什么。

· · ·

"桥不是路。"顾迁舟合上桥账，"但桥被走成了路。不是任何人的错。是没有人负责桥的退场。你在搭桥的时候就想好了它应该什么时候拆——但制度没有让你把这个日期写下来、并且确保后来会有人回来检查。结果——每一座'临时'的桥都变成了永久建筑。不是建筑的材料好——是'临时'这个标签让所有人以为它会在某天消失，于是没有人对它负责。"

"桥有一个退场条件（`sunset condition`）。'等那边修好'。'等迁移完'。'等新版本出来'。条件满足了——但没有人回来核实。因为没有人负责回来核实。退场条件不是只写给自己的备忘。是写进制度的承诺。承诺需要有人在它到期的时候回来检查。"

"在玄枢——他们建了渡桥司专门管这个。在息壤——还没有。所以我来。不是来拆桥的。是来让桥有出生证和死亡证。"
