# 化形卷 · 第74章 · FastAPI 与 Pydantic

入世层的`field-mapper`需要对外提供HTTP API。但如何保证调用方传正确的参数？之前API的参数定义在周栖野的脑子里——每个调用方都要问他"这个参数是必须的吗？可以传None吗？"

Pydantic的`BaseModel`用一个类定义了所有字段的类型、必填与否、默认值和验证规则。FastAPI在请求进来时自动校验body是否符合schema——不符合就返回422，附带明确的错误信息说明哪个字段类型不对。

"之前——这些信息分散在我的脑子里、README里、季晚禾的聊天记录里、白又新的MRC里。现在——在一个地方。机器会替你检查。类型就是契约——`str`就是`str`，`int`就是`int`，不要传`None`除非你写`Optional[str]`。mypy是编译期检查，Pydantic是运行时验证。两层锁。"

宋既明跑了FastAPI自动生成的`/docs`（OpenAPI/Swagger）."之后的外部调用方不需要问任何人。他们看这个页面就知道怎么调。这是入世层的真实入口。Pydantic和FastAPI用类型把契约从口头变成了代码。机器会验证——后来者不需要依赖'应该'——他们依赖'会报错'。"
