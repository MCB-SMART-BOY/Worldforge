# 化形卷 · 第34章 · poetry / uv

周栖野的`requirements.txt`里有`pandas>=1.3`。宋既明问了一个问题："你装的是pandas的哪个确切版本？"

"最新的。""明天，最新的可能就变了。明天后来者装的pandas不是你今天用的pandas。"

`requirements.txt`的`>=`语法是承诺的漏洞。它说我需要至少1.3版本——但它不承诺我用的是1.5.3。更深的漏洞在依赖的依赖。pandas依赖numpy，numpy依赖系统级库——它们在macOS上的行为和Linux上的行为不同。

lock file的哲学不是锁定——是诚实。`uv lock`生成一个文件，精确记录每一个依赖包的版本哈希，包括间接依赖。八十多个包——远比`requirements.txt`里的十几个多。那些多出来的包，周栖野从来没有import过，但它们在他的代码运行时被加载了。它们一直在——他从来没有声明过。

lock file不只是锁定了版本——它是依赖链的完整地图。后来者拿到这份地图，知道每一个字节从哪里来。地图不能阻止前提改变，但地图让改变发生时你能追索——是哪一环变了，影响从哪开始。诚实不是完美——是知道自己在依赖什么。
