# 化形卷 · 第78章 · 唐野渡的沼泽

唐野渡是周栖野的镜像——更极端、更成功的版本。他是息壤公认最快的人，比周栖野还快，在谢催成眼里是"最像林过川的人"。

三层制度运行后，唐野渡的模块被退回最多。不是写得差——是快得太纯粹。函数签名没有类型标注，没有 MRC，依赖散落在代码的各处，硬编码的路径比林过川的还多。每个被退回来的评审意见都在说同一句话："你这是三年前的周栖野。你在沼泽里跑步——觉得脚下是平地，但下面全是坑。你不知道是因为你跑得太快了——那些坑在你身后爆炸，不在你脚下。"

镜像者的意义在这一刻不在对比——在预见。唐野渡是周栖野没有遇到叶藏拙的账本之前的样子。唐野渡需要的不是批评——是有人让他停下来，让他看见沼泽里困着的人。正如叶藏拙的账本让周栖野停下来那样。唐野渡一直没有停下来，因为他的快一直被奖赏。现在三层制度不奖赏他的快了——退回不是惩罚，是告诉他"你已经够快了，现在需要让别人也能跟上。"

"我不是你。但我可能曾经是你——如果没有叶藏拙的账本，如果没有林过川的遗迹，我可能现在还在沼泽里跑步，觉得自己最快，不知道身后在爆炸。"

镜像者不是敌人——是另一种可能性。唐野渡代表了"快"不被约束的终点——林过川的 README 只有三个字。周栖野代表了"快"被约束之后的方向——固核层的晋升标准。
