# 化形卷 · 第69章 · 火种之后

卷七收束。林过川遗迹的清理告一段落。十二个火种迁入了固核层——有了文档、测试、MRC。废土归档了——每份旁边标注了为什么不能迁。骨殖留在原处——标注了"待判断"，等待后来的考古者。

"火种之后——不是遗迹消失了。是遗迹被分类了。有用的被抬上来，没用的被归档作为参考，不确定的留给后来者。林过川的沉默不再是一面墙——它被翻译成了一堆文件。每个文件都说：'这是林过川做的东西。它的价值在这里。它的局限在这里。它的前提在这里。后来的考古者——你们不需要重新挖。'"

但清理遗迹只是化形卷漫长重建的一部分。三层息壤需要更多——试法层和固核层之间的边界需要守界者，固核层和入世层之间的 API 契约需要被验证，入世层和外部世界之间的桥需要渡桥司的制度化。这些需要卷八到卷十二。

林过川的笔记被留在了公共记录板上——和驭器卷钟守玄的"前提可能不成立"并排，和玄枢旧石镜里三代人的"后来者应该自己判断"并排。不同世界的守缺者信仰在化形卷的公共记录板上汇合——不是被批评，是被回应。回应不是"你错了"，是"你的信仰是对的，但它的执行方式可以比沉默更好。沉默让后来者没有入口，前提声明给后来者入口同时不替他们判断。你的信仰值得被继承——但它的形式需要进化。"

卷八「分层」——三层息壤从雏形走向制度化。试法层的治理规则、固核层的晋升标准、入世层的契约格式——这些在卷四画成了图，在卷八将被建成制度。守界者即将出现。
