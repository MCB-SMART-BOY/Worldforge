# 化形卷 · 第71章 · 三层息壤

三层目录结构正式建立。从卷二十的"如果墙"到卷七十一的物理目录——试法层（xirang-lab）、固核层（xirang-core）、入世层（xirang-gate）。

每个目录有一个 README，每个 README 开头是"你在这里意味着..."。`xirang-lab/` 的 README："欢迎。这里没有规则——除了一个：任何产出被外部引用时，必须告知引用方这是实验代码。不保证 API 稳定性，不保证明天还能跑，不保证任何东西。自由是你的权利——标签是你的责任。"

`xirang-core/` 的 README："严谨。这里的每一个文件都有 MRC、mypy 和 pytest 通过、依赖通过 uv.lock 锁定。任何修改需要审契者通过——因为有人在依赖它。稳定不是感觉——是可验证的状态。"

`xirang-gate/` 的 README："承诺。这里发布的每一个接口都有一份契约。契约说：这个接口至少维持到这个版本。改 MAJOR 之前你会提前三个月知道。入世不是终点——是责任。被依赖是一种责任。"

建立目录容易——但目录之间如何流转？晋升标准、审核周期、谁来守门——这些需要制度而不仅是目录结构。三层治理的物理化不是有规则就行，是规则在目录里。每个目录的 README 就是入口，每个子目录的 CONTRIBUTING 就是晋升流程。后来者不需要读完整本手册——他们只需要打开对应的目录，读那个目录的 README，就知道自己站在哪里。

叶藏拙把三层目录的创建日期记录在账本里。"这是历史。三层是在今天降生的——但它们的胎盘是林过川的遗迹，是 Ch11 季晚禾的报错，是 Ch56 runbook 的第三步失败。三层不是设计的胜利——是历史中每一个失败的人共同推动的。后来者打开 core 的 README——他们不知道这些规则是从多少人的痛苦中提炼出来的。但他们不需要知道——他们只需要遵守。规则替他们省下了那些人的代价。"
