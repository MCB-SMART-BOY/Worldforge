# 化形卷 · 第103章 · 文档的入口

Onboarding 测试暴露了文档中的几处模糊。周栖野开始系统性整理——不是说明书，是一张路径图。后来者看到文档就知道从哪里开始，每一步后到哪，走错了怎么办。

Onboarding 文档的三层体系。路径图——从零到第一个成功，每一步可验证。常见卡点——每个卡点后面有被卡住的人的名字和日期。"这里——季晚禾卡了十分钟，因为 pip 和 uv 的路径冲突。已修复。"深度文档——不是新手需要的，是第一个任务完成后可以深入的东西——固核层的晋升流程、入世层的契约格式、红色标签规则的完整说明。

文档不是静态的——是活的。后来者每走一步都在测试文档。走不通不是人的问题——是文档的问题。每次有人 onboarding 后更新文档中的卡点。文档也有退场日期——因为工具链会变，今天的"用 uv sync"可能三年后不再是对的步骤。

"林过川没有写这份文档——因为他觉得空白是恩赐。我们写了——因为我们知道空白是墙。这就是化形卷的答案——不是永远不要空白，是在入口处不要有空白。Onboarding 文档不是说明书，是后来者的第一个路牌。这个路牌是化形之道对林过川最完整的回答——不是否定他的信仰，是完成他来不及做的事。他的 README 只有三个字'对不起'，我们的 README 开头是——'欢迎。你不是第一个走进来的人。以下是你的路。'"
