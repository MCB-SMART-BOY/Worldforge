# 化形卷 · 第13章附 · 承契，稳流之外

三层息壤正式运转之后，季晚禾被调到稳流派做基座兼容性验证。她的工作是：每次稳定骨有模块更新，在三种基座上各跑一次完整的测试套件——稳流派、前沿派、承契派。

最开始她以为这只是体力活。跑就是了。直到她第一次在承契派（企业仓库的长期支持版本）上跑一个用了新语法特性的模块——跑了三遍，三遍都失败。不是模块的错。是承契派的 Python 版本比稳流派落后一个大版本。模块里的一行代码在稳流派和前沿派上跑得飞快——在承契派上直接报语法错误。

"承契派不能升级吗？"

"不能。"岑照渠说，"承契派的版本是受企业合规约束的。改一行代码比升一个大版本容易。但你得先知道——你写的那行代码在承契派上不成立。"

季晚禾在验证报告里写了一条新声明：`本模块已通过稳流派和前沿派验证。承契派验证失败——原因：语法特性不兼容。承契派用户请使用 v2.3.1 旧版。`

这是三层息壤运行以来第一份标注了"部分基座不兼容"的声明。
