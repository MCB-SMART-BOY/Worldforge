# 化形卷 · 第11章附 · runbook入侵，别人的前提不是你的前提

息壤收到第一份来自玄枢的正式 runbook 是在一个周三下午。不是请求。是传递——纪承钧把玄枢旧适配层边界维护的完整操作流程写好之后，发给了所有可能的跨道调用方。他是好意。他在明契卷沈见微那里学到了"先写失败"——所以这份 runbook 的每一步旁边都标注了前置条件、失效判断和回滚路径。

但它在息壤的前提不成立。

· · ·

季晚禾是第一个试着照这份 runbook 操作的人。她需要验证息壤与玄枢之间的数据对账接口在一次配置变更之后是否仍然一致。runbook 上有明确的步骤：第一步，加载旧适配层符号表。第二步，比对当前输出与预期输出的偏移量。第三步，如果偏移在阈值以内，确认对账一致。

"旧适配层符号表。"她盯着第一步，"在哪？"

白又新查了息壤共享目录。没有。查了息壤固核。没有。查了岑照渠的工具清单。也没有。

"息壤从来没有'旧适配层'这个概念。"叶藏拙翻着 runbook 的剩余步骤，"玄枢的 runbook 假设使用者有一个已经建好的符号表，可以用命令行直接加载。息壤不维护编译符号——我们这边全是脚本，加载的是模块路径和版本声明。不是同一种东西。"

"所以第一步就走不通。"

"对。但问题不在你的能力。问题在他写 runbook 的时候默认了你拥有和玄枢一样的基础设施。"

季晚禾看着那份写得极认真的 runbook——每一步都有前提声明，有失效判断，有回滚路径。它在玄枢内部可能是一份教科书级别的文档。但在息壤——它被翻译成了另一种语言。不是 Python 和 C++ 的区别。是"你的前提在别人的世界里不成立"的区别。

· · ·

周栖野把 runbook 从头到尾翻了一遍。他不是在看步骤——是在数"前提声明"里有多少条在息壤根本无法满足。第一条：旧适配层符号表——没有。第二条：编译产物校验工具——没有，息壤不编译。第三条：内核调用链追踪——没有，息壤没有内核概念。第四条：内存对齐偏移验证——没有，Python 不管内存对齐。

十七条前提声明。十一条在息壤不成立。

"这不是 runbook 的错。"他说，"纪承钧写的前提声明对玄枢来说是完整的。但他没写——也不可能写——每一句声明的对面是什么。比如'需要符号表'——他在玄枢只需要写这一句，因为玄枢的每个人都有一份编译出来的符号表。但在息壤，'需要符号表'就是一道墙。"

他把那十一条不成立的前提圈出来，放到公共记录板上。标题："runbook 跨道迁移未满足前提清单"。

· · ·

宋既明是最晚看这份清单的人。他看完之后在清单下面加了一行字——不是补充，是一条新规则：

`任何从其他道迁入的 runbook、脚本、模板或配置，必须由迁入方在迁入时验证所有前提声明。任何一项前提不成立，不视为 runbook 缺陷——视为迁入适配不完整。`

"这条规则的意思是，"他说，"以后再有从玄枢、青炉、驿河过来的东西——不是直接拿过来用。是先验证它说的每一个'需要'，在息壤是不是真的能被满足。"

"验证不过怎么办？"

"不是退回。是适配。写清楚——原 runbook 的这一条前提在息壤不成立。息壤的替代方案是什么。如果没有替代方案——这一条标注为'暂不可用'。不是假装能用。"

周栖野把这条规则抄到了实验田的入口——所有从外面迁进来的东西，先过这道门。

"你知道这让我想起什么吗？"顾迁舟翻着玄枢那份 runbook 的末尾，"纪承钧在 runbook 最后一页写了一行——'本 runbook 前提可能不成立，请先判断。'他写了这一行。但他没有写——他也不知道——在另一个世界里，判断本身的前提也不成立。他不是不够诚实。是一个人永远无法写出他看不到的前提。"

· · ·

季晚禾在那天晚上重新打开了这份 runbook。她没有按步骤走——她重新写了一份适配单。在每一行纪承钧的步骤旁边，她都填了三列：原步骤的前提、息壤是否满足、如不满足——息壤替代方案是什么。

`第一步：加载旧适配层符号表` → 息壤无符号表 → 替代：加载模块版本声明与 pip freeze 输出，比对接口契约约定的字段格式。等价性需手动验证。

`第二步：比对偏移量` → 息壤无编译偏移概念 → 替代：在测试环境重新执行对账流程，比对输出值。偏差阈值沿用息壤内部约定。

她写到第十三条的时候停了。第十三条是——内核调用链追踪。纪承钧的 runbook 说："若此步失败，回退方式为：卸载本次内核符号更新，重启调用链服务。"

"息壤没有内核。息壤没有'卸载符号'。息壤重启的方式是——重新 import。"

她在第十三行的替代方案里写了："若此步失败，替代回退方式为：回退本次依赖版本更新，重新加载模块，重启服务进程。等价性未经验证。"

写完以后，她把这份"息壤本地化适配单"贴在公共记录板上玄枢 runbook 的旁边。两份并排——左边是纪承钧写的一切，右边是她在息壤一条一条对的现实。

不适配不是谁的错。是前提的翻译本身——就是最容易被漏掉的那一步。
