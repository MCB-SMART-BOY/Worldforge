# 化形卷 · 第118章 · 路在

周栖野离开前最后一天，站在息壤最高处。公共记录板上的红色标签规则、叶藏拙的最后一页账本、顾迁舟的新桥账、岑照渠回到试法的声明、白又新和季晚禾留在林过川 README 上的话。

十二卷。从"我这边能跑"开始，到"后来者的路——在"结束。沼泽没有消失——它被圈进了试法层，带着标签。桥没有全部拆除——但它们都有退场日期。空白没有被填满——但它在入口之后，在留白处，在"接手的你也写"。

"路在的不是完美的路——是带着前提声明的路，是有红色标签的路，是告诉你'这里可能不对——你来验证——你来写'的路。我们从前人的沉默中走出来——不是因为他们不够好，是因为他们不知道如何把沉默变成可传递的入口。我们现在知道——不是因为我们更强，是因为我们继承了他们所有的失败和所有的'对不起'。失败和对不起变成了制度——在公共记录板上，在 CI 的自动检查里，在 Dockerfile 的可执行环境里。路不是请后来者依赖我们——是请后来者覆盖我们。在前提声明的空白处写上新的前提——在留白处写上新的章节。"

"接手的——你也写。前提可能不成立——但方向是对的。"

他转身。息壤的三层在身后安静地运行。试法层的快、固核层的稳、入世层的承诺——三个同心圆，同一个世界。
