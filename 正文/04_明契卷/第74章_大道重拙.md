# 明契卷 · 第74章 · 大道重拙

苏野平写了一周 Rust 之后说了一句话。"你们的语言——太重了。每改一行——要改十个地方——类型、trait bound、生命周期——我写 Python 的时候——改了就跑——跑不了再改——三分钟。在 Rust——三十分钟——还在编译。"

"编译时间长——但编译器告诉你每一个错误在哪。Python 三分钟'改了就跑'——但你在凌晨追的那个 bug 是因为传了 None 给一个标注不完整的函数——那个 bug 排查花了三个时辰。三分钟和三十分钟——不止是时间的差异——是时间在不同时间的分配。Python 的时间花在前面的编写和后面的排查，Rust 的时间花在前面的编写和编译——后面的排查几乎不需要。"

"重——不一定是拙。拙——是编译器的钳制似乎让你慢下来，但它在每次编译中替后来者做了判断。你写的 trait bound 是给调用者看的——它告诉他这个函数要求什么能力。你写的生命周期是给维护者看的——它告诉他这个引用的有效期。你的重——是后来者的轻。后来者不需要在凌晨追问这个函数接收什么参数——编译器已经提前帮他验证了。"
