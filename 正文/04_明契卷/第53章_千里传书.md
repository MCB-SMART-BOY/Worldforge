# 明契卷 · 第53章 · 千里传书

沈见微设青炉的远端仓库。不是"代码在 GitHub 上"——是"代码的权威版本在远端。每个人从远端拉，推到远端，经过 review。远端是唯一的真相来源"。

旧工具链——代码散落在各自机器上，"谁的机器上的是最新版"——不知道。没有权威版本，每个人在自己的本地有一份可能是最新的也可能不是的拷贝。远端是"真相只有一个"——不是备份，是真相。真相在远端，每个人从它开始，向它提交，经过验证才成为新的真相。

"不是把代码放网上——是让分布式协作有一个共同的权威版本。之前玄枢的构建脚本在钟守玄的机器上——纪承钧在另一台机器上有一份旧版本——陆踏痕用的是沈照痕发来的备份。每个人都在自己的机器上改——但没有人知道改的是不是最新的。远端仓库是权威——不是集中控制，是分布式协作的中心锚点。你从它出发，回到它——但中间你在你自己的 branch 上自由走。"
