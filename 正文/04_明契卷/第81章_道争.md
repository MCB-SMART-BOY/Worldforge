# 明契卷 · 第81章 · 道争

沈见微面对内部的道争——苏野平代表"快"，裴照川代表"形式化验证"，闻衡代表"审契"——三种方法在青炉的 workspace 中碰撞。

苏野平："你的前提声明太长——使用者不读。他们只想 run——不想要读两页文档。"裴照川："前提声明可以被形式化——写成机器可验证的前置条件。不是让人读——是让机器检查。"闻衡："机器只能验证你写下来的条件——不能验证你忘了写的条件。前提声明需要人工审查。"

三种方法——三种"写清楚"。苏野平的快——写少，够用就行。裴照川的准——写机器能验证的证明。闻衡的稳——写人能审查的契约。三人不是在争谁对——是在争各自时代的后来者需要什么样的路标。快给现在的使用者，准给未来的验证者，稳给之后接手的人。三条方向同时存在于同一座仓库里——不需要合并为一种声音，只需要在入口处标注谁来守护什么。
