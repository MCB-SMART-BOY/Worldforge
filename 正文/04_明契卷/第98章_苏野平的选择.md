# 明契卷 · 第98章 · 苏野平的选择

苏野平在青炉的 workspace 里留下了他最后的脚本——不再是三百行无文档的临时工具，而是一个带前提声明和退场日期的 Python 桥接模块。"这是临时的——退场日期：六个月——退场条件：青炉 CI 全面覆盖依赖审计。我仍然用 Python——因为我跑得快。但我现在在搭桥的时候——在桥账上登记——让后来的渡桥人能来找我。"

他不放弃快。快是他的道。但在"先跑通"之前多加了一行标注——这个模块在什么前提下成立、什么时候到期、谁在维护。快不必反慢——只需在速度快的同时让后来者跟得上速度的方向。化形之道的快没有被他丢弃——他把申明加在了快的前面。
