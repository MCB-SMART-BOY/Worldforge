# 明契卷 · 第86章 · 放弃"写清楚就是一切"

纪承钧的传讯击穿之后，沈见微在青炉的公共记录板上站了很久。

他在想梁故川。那个在他之前来到青炉的人——写文档、写 scope、写"为什么"——然后有一天清空了记录板，只留了一行字："此处逻辑不应被文档化。"然后走了。梁故川遇到的是同一个问题——写清楚的东西在另一个世界可能变成炸弹。他的回答是清空一切——让后来者从头来——不要信任何写下来的东西。

沈见微拿起笔。他要在同一个位置——梁故川清空的地方——写下另一种回答。

"我放弃'写清楚就是一切'。"

"我仍然会写清楚。写每一个接口的输入、输出、错误处理——写每一条 unsafe 的安全论证——写每一个 trait 的设计理由和替代方案。但我会在第一行写清楚：'以下内容的前提——在你的世界里可能不成立。——你的前提——可能和我不一样。'写清楚不是保证正确——是让错误在发生时能被追溯。写清楚——不是一切——是知道自己的边界——并在边界处标注——'这里——我的清楚——可能不够。'"

他停了笔。看着自己写下的字。

"梁故川——你选择不写——因为你怕写下来的东西变成不容质疑的真理。你的恐惧是对的——所有经历过跨域爆炸的人都知道它是真的。你把记录板清空了——因为那是你那个时代唯一能找到的回答。沉默——保护后来者不被你的判断误导。但沉默也让后来者没有入口。他们在黑暗里摸——和你在世时一样。"

"我选择写——并在第一页写'前提可能不成立'。两种方式面对同一个恐惧。你的沉默和我的声明——是同一枚硬币的两面。你不写——是因为你怕你的字变成墙。我写——是因为我知道——我的字在墙的位置上——只要标注'此处是纸——前提可能不成立'——墙就变成了门。"

"你不是错了——你是早了。在你的时代——还没有前提声明这个格式。你不知道可以'写承诺——同时标注承诺的前提和失效条件'。如果你有——你不会清空记录板。你会在每一个文档的第一行写：'以下内容基于青炉的考古——在 Rust 1.x + Linux 的前提下成立——如果这些前提在你的世界不成立——请验证。'那不是你的沉默的失败——那是你的沉默——在等一个你没能等到的词。"

他在梁故川留下的那行"此处逻辑不应被文档化"旁边——刻上了新的字。"此处逻辑的前提已被声明。——此后失效条件被标注。——你可以文档化。——前提可能不成立。——沈见微。"

不是反驳——是完成。梁故川的话没有被擦掉——它被保留了——作为路标。路标说：这里有人停过——他停是因为他的时代没有前提声明。后来者——你有了——继续。

"放弃不是失败。是让写清楚知道——它有一个边界。——在边界内——它是路。——在边界外——它是墙。——知道边界在哪——比假装没有边界——更诚实。——诚实——是写清楚的前提。——前提可能不成立——但方向是对的。"
