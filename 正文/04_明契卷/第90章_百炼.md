# 明契卷 · 第90章 · 百炼

卷十二开始。不是"从写代码的人到立道之人"的瞬间转变——是"在放弃之后——继续写"的每一天。

沈见微继续写文档、写测试、写 changelog、写前提声明、写 unsafe 安全论证。放弃的不是写清楚这个动作——是"写清楚可以替代一切"的假设。每一次写——都在边界处标注——"以下内容基于青炉的考古。你的前提——可能不同。请验证。"

季循接手了青炉的核心维护。他的第一个 PR 被闻衡打回了三次——不是因为代码不好，是因为没写清楚一个 trait bound 的设计理由。"你在放弃声明下面写这些——和梁故川时代的沉默相比——是不同的选择。你在告诉后来者'这是我的选择、为什么我这样做、什么条件下这个选择仍然成立'。梁故川的那个时代没有人做到这一点——不是不能，是没有人告诉他们这是可以做的。"沈见微看着季循重写的 PR 描述——设计理由、替代方案、前提条件、失效风险。这些框架不会过时——即使代码过时了。
