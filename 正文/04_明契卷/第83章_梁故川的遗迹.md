# 明契卷 · 第83章 · 梁故川的遗迹

韩砺年带沈见微去旧区——梁故川曾经工作的地方。旧机器还在，上面有他留下的记录——不是代码，是笔记。

"前提声明——如果我在明契卷写'以下内容基于 Rust 1.x + Linux'——化形卷的 Python 使用者会问：'Rust 是什么？这是写给谁看的？'前提声明——需要被接收者读懂——否则它只是另一份'写得很清楚但没有人在看'的文档。我需要想明白接收者需要什么语言——而不是我认为什么语言是对的。前提声明不是信息发出者完成的——是信息到达收件人手里时完成的。我在第一卷画下的声明需要穿越道的边界到达对方的终端——我需要对收件人的世界说他们能懂的话。"
