# 明契卷 · 第61章 · 守界

内存安全不是 Rust 的特性——是 Rust 的承诺。所有权（ownership）、借用（borrowing）、生命周期（lifetime）——三个概念合在一起，让编译器能证明"这段代码不会在运行时访问已被释放的内存"。

不是程序员靠谨慎来保证——是编译器靠类型系统来证明。"你说'我借用这个值'——编译器说'可以，但在这个借用期间——你不能释放它。'这不是约束，是保护。保护后来者不需要在凌晨排查 use-after-free。"

青炉的一个模块在旧工具链中是 C 写的——裸指针、手动内存管理。迁移到 Rust 时原来的指针操作被替换成引用和生命周期标注。编译器在第一次编译时拒绝了它——因为一个借用活得太久了，可能覆盖了另一个可变引用。在 C 中这段代码能编译通过——然后在运行时随机崩溃。在 Rust——编译时就拦住了。"不是编译器讨厌你——是编译器比你更懂内存。编译器不骗人，但人会骗自己——觉得自己记得所有指针的生命周期。"
