# 明契卷 · 第93章 · 前提之外

沈见微写下最后一行声明——放在青炉记录板最上面。这一行会出现在每一个 crate 的 README、每一个 PR 模板、CONTRIBUTING.md 的第一行。

"前提之外——他们需要自己判断。"

"此 crate 的每一个文档——基于青炉的考古前提——在 Linux x86_64 + Rust 1.x 的语境下成立。在你的世界里——可能不成立。如果不在——你来画——你来写。接手的——你也写。前提可能不成立——但方向是对的。前提不是束缚——是让后来者知道你写下的承诺在什么语境下成立。在你那边的语境下不成立——那是你为你的世界画图的时候了。"

闻衡看了这行字。审契者的尺量过无数个接口——这是他第一次量一行不是接口的文字。"你在每一个文档前面写这行——不是在削弱你的写清楚——是在让写清楚知道它在什么地方可能不够。之前你写文档——是在告诉后来者'这个接口能做什么'。现在你加了这一行——是在告诉后来者'这个接口在什么条件下能做什么——在什么条件下不能。'后者比前者更诚实。"

季循看到了这行字。他是青炉的继承者。"我第一次读你的文档时——以为它们是完美的。完美到我不敢改。现在这一行告诉我——'你可以改——只要你知道你在什么前提下改。理解了我的前提——然后为你的时代重新判断。'不是沈见微给了我一堆答案——是他给了我判断的起点。"

和纪承钧、周栖野、傅远洲的放弃声明一样——全系列放弃声明在四个平台上以四种语言同时存在。玄枢——"前提可能不成立。"息壤——"此 runbook 的考古前提在你的世界里可能不成立。"驿河——"以下必填项的选择可能不完整。"青炉——"前提之外——他们需要自己判断。"

四行——同一个意思。写下来不是给规则锁死——而是让每一个跨越边界的人知道前人的清楚有明确的界限——在那个界限之外需要他自己的判断。他的放弃不是失败——是让写清楚知道它在什么前提下有用。青炉会继续下去——带着这行声明。每一个后来者打开文档——第一眼看到的——不是戒律——是邀请。
