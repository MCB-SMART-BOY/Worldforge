# 明契卷 · 第06章附 · 借用，看而不取的工程伦理

临时目录的事收住以后，季循以为自己总算摸到了青炉的骨。

他能分清什么是拿着、什么是丢掉、什么是用完自己收。但第二天上午，沈见微让他把那份样本改成两个函数（`function`）——一个负责读校验清单，一个负责把结果写进记录。

他很快写出来。然后在石镜前被绊了整整半个时辰。

· · ·

事情本身不复杂。

清单放进去了，记录也放进了该去的位置。可当他用第一个函数读清单，再让第二个函数接着写记录时，镜上吐回的却不是跑通的光纹，而是一段他从没见过的暗红字：

```
error[E0382]: borrow of moved value
```

季循盯着那行报错，脑子里翻来覆去只有一个念头：我没动它。它还在那里。

沈见微正巧从门外进来，看见他僵住的样子，只把一杯温水放到他手边。

"卡在哪了？"

"我本以为昨天懂了。"季循指着那行报错，"第一个函数读完清单，清单明明还在原地，可第二个函数再想碰它，青炉就说它已经被移走了。"

"因为它确实被你移走了。"

"我只是让它看了一眼。"

"你让谁看了一眼？"

季循愣了一下。他重新看自己写的那两行：

```rust
fn read_manifest(path: PathBuf) {}
fn write_record(path: PathBuf) {}
```

"两行都是 `PathBuf`。"

"对。"沈见微说，"不带 `&` ——不是借来看，是拿进来。第一个函数把清单拿走了——清单就归它了。第二个函数再要，手里已经没有了。"

季循沉默了。

不是因为不会改。

而是因为他忽然发现，过去在任何一种旧法里，他从来没想过"看一眼"和"拿走"这两种事竟然需要被分开。

· · ·

苏野平不知什么时候已经到了。他从镜边瞥了一眼那两行命文，笑了。

"你这不就是典型的 Rust 式自己绊自己？在息壤——"

"在息壤，我直接传进去就行。"季循破天荒替他把话接了，"可现在是在青炉。我昨天已经摔过一次了。"

苏野平收了笑。

"那你现在打算怎么改？"

"加 `&`。"

"就这么简单？"

"就这么简单。"季循把第一行的 `PathBuf` 改成 `&Path`，"第一个函数只借来看。它看一眼清单，不做任何别的。第二个函数才真正拿进一份独立的记录，负责到底。"

他按下重跑。

两面镜的光纹平平顺顺交错而过，互不相撞，也互不相吞。

报错没了。

可季循并没有多高兴。他看着那两行已经修好的命文——一行带 `&`，一行不带——像在看一把尺。

一把他过去从来没有过、也从来没人给过他的尺。

· · ·

"所以 `&` 不只是少打几个字。"他说。

"对。"沈见微说，"它是一种区分。青炉把'看'这件事单独拎出来——你只借来看，不能拿，不能改，不能删。谁借的，借了多久，青炉自己盯着。超了该还，它就会替你报。"

"为什么要盯得这么紧？"

"因为过去北院的病里，有太多'只是看了一眼'然后不小心把东西动了的旧事。"闻衡的声音从门口传来，她手里拿着昨夜临时目录事故的抄片，"昨天那份被程知序顺手清掉的中间文件——她也不是故意的。她当时也只是'顺便做了一步'。"

季循低下头。

这次他听懂了"不是故意的"那一刀为什么反而更疼。

因为最深的伤，往往不是恶意的。是"看了一眼"和"拿了起来"这两件事，从来没有被写成分开的规矩。

· · ·

那天下午，季循做了一件在旁人看来也许不算什么的事。

他把青炉存着的每一份旧发版脚本都翻出来，找里面有没有没带 `&`、用全量传参的地方。

找到的不是一处。

是三十二处。

每一处都不算错。每一处在当时写它的人手里，都活得很好。

可季循看着那三十二个没有借、只有拿的命文入口，忽然觉得它们像三十二道没挂锁的门。锁不一定每次都会被人踢开。可门没锁这件事本身，就是对后来者的一种不需要说出口的询问：你得自己小心。

他把那三十二处抄进自己的记事板，在旁边注了一行：

`这些不是错。是没写清楚借与拿的边界。`

沈见微看见这行注的时候，把那张纸看了很久。

"你知道吗，"他说，"裴照川当年刚进北院，也干过和你几乎一样的事。他翻出了二十九处没带声明就共用的缓存口子。后来那些口子被一个个用旧法包了起来——但不是改成借。是在每一处前面加了三行注释：此处勿动，老钩在前。请先联系值班组。"

季循抬头。

"那不是修。"

"不是。"沈见微说，"那是把锁人的力气用在了锁门上。你现在的做法是反过来——先把门写清楚，再让人自己知道哪里不该乱推。"

· · ·

韩砺年在这时走了进来。

他很少主动看别人写命文。但今天他在季循镜前站了许久，一直看完那三十二处的抄注。

然后他说了一句很短的话。

"我当年就是锁门的那个人。"

季循没敢接。

"不是因为锁门更好。是因为当时没人告诉我，你这种写法——借和拿，看和改，各归各路——才是路。"

他顿了顿。

"所以后来的人问为什么不能动，我只能说'以前出过事'。再问为什么出过事，我只能说'你别问，问就是老钩'。"

季循忽然觉得手里的记事板比之前重了。

不是因为它写了三十二处。

是因为它让一个锁了半辈子门的人，认出了门本来可以不用锁。

· · ·

到傍晚，苏野平又把那面共用缓存的镜翻了出来。

"我承认借和拿得分清。"他说，"可你们这 `&` 的讲究，是不是走得有点过头了？一个东西临时给人看一眼，还非得写成借？"

"那你觉得应该怎么写？"闻衡反问。

"直接传进去不就完了。"

"传进去以后呢？传进去以后，你拿什么来保证他不会顺手改掉？靠自律？靠'大家都懂'？"

苏野平没立刻答。

"卷首那夜的事故里，至少有两处回退指令没跑通，是因为有人在前面一步'顺手更新了'一段本该只读的旧钩接口。"闻衡把那张抄片放到他面前，"那个人不是故意的。他甚至以为自己做了件好事——'顺便帮后来者把版本也提了'。"

苏野平看着那张抄片，好一会儿才出声。

"所以你们的意思不是怕人坏。是怕人好心。"

"对。"沈见微说，"青炉把'借'写成强制区分，不是因为它不相信人的良心。是因为它知道——越是想做事的人，越容易在没被划清边界的地方，顺手多做了一步。等出了事，他自己都不记得自己碰过什么。"

季循听到这里，忽然想起了梁故川。

那张"回头我来收"的便签。

他不是不在乎。

他也是顺手——先救眼前的火。然后顺手多救了另一处。再顺手替别人补了一道。一直顺手，一直没回头。

原来所谓"顺手"，真正的代价不是多做了一步。是把那一步没写清楚——让后来者不知道这一步是怎么走的、能不能重走、谁担后果。

· · ·

天色全暗之后，季循重新打开青炉文契。

他在昨日沈见微那四句新规下面，又加了四行：

`凡借来看的东西，声明只借不拿。`

`凡拿进来的东西，声明归谁负责到底。`

`借和拿不在同一行命文里混用。`

`借出事的，找借的人；拿出事的，找拿的人。`

苏野平看了一眼，喉咙动了动。

"你这四行，息壤里根本没法执行。"

"所以这不是息壤的规矩。"季循说，"这是青炉的。"

他说这句话的时候，才发现自己用的不是"青炉的规矩"——而是"青炉的"。像一个终于不再是客人的人。

闻衡把那四行看了一遍，画掉第四行里一个模糊的措辞，改成：

`借出事的，找借的入口声明；拿出事的，找拿的入口声明。`

"不要找人。"她说，"找声明。人能走，声明留下。"

季循愣了一下。

然后他明白了。

如果找的是人，那么只要那个人还在、记忆力还好、愿意再说一遍——就能继续。可梁故川不在了。钟……他停了一下，没继续想。他知道在另一个旧世界里，也有过同样的人。

只有找声明——找一条写下来、后来者也能跟着查到的声明——这条路才不会因为一个人离开就断掉。

· · ·

雨在凌晨停了一会儿。

东廊外冷得很干净。季循靠在门框上，翻开记事板，把今天加的四行又从头看了一遍。

沈见微走过来，站在他旁边。

"你今天没写新功能。"

"嗯。"

"但做的事比写新功能更重。"

"我知道。"季循说，"我在学怎么把'看'和'拿'分开。以前我以为这是编译器（`compiler`）才需要操心的事。"

"现在呢？"

季循看着檐角那一滴将落未落的雨水。

"现在我知道，它是为了让那些只是顺便看了一眼的人，不会在某一天忽然发现——自己不知道什么时候已经把一条路替别人踩断了。"

沈见微没有接话。他知道这句话真正指向的，不是今天的代码。是梁故川。是所有"回不来"的人。是所有被最善意的顺手，悄悄掩埋的暗路。

他只是在季循肩上拍了一下，低声说：

"继续写。"

然后转身回炉房。

镜光从门缝里漏出来，照着季循记事板上那四行新加的规则。

借——看而不取。

拿——取则负责。

分开——不是为了制造麻烦。是为了让每一个后来者都能分清：什么事是顺着先人的脚印在看，什么事是自己正在替将来的人留下新的路。
