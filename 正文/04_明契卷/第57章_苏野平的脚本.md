# 明契卷 · 第57章 · 苏野平的脚本

苏野平从化形卷过来——带着 Python 的生态和"我那边有个脚本能帮上"的姿态。他写了一个自动检查依赖兼容性的 Python 脚本——用了 pip-audit，很快，能自动标记废旧的依赖引用。

"放你 workspace 里——临时的——等青炉的 CI 起来就删。"

"你的脚本——文档在哪？"

"呃——看代码——很简单的——三百行——不需要文档。"

"三百行——不需要文档。但后来者看到 py 文件——不知道它做什么，什么时候该跑，什么时候不该。你的脚本——依赖了 pip-audit——pip-audit 的版本变了——脚本可能出错——后来者不知道。'简单'——不等于'清楚'。"

苏野平是从化形卷过来的人——他的"先跑通"是息壤的文化底色。"三百行 Python 在化形卷那边算中型脚本——写文档的时间比写代码还长。只要它的入口清晰、输入和输出定义明确——就足够被后来者使用和维护。"沈见微看着他走回编辑器的背影。两个不同的世界的工程节奏在同一个 workspace 里第一次碰撞。
