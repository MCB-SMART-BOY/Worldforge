# 明契卷 · 第68章 · 入世之后

程知序在外部项目中引入了青炉——第一个外部使用者。"你的文档说 feat 需要一个 Config——但没说 Config 从哪来，没有示例。我猜了——猜错了——花了几个时辰才找到正确的初始化方式。"

沈见微加了一个 examples 目录——每一个 pub API 有一个独立可运行的示例。不是放在文档里描述——是真正可编译的 `.rs` 文件——被 CI 保证每次提交都编译通过并且运行正确。使用者打开 examples 目录看到的就是"从这里开始"——不是读文档，是直接看运行中的代码。

"入世意味着外部使用者会用你的接口——而且他们不会来问你怎么用。他们会在凌晨自己翻文档和例子。文档是你和凌晨使用者之间唯一的联系。如果文档模糊——他的凌晨变成排查你的 API 的凌晨。如果你的示例过时了编译不过——他需要从你的源码反向推断正确用法。第一个外部使用者是契约的最终检验——他没有任何上下文，没有听过你的口述，没有参与过设计讨论。他只有文档、示例、changelog、和你的 crate。如果他能独立用起来——你的写清楚够用了。"
