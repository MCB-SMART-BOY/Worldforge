# 明契卷 · 第108章 · 后来者的后来者

季循带了第一个新人——从零开始 onboarding。他给了新人三样东西：青炉的 README——第一行写着"前提之外——他们需要自己判断"；闻衡的尺——四个问题在每一个 PR 模板里；CONTRIBUTING.md——第一行是一样的前提声明。

新人第一天提交了第一个 PR——改了文档中的一行过期描述。PR 描述完整——有上下文、有影响分析、有验证步骤。闻衡的尺在他自己的 PR 里亮了——他提前回答了尺会问的所有问题。"不是因为他聪明——是因为他读的第一行就是'前提可能不成立'——他知道问什么。他不需要先撞过所有的墙才知道自反——自反已经是青炉入口文档的一部分。"后来者的后来者——接过的不再是沉默——是带着前提声明的起点。
