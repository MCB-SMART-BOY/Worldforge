# 明契卷 · 第65章 · 守界之后

卷七收束。所有权系统让内存安全从人的谨慎变成编译器的证明。并发安全从 code review 变成类型系统的 Send/Sync 检查。Unsafe 从"这里危险，小心"变成"这里自负其责——写下安全论证，留给后来者"。裴照川为同样的 unsafe 代码留下了形式化证明——不是替代沈见微的注释，而是给未来的后来者多一条验证路径。

"守界之后——不是所有边界都被保护了。是关键的边界被标注了——编译器保护不了的地方——人为承诺写了安全论证。Unsafe 不是漏洞——是自承其责的声明。边界永远不会消失——系统总需要越过编译器去和外部世界交互。守界的意义不是消除边界——是标注边界——让每一个跨过边界的人知道——'此处——需要额外论证。'论证是人留给后来者的——不是编译器的检查替代了人的责任，而是人在编译器做不到的时候留下自己能做的部分。"

卷八「出山」——青炉走到外部世界。发布、部署、运维。从内部的守界到对外的承诺——semver、发布说明、弃用声明。裴照川的镜像在更大尺度上展开。
