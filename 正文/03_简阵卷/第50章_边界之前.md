# 简阵卷 · 第50章 · 边界之前

卷五最后一天，秦望秋把观测三视图的完整部署记录贴在公共记录板旁边。从 OpenTelemetry 的第一个 trace 到全平台覆盖，从 goroutine 泄漏的缓慢增长到 pprof 火焰图中的字符串拼接，从四十三条传讯牌到四条核心告警——观测不是一蹴而就，是一层一层揭开的。

"看得见了——但看见的东西比预想的更多。之前不知道有多少 goroutine 在等，不知道对账的百分之九十时间在等数据库。知道了——能修，但知道的过程让人不安。观测的代价不是延迟的那百分之五——是发现'原来系统里藏着这些东西'的不安。但不安比不知道要好——不安可以被行动解决，不知道永远在那里。"

卷六「边界」——画边界。内部已经可见，现在需要的是区分哪些在内部可以被观测保护——哪些在外部需要契约来约定。化形卷过来的模块在边界上，外部 API 的调用在边界上，从息壤继承的隐式依赖在边界上。边界不是墙——是需要标注和管理的区域。观测让内部为明——边界是明的第一道外延。
