# 简阵卷 · 第95章 · feature flag

Ch61——优化让服务变快，因为时序假设改变，炸了下游。如果有feature flag（`特性开关`）——先给百分之一的流量，在百分之一上发现时序变化——不会炸百分之九十九。

Feature flag让变更不再是二进制开关——是渐进交付。开关层——on或off。百分比层——百分之一到十到五十到一百。定向层——特定用户或条件。部署不再是全量上线后祈祷——是先给少量流量，等几分钟，看指标。正常就扩大，异常就回滚。那百分之一的流量是唯一真正的测试——生产环境上的百分之一比任何测试环境更接近真实。

Flag不是永远的——有退场日期。每个flag创建时就标注了两周后要么全量要么删除。留在代码里的flag会变成新的技术债。特性开关让上线从赌博变成可控的实验——不是让变更更慢，是让变更更安全。
