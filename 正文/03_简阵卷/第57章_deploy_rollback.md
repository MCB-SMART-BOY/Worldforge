# 简阵卷 · 第57章 · deploy / rollback

桥账建立的同时，傅远洲把部署系统从手动改成了自动化。之前——部署是两个时辰的流程：scp 代码上去，重启服务，检查日志，如果不对，scp 旧版本，重启，再检查。人在每一步上等，人在凌晨做重复的事——会出错。

现在部署是声明——定义目标状态，系统自动执行。`deploy v1.2.3`——机器做，人在看。部署和回滚是同一个系统的两个方向——不是"出错了怎么办"，是"如果不对，反向执行同一个声明"。回滚从"不知道滚回哪里"变成了部署系统的反向命令，和部署一样只需要一条命令。部署窗口从两个时辰降到了不到一个时辰。

"部署不是把代码放上去——是声明'这个版本从此刻起是生产版本'。回滚不是把旧的放回去——是声明'上一个版本重新成为生产版本'。部署和回滚是对称的——是同一个系统的两个方向。机器做步骤，人做判断。凌晨——人应该用来做判断而不是做步骤。"
