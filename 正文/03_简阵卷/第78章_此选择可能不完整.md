# 简阵卷 · 第78章 · 此选择可能不完整

傅远洲在模板第一页加了一行。

"以下必填项由傅远洲选定，基于卷一到卷八的驿河事故经验。此选择可能不完整——不完整不是缺陷，是诚实。后来者——如果你经历了新的事故，发现某项应该被加上，在此添加并标注理由。如果你发现某项不再是必须的——在此删除并标注为什么。模板是活的——不是因为傅远洲选了就永远在，而是每一代守门者根据新的事故更新取舍。"

和化形卷前三层息壤的 README 一样——"你在这里意味着..."——驿河的模板也变成了入口文档。四项必填从"规则"变成了"有理由的选择"——理由写在每一项旁边，前提声明在每一页上面，空白的行留给后来的守门者标注新的必填或值得删除的旧项。

"制度需要诚实地标注自己的不完整。因为不完整不等于没用——不完整是承认我不知道的事可能比我知道的更多。周栖野的空白是诚实的不知道。傅远洲的四项必填是被事故验证过的知道。两者汇合在模板第一页：声明了知道的，留下了空白的行。声明不是终点——是让不知道变成知道的起点。制度最危险的时候不是'不够'——是'以为够了'。标注不完整是防止制度从地板变成天花板的唯一方式。"
